## PERF-03 — startup

| scenario | command | observed |
| --- | --- | --- |
| cold store | `cargo test --test startup_latency -- --nocapture` | ready-to-type p50 40 ms, p95 49 ms; ready-to-submit p50 7 ms |
| warm store | same command | ready-to-type p50 39 ms, p95 42 ms; ready-to-submit p50 7 ms |
| monorepo | `MIAO_PERF_WORKSPACE=<repo> cargo test --test startup_latency startup_on_a_monorepo -- --nocapture` | ready-to-type **p50 45 ms, p95 635 ms**; first frame p95 477 ms; ready-to-submit p50 7 ms |

The monorepo p95 **misses the 500 ms gate** and is recorded as missed. The p50 of 45 ms
says the steady state is fine; the 635 ms is the first of five launches in that tree,
so the gate is being compared against a cold sample. Either the gate means "warm", in
which case the harness must discard the first launch, or the cold monorepo path needs
work — that is a decision, not something this record can settle.
