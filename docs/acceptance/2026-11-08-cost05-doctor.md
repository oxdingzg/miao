schema, the routing state with the primary route named, the sandbox's
enforcement state (`crate::process::enforced()`), and the external
dependencies checked live. The integration suite
(`crates/miao-engine/tests/doctor.rs::doctor_reports_version_routing_sandbox_and_dependencies`)
pins the same facts.
