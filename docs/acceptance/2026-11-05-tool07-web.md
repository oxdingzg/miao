## "Support source URLs, body budgets, redirect and auth failure handling, and in-flight cancellation" — accepted

| part | test | observed |
| --- | --- | --- |
| source URL and body budget | `fetch_renders_real_html_and_declared_text_encoding_and_bounds_output` | the fetch payload is `{url, content_type, content, truncated}`; a 30 000-character page comes back truncated, a page past the 2 MiB download bound is refused rather than buffered |
| encoding and rendering | same | UTF-8 HTML renders to markdown with link targets preserved and `<script>` dropped; a `charset=gbk` body decodes through the declared encoding instead of arriving as mojibake |
| redirects | `redirects_are_reauthorized_and_denied_targets_receive_no_request` | a redirect target is authorized on its own, and a refused target receives no request at all |
| credentials and auth failures | `search_redirects_never_forward_credentials_and_errors_hide_provider_bodies`, `searches_use_their_native_wire_contract_and_never_return_the_key` | a search redirect never carries the key; provider error bodies are not echoed to the model; the search key never appears in a result |
| cancellation | `cancellation_drops_an_inflight_web_response` | cancelling drops a response that is still arriving |
| product execution path | `runtime_fetch_waits_for_bound_controller_approval_before_any_http_request` | a fetch from a run waits for the bound approval before any HTTP request leaves the process |

## "Preserve distinct REST and MCP backend differences and support real selection between them" — not accepted

The engine has REST search backends only: `crates/miao-engine/src/web.rs`
selects between Exa and Parallel by host configuration, and `websearch` never
accepts a model-supplied endpoint. There is **no MCP search backend**, so the
criterion's "REST and MCP … real selection between them" has one side
implemented. MCP tools can still be called as MCP tools; that is not a search
backend selection.

## "Measure retrieval quality and cost independently …" — not accepted

This run asserts contracts (bounds, encoding, redirects, credentials,
cancellation), not recall quality. No harness compares formats or measures what
a search cost, and none is claimed here.

Still unaccepted after this record: the MCP search backend and selection between
backends, and retrieval quality/cost measurement.
