# Screenshot provenance

Refreshed 2026-10-04.

- `miao.png`, `miao-home.png`, `miao-providers.*` and `miao-web.png`: miao
  v0.1.0, displayed through the actual terminal/browser application.
- The code-review session is an **illustrative imported session**, not a paid
  model run. It is marked as such in the captured conversation and README.
- `miao-mini.*` and `miao-permission.png`: the opt-in mini interface in the
  v0.1.1 development build, using its built-in demo mode.
- Terminal captures exclude the enclosing terminal's window chrome. Stills are
  at most 1600 px wide; short GIFs are 960 px, 2 fps, and under 175 KB each.
- The website uses responsive WebP stills and smaller, controllable MP4 demos.

The [shared media notes](https://github.com/oxdingzg/mtty.dev/blob/main/docs/media.md)
describe capture isolation, feature coverage, dimensions and size budgets.
