# Experiments

[简体中文](README.zh.md)

This directory holds **reproducible live-model measurements**: the report, the comparison tool, and the raw evidence are committed together so a conclusion can be re-derived or re-run on a newer version. Local drafts and scratch output belong in `docs/research/`, which is gitignored and not committed here.

## Layout

```
docs/experiments/
  README.zh.md, README.en.md      index and rules
  tools/compare.py                shared comparison tool (stdlib, no deps)
  <YYYY-MM-DD>-<slug>/
    README.zh.md, README.en.md    conclusion, method, reproduction, evidence boundary
    manifest.json                 version and environment facts
    prices.json                   billing rates (per 1M tokens)
    results.csv                   machine-readable per-class and totals
    results.md                    tables generated by compare.py
    raw/<engine>/
      evidence/*.json             full evidence per run (attempts, phases, receipts)
      samples.json                merged samples
      sweeps.json                 per-chunk sweep summaries
```

## Every experiment must record

- **revision**: the repository commit the runs used. If the arms differ, explain why in the README or re-run both at one commit.
- **suiteHash**: the frozen suite hash. Different hashes mean different task sets and cannot be compared.
- **Model and route**: model id, provider, endpoint. **Never** record an API key.
- **Binary identity**: when the engine runs from `--binary`, record `binarySha256` and `--version`.
- **Prices**: `prices.json` with its source and date; recompute the amounts with the product's own `SessionRunnerCost.ofTurn` and check they match a manual sum.
- **Commands**: the full command lines, with `<env>` in place of keys.
- **n and task list**: repetitions and classes; state which class is missing or not comparable.

## Rules

- No credentials, absolute paths, or personal directory names; scan `raw/` before committing.
- Keep raw evidence as JSON (inspectable, greppable). If one experiment directory would exceed 25 MB, switch to `.json.gz` or a release asset and keep only the summary, scripts, and reproduction commands in the tree.
- Every number in the README must be reproducible from `tools/compare.py` and the raw evidence; a mismatch with `results.md` is a defect.
- Cost claims should run the same configuration at least twice and report both rounds: two rounds of one suite ranged from 0.785 to 0.881 in the 2026-10-19 experiment.
- One experiment answers only what it covers. The README must state its evidence boundary (model, n, task types, machine) and must not generalize a run into a product-level claim.
