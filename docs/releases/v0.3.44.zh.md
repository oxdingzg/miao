# miao v0.3.44

v0.3.44 把 TypeScript 版产品线退役，只留一个 Rust 二进制，并收进了 v0.3.43
以来引擎、TUI、CLI 与远程控制的全部改动。

## 一个二进制就是产品

- **TypeScript 的 CLI 与 TUI 已移除（#2627）。** `miao` 就是 Rust 二进制：
  它链接引擎，并在同一进程内运行 TUI。TypeScript 工作区现在只构建桌面端
  及其内嵌的服务端，随退役 CLI、TypeScript TUI 与 TypeScript ACP 服务一起
  离开的还有驱动它们的那批测试。
- **提示词与技能文本移出 `packages/core`（#2621）。** 人格与内置技能改放在
  仓库根 `assets/`，两个宿主读同一份，因此编译 crate 不再要求 TypeScript
  树在场。
- **nix 打包的就是这个二进制（#2625）。** `miao` 包改成了对 `crates/miao-cli`
  的 `rustPlatform.buildRustPackage`，不再用打过补丁的 bun 编译 TypeScript；
  发布脚本只保留它真正用到的 `--native-cli` 一条路径（#2631）。
- **三个 core 模块随最后一个调用者一起移除（#2641）。** 旧环境变量迁移、Session
  保留策略与 public event manifest 都已无调用者：前两者由 Rust 宿主负责，第三个
  更早之前就没有引用者。
- **`serve` 仅作为测试支撑保留。** 一个小的 `src/serve.ts` 启动与桌面 sidecar
  相同的服务端，集成测试因此仍能以真实 HTTP 驱动它。

## v0.3.43 以来的其他改动

- **引擎**：Session 可以在进程内使用 git worktree（#2608、#2618）；记录网关
  上报的费用（#2581）；每个账号都可路由并在 picker 中具名（#2564）；上下文
  预算退化时会明确说明；不健康的缓存状态附带推荐修法（#2535）。
- **TUI**：worktree 对话框（#2615）；侧栏显示自身快捷键（#2624）；可在
  picker 中保存 provider key（#2556）；侧栏显示最近 24 小时用量（#2568）；
  一轮运行中排队提示会被回显。
- **CLI**：`miao upgrade` 从"只报告"变成真正升级（#2477），并带经过校验的
  数据库备份（#2485）；`doctor` 报告路由、沙箱与依赖（#2547）；新增受管
  配置作用域（#2541）。
- **远程控制与移动端**：在手机上管理 Session（#2570）、配置供应商与模型
  （#2566）、查看各 Session 中需要你处理的事项（#2567）、无需电脑的手机
  模式（#2584）、提示入队后的确认（#2591）。

## 升级方式

`miao upgrade`，或用 `install` 脚本重装。Windows 二进制仍未签名，发布说明里
会记录该状态。
