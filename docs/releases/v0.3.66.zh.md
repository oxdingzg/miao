# miao v0.3.66

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.66.md)

v0.3.66 将自动压缩触发点从 90% 降到 88% 以留出更多余量，并将 Windows 上必败的 TS 测试按原因门控。

## 自动压缩 88%（#2938）

- 触发点从 90% 降到 88%，为摘要与操作者的下一轮留出更多空间。

## Windows TS 单元腿转绿（#2938、#2917、#2919）

- 七组在 Windows 上不可能通过的用例按原因门控（Unix fd 构造、POSIX 文件名、进程/shell 层已随引擎迁移退役）。
- 权限分类器不论分隔符都能识别受保护路径（#2917）。

## /accounts 多 key 路由正常（#2931）

- 给同一 provider 存第二个 key 不再导致配置重载失败。

## 其他修复

- Schedule 编辑对话框预填当前表达式并本地校验（#2934）。
- 运行中任务的输出保留在内存中以供 jobs 回答（#2925）。
- jobs 面板预览输出而非结果外壳（#2923）。
- 压缩按大小规划并说明自己在做什么（#2920、#2921、#2912）。

## 已知问题

- `tests/web.rs` 在 Windows 上有一条审批用例以 `STATUS_STACK_OVERFLOW` 崩溃（#2926）。
- `tests/wakeup.rs` 在 CI 负载下可能超时（#2932）。

## 升级

`latest` 通道的 `miao` 会自动更新；否则重新执行安装命令。
