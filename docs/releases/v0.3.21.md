# miao v0.3.21

v0.3.21 arms automatic compaction for custom providers: a Session on a provider the catalog does not know (for example a Volcengine Ark route declared in `miao.jsonc`) now takes its window from the operator's own `providers.<id>.models.<model>.limit.context`, so it compacts before the provider refuses the turn instead of growing to the hard limit.

## Engine

- **The compaction window follows the operator's provider config (#1886).** A custom provider is invisible to the models.dev catalog, so `contextLimits` was never derived and auto-compaction stayed off — Sessions on such a route grew until the provider answered `Input exceeds the context limit (1048568 tokens)`. `engineSettings` now reads the declared limit and derives the same ratio/headroom the catalog path uses; an explicit `engine.context_limits` still wins.
- **The overflow retry it complements already ships in v0.3.20:** a summarizer that itself overflows is retried once against a hard-truncated body, so a Session parked at the boundary recovers instead of looping.
