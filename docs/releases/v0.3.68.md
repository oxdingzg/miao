# miao v0.3.68

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.68.zh.md)

v0.3.68 turns the built-in code index on for everyone, mirrors release downloads, and fixes a proxy edge that could keep the engine from its own loopback server.

## The code index is on by default (#2955)

Enabling it needed a line of configuration, which meant most people who upgraded never got the feature at all. It is now on unless you say otherwise:

- Absent configuration means enabled; `MIAO_CODEGRAPH=0` turns it off for one run and `"codegraph": { "enabled": false }` for a machine or a workspace.
- Cost of the default: one store file beside the engine's own and a few seconds of indexing on the first call in a workspace, spread under a per-call budget; the answer says when the index was still partial.
- Why it is worth the default: on one task, two runs per arm, same model — input tokens -32%, provider turns -33%, tool calls -27%, identical answer correctness.

The four tools are unchanged: `codegraph_explore`, `codegraph_node`, `codegraph_callers`, `codegraph_status`, across 41 languages and single-file components.

## Release downloads have a mirror (#2946)

`install` and self-update can fetch from `dl.mtty.dev` when the GitHub release host is slow or unreachable, and a failed mirror probe no longer aborts the installer (#2950).

## The engine reaches its own loopback server (#2947)

With a global `HTTP_PROXY` set, the engine now talks to its loopback sidecar directly instead of sending that traffic through the proxy.

## Smaller fixes

- `miao status` counts an untracked file's lines toward the additions it reports (#2954).
- Engine formatting and lint gates are clean again (#2956), and the Windows TUI leg's `needless_bool` is fixed (#2960).
- Test hygiene: the monitor fixture commands have Windows equivalents (#2958), the busy-retry test closes its second connection (#2949), and the heal-notice assertion no longer depends on JSON formatting (#2953).

## Known issues

- `tests/web.rs` still overflows the stack on Windows in `runtime_fetch_waits_for_bound_controller_approval_before_any_http_request`; 64 MB of stack does not help, so it is unbounded recursion that needs a stack dump (#2926).
- A paused autonomous goal can restart itself from its own pause notice (#2948); the fix is to persist the loop gate in session state.

## Upgrading

`miao` on the `latest` channel updates itself; otherwise re-run the installer.
