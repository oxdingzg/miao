## [0.1.16] - 2026-10-06

### 新增

- **core**：将已配置 linter 的失败信息返回给 edit 和 write 工具，让模型根据检查结果继续修正（#276）。

### 修复

- **core**：数据库被其他进程占用时，按实际经过时间限制启动重试，避免 SQLite 内部等待将预算放大到数分钟。启动会在几秒内提示关闭其他窗口，并且不会抢占正在执行的会话（#280）。

首次切换到窗口生命周期架构仍需关闭使用同一数据库的旧窗口，完成数据库迁移。`miao runtime status` 已随常驻服务管理命令移除。
