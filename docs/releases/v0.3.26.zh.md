# miao v0.3.26

v0.3.26 让 Rust 引擎成为能同时容纳多个对话的运行时：Session 之间现在可以互
相留下持久化的邮件，发布物也从"脚本包着一个构建目录"变成每个平台一个原生二
进制。其余篇幅花在操作者能感知的地方——用量能加成一个数、宽终端下 TUI 布局
不再散架、引擎不再为了回答简单问题而遍历日志。

## 引擎与上下文

- **Session 间消息（#2310）。** 一次 turn 可以调用 `send_message`，邮件落到
  对端的持久化收件箱并带署名（"Message from Session a"），对端因此能分清邻
  居的请求和操作者的指示。授权按目标逐个配置，`wake: never` 只投递不唤起，
  被拒绝的目标收不到任何东西。
- **启动时选择计费凭据（#2307）。** 每次启动选定使用的存储凭据；fork 用其请
  求的历史水位上的账户，账户变更不会把 agent 默认值提升成显式的模型 pin。
- **目录不再遍历日志。** Session 列表在单个事务里回答（#2306），事件类型建了
  索引，启动恢复和目录不再逐行扫描（#2300、#2326）。
- **存储锁会报出持有者（#2296）。** 竞争者等待有上界，错误信息说明锁在谁手
  里，而不是永远阻塞。
- **其他修整：** 从零创建的数据库会归还空闲页（#2269），切换途中打开的权限库
  会重试（#2279），children 的回答按其本来的对象读取（#2313）。
- **宿主插件钩子桥已删除（#2316）。** 路由与权限来自产品配置，原生路径是唯
  一路径。
- **命名权留在宿主（#2293）。** 引擎不再从首个 prompt 派生标题——命名由宿主
  的标题模型负责。没有宿主标题模型的 TUI 自己用首个 prompt 给新 Session 命名
  （#2294）。

## 用量与成本

- **一次运行一个数。** CLI 把一次运行的成本汇总成单个 `usage_total` 事件
  （#2312），benchmark 会展示它（#2311）。
- **委派工作计入账单。** 服务端报告一个 Session 的委派工作成本（#2308），并
  把辅助 provider 调用——压缩、标题、后台 turn——单独归入 `auxiliary` 组
  （#2339）；client 类型已为其重新生成（#2342）。

## TUI

- **正文占满窗口。** 侧栏贴住右缘，正文占下其余全部（#2291、#2340）；正文按
  该列换行而不是既封顶又居中（#2285），输入框坐在同一列里（#2286、#2337），
  落地列表横跨窗口，状态行与正文对齐（#2295）。
- **有层级，而不是一片灰（#2314）。** 侧栏的 todo 文本调成与正文一致的弱化色
  （#2346）；标签页标题按显示单元格而非字符截断，中日韩标题不再溢出（#2341）。
- **流式输出时输入照常回显（#2320）。** 每批只绘制一次帧，输出滚屏时输入框跟
  得上。
- **Escape 能回应待决的批准（#2343）。** 引擎已不再持有的批准不会再锁死键盘：
  Escape 像其他键一样送达面板。
- **零碎修补：** 粘贴的路径会被读取而不是当文本发送（#2282），复制选区而不是
  只复制最后一条回答（#2277），复制宽字符后不再留缝（#2330），组合键从实际键
  位表读取（#2302），临时提示会过期（#2284），正文停止跟随时有提示（#2283），
  注入的上下文画成注释而不是操作者 prompt（#2309），`--attach` 打开操作者指定
  的 Session（#2301），侧栏的标题与时间与 Session 保持同步（#2303），首页列表
  每个 Session 一行、按单元格截断（#2288、#2289）。

## 发布与打包

- **每个平台一个原生构建物（#2334）。** 发布物把原生二进制与引擎一起发布
  （#2315），每条构建线在其产出所在处对构建物做冒烟（#2331、#2335），打包错
  误由造成它的那条线自己暴露。

## CI 与测试

- **断言读屏幕，而不是字节流（#2317、#2323、#2345）。** 重绘会把单元格切成由
  光标移动分隔的片段，匹配原始字节流等于把断言押在帧差异上；交互套件现在重建
  终端画面，布局改动不再让"碰巧倒霉"的断言变红。
- **夹具把 Session 放在运行时会放的位置（#2344）。** 消息测试一边规范化路径
  一边不规范化，只有 Linux 能容忍；macOS 与 Windows 因为一个路径写法把放置判
  成冲突。
