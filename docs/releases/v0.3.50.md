# miao v0.3.50

v0.3.50 makes two things the operator had already done actually take effect: a
message left queued when the engine restarted now runs, and a changed diff row
reads as a block instead of a streak of coloured text.

## A restart sends the message it left queued (#2720)

- **Queued input no longer waits for an unrelated event.** The engine promotes
  queued input only at a boundary a client asks for, and a Session opened after a
  restart still held a message the operator had already sent with nothing left to
  promote it. The composer showed it queued while nothing ran, and a second
  prompt — or an interrupt and a resend — was what finally started it. Opening
  such a Session now asks the engine to send what is waiting, once per open, and
  only while no turn is running.
- **No silent retry of provider work.** The wake drains still-pending durable
  input only. The turn that was interrupted is not resumed, so opening a Session
  never starts a second provider call behind the operator's back.

## A changed diff row is a block (#2719)

- **The row carries the change, not only the marker.** Added and removed rows
  used to take the change's colour on the `+`/`-` glyph alone, so the eye had to
  find the edge of every change line by line. The row now carries it: the theme
  mixes the change's hue into the canvas at one quarter, and the row is padded so
  the block's right edge is straight.
- **Derived from the theme, not a second table.** Every builtin theme, a light
  canvas and a custom `themes/*.json` follow the same rule, and a colourless
  terminal (`NO_COLOR`, `TERM=dumb`) keeps the tint off the way it keeps every
  other colour off.
