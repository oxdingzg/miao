# miao v0.2.21

本版修复终端界面卡成几行文字残片的问题，并让 iOS 每张电脑卡片上的 × 真正移除对应电脑，而不是关闭侧栏。

## 修复

- **终端文本缓冲区耗尽**：即使已限制同时挂载的消息数量，密集富文本仍可能耗尽 OpenTUI 固定容量的原生对象表。现在富文本共用保守的资源预算；超出预算时显示完整原文，不截断内容。如果原生分配仍失败，界面会正常拆卸，并打印重新打开已保存会话的命令，不再尝试用同样耗尽的资源绘制错误界面（#1188）。
- **iOS 电脑移除**：每张电脑卡片上的 × 现在会确认并移除对应的本机条目。移除状态跨刷新、App 重启和之后的登录保留，后台目录发现不会再悄悄加回。重新扫码配对或点击“连接我的电脑”可恢复这些电脑。侧栏另有独立的关闭按钮；移除本机条目不会停止电脑上的任务（#1187）。
- **会话迁移命令**：修复 `session migrate` 的完整命令执行流程（#1184）。

## 引擎

- 过期凭据错误携带标准化身份，并触发所属凭据代理刷新（#1182、#1183）。
- 支持激活原生迁移包，并将 worktree 桥接工具接入迁移协调器和产品工具传输（#1175、#1177、#1178）。
- 插件工具钩子可反向分发到宿主（#1180）。

## 验证范围

两项界面修复均通过完整 CI 后合入。TUI 验证包括 44 项本地相关测试、类型检查、lint 和 Windows 验证版编译；回归测试覆盖密集 Markdown、完整原文保留、流式更新和释放，以及在独立进程中真正耗尽原生对象表后验证渲染器正常退出。iOS 验证包括移除状态持久化及原生 App 连接真实 Runtime 的测试。

## 更新方式

CLI 和 iOS App 使用独立分发渠道。终端修复通过安装 v0.2.21 获取；电脑卡片修复请通过 TestFlight 更新 iOS App。已有对话记录保留。
