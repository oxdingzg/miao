# miao v0.3.24

v0.3.24 fixes the four things that made long sessions feel broken: the engine
restarting looked like a crash, a provider with only a saved credential could
not be routed, a truncated stream discarded the whole turn's answer, and the
Rust TUI's home list buried the newest work under sheets of preview text.

## Engine

- **A clean engine exit is a restart, not a failure (#2028, #2040).** The engine
  exits 0 after refreshing its project copy and expects to be respawned on the
  next request. Both the Rust and TypeScript clients reported that as
  `engine_closed` and painted it over the Session; a clean exit now marks the
  client for respawn and says so in one line, while non-zero exits keep the
  existing diagnostic (stderr tail, `Error: Busy` classification).
- **A provider that only has a saved credential is routed (#2033).** A provider
  added through the providers UI stores a credential but has no registered
  integration, so route preparation produced no route for it and every Session
  pinned to it was rejected with `Model is not in the native host route
  catalog`. Route preparation now falls back to the saved credential, and that
  error names the model and the reason.
- **Provider HTTP failures name the provider's own reason (#2034).**
  `provider HTTP 500` now carries a bounded body excerpt and `Retry-After` when
  the status is a rate limit or a server failure.
- **Automatic compaction runs on a conservative default window (#2046).** A
  provider with no declared context window used to switch the trigger off
  entirely, so context grew until the model refused. Unknown windows now run on
  131,072 tokens, and a provider-side context rejection triggers a compaction
  checkpoint.

## TUI

- **The transcript follows the newest turn again (#2022).** A scroll used to
  leave every Session opened afterwards parked at its oldest rows; opening now
  follows, and scrolling back to the last row re-attaches.
- **The home list opens at the newest ten (#2022)**, with space revealing ten
  more and the hint line reporting how many rows stay folded away. Row previews
  are one clipped line, ages align by display width, and the redundant
  workspace/branch/version row is gone.

## CI

- Three legs were sharded (engine ubuntu, integration, blackbox) and a
  macOS-runner disk guard added (#2037); macOS legs now run on push to `main`
  and nightly rather than on pull requests (#2048), because the self-hosted
  runner was unreliable and turned every PR red for reasons unrelated to its
  change.
- Every push to `main` gets its own run instead of cancelling the previous one
  (#1930), and `crates/miao-tui/Cargo.lock` records its `libc` dependency so
  `--locked` release builds succeed (#1938).
