# miao v0.2.21

This release fixes the terminal interface getting stuck on a few text fragments and makes each iOS computer-card × remove the selected computer instead of closing the drawer.

## Fixed

- **Terminal text-buffer exhaustion**: dense rich Markdown can consume OpenTUI's fixed-capacity native object table even when the number of mounted messages is bounded. Rich Markdown now shares a conservative resource budget; over-budget content stays fully readable as plain source, without truncation. If a native allocation still fails, the interface tears down and prints a command to reopen the saved session instead of trying to allocate another rich error screen (#1188).
- **iOS computer removal**: each computer-card × now confirms and removes that specific local entry. Removal survives refresh, app restart and later sign-in, so background directory discovery cannot silently add the computer back. Explicit QR pairing or “Connect My Computers” restores removed computers. A separate control closes the drawer; removing a local entry does not stop tasks on the computer (#1187).
- **Session migration CLI**: `session migrate` is runnable end to end (#1184).

## Engine

- Expired-credential errors carry normalized identity and trigger refresh through the owning credential broker (#1182, #1183).
- Native move bundles can be activated, and worktree bridge tools are wired through the move coordinator and product-tool transport (#1175, #1177, #1178).
- Plugin tool hooks dispatch back to the host (#1180).

## Verification

Both interface fixes passed full CI before merging. TUI validation includes 44 related local tests, type checking, lint and a Windows verification build. Regression coverage includes dense Markdown, complete source retention, streaming updates and cleanup, plus a child process that genuinely exhausts the native object table and verifies renderer teardown without a rich crash screen. iOS coverage includes persistent removal and native-app tests against a real Runtime.

## Updating

The CLI and iOS app have separate distribution channels. Install v0.2.21 for the terminal fix, and update the iOS app through TestFlight for the computer-card fix. Existing conversation history is retained.
