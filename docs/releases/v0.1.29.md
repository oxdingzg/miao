## [0.1.29] - 2026-10-09

### Remote control

- One tap connects every same-account computer: an already-enrolled device reuses its accepted trust, and a fresh device asks the computer for the same-account auto-admission the owner has enabled (#487). A trusted browser account can also enroll the phone from the browser flow (#482).
- A cold launch now reconnects the selected computer. The scene used to register the phase captured when its task started, so a launch that raced the transition from inactive to active could sit in the idle state until the next background/foreground cycle (#487).

### TUI

- User messages carry a `❯` prompt glyph and one more line of separation, so a run of inputs no longer reads as one stack of identical blocks (#489).
- Scrolling the transcript no longer strands the viewport off the mounted window. When nothing overlaps, the window moves under the viewport in one step instead of stepping toward it, which had left the session view blank until it was reopened (#488).
- A title generated beside the first provider turn no longer reverts to the default in the session list, and a rename lands again at the turn's idle boundary (#485).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes.

### Distribution notes

Windows binaries are currently unsigned.
