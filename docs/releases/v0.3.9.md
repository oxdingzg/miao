# miao v0.3.9

v0.3.9 is a maintenance release on the road to the single kernel: the engine learns to read the product's own configuration files, and the two failure modes that kept Sessions unnamed — a swallowed title-model error and an endlessly retried dead model — are now visible, bounded and self-healing.

## Engine

- **The engine reads the product config files (S5 step 1).** `miao.json` discovery — JSONC comments and trailing commas included, later directories winning by precedence — now runs inside the engine (`config_scope`), with merge rules matching the product's whole-key replacement per section. This is the first half of S5; the TS side still passes directory and environment, and the temporary `product-*.json` materialization goes away in the next step.
- **A file mutation's diff reaches the transcript.** An edit whose diff was computed engine-side no longer disappears between the tool result and the product projection.
- **A Session absent from its storage is reported as absent.** A missing engine Session surfaced as a generic conflict; consumers can now tell "not there" from "broken".
- **A transport failure keeps its cause.** A routed endpoint failure wrapped the underlying error so thoroughly that the availability layer misread it as a malformed request; the wrapper now stays readable.

## Product

- **Title generation tells the truth and stops beating dead models.** Native Session naming retried a failing model on every idle transition and swallowed the provider error, so a Session kept its `New session - …` placeholder with only an `exhausted its model candidates` warning. Each candidate's real failure is now logged (model and error, timeouts separated from rejections), a plan-excluded or unknown model is remembered and skipped (generic rate limits stay retryable), and the idle pump backs off exponentially instead of once a minute. Sessions whose plan rejects the catalog's small model — the zhipuai `glm-5.3-highspeed` case — fall back to the Session's own model after one rejection, so titles appear where they never did before. Existing placeholder Sessions pick up a title automatically on a later idle transition once the blocking condition (for example the Google quota window) clears.

## Platform

- **A Location whose directory is gone is skipped, not warned about.** Scanning no longer litters the log for worktrees that were deleted out from under the product.

## Docs

- The Phase 3 design (ratatui TUI unification, slices T1–T11) and the settled S2 reader path are part of the spec set.
