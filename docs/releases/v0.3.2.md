# miao v0.3.2

[简体中文](https://github.com/oxdingzg/miao/blob/v0.3.2/docs/releases/v0.3.2.zh.md)

This release aligns native model/account selection with actual requests, improves progress readability, and fixes OAuth recovery, snapshots, preview installation and multi-window startup.

## Improvements and fixes

- **One status row** shows the selected model, remaining context, directory, Git branch, agent activity and command shortcut. Narrow terminals keep the model/context first; measured native estimates carry `~` and unknown data does not invent percentages (#1348).
- **The first native request uses the chosen model, account and variant.** Existing-session retries preserve their binding. Provider filters, account labels and per-session account selection use the engine's logical route identities (#1344, #1347).
- **Google account OAuth works through the native chat bridge**, exposes only models discovered for that account, and refreshes expired credentials through the owning broker. Recovery uses the native inbox, skips historical failures and bounds repeated attempts (#1345, #1350).
- **Readable progress** includes concise updates, provider-authored thought summaries and actual tool names. Tool-only steps no longer repeat a final-answer model footer. Command previews show six lines and mark nonzero exits/timeouts; missing timing no longer claims `Thought for 0ms` (#1349, #1353).
- **Prompt receipt deadlines** separate preparation from admission, retain one durable message ID across transport retries, and show elapsed waiting time (#1352).
- **Snapshot recording** uses validated tool paths, fixing `invalid snapshot path` for absolute paths inside the workspace (#1342).
- **Native titles and LSP diagnostics** remain consistent across product and engine state. Cold-start diagnostics wait after provisional empty pushes and report a missing analysis explicitly (#1337, #1343, #1346).
- **Multi-window startup** retries the shared SQLite lock handoff asynchronously and can recover shared usage after a failed exclusive upgrade (#1355).
- **Preview builds retain their matching native engine**, preferred over the stable engine and preserved during rollback. Install both with `./script/install-local.sh --binary /path/to/miao --engine-binary /path/to/miao-engine` (#1356).
- **CI** preserves checks for each main commit instead of cancelling them when another merge lands. Optional issue-model checks require explicit credentials and model configuration (#1351, #1354).
- Native shell timeout projection uses the engine's actual timeout reason (#1338).

## Validation

The repair audit inspected 20 retained native-engine SQLite databases containing 32 historical failures, including verification sessions. Stable/native database integrity checks pass. Historical HTTP 400 entries without response bodies cannot be reconstructed; provider error summaries are now retained.

A naturally expired real Google credential refreshed successfully. The selected Gemini model answered the first native request, and an isolated client/engine restart preserved the exact transcript, model binding and subsequent conversational recall. A controlled real-engine test also verifies mid-session expiry and native continuation without engine credential writes.

Windows hardware passed 21 ownership/storage tests and ten consecutive concurrent-startup stress runs. A real HTTP receipt delayed beyond ten seconds passes. Discovery/installer tests cover engine pairing, retained builds, rollback and version-mismatch rejection; wide/narrow terminal checks verify the single status row.

Actual provider balance exhaustion and network failures remain external errors. Requests use the selected route, and ambiguous outcomes are not automatically replayed.
