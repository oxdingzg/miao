# miao v0.2.19

This release fixes the run TUI exit command regression, explains provider 400 rejections that are really context-overflow rejections, and keeps background subagents observable while they run silently.

## Run TUI

- Typing `exit`, `quit`, `:q`, `/exit`, or `/quit` at the prompt exits again. The rewritten run TUI only accepted the slashed forms, so plain `exit` was submitted to the model as a chat message (#1160).

## Provider errors

- When a provider rejects a request with HTTP 400 and the request's estimated size exceeds the selected model's declared context window, the terminal error now names both counts — for example `The request carried about 600k input tokens against this model's 128k-token context window; compact the session or switch to a model with a larger context.` Previously such a gateway rejection (an `invalid parameter` body with no capacity wording) read like a defect elsewhere in the request (#1164).

## Background subagents

- A background subagent that produces no events is now announced at half its silence window: the parent holds one progress note naming the deadline, so a slow-but-alive child is distinguishable from a hung one while it still runs. When the silence limit does interrupt it, the failure report carries what the child had already completed, for example `It had completed 3 tool calls (last: Bash) before stopping.` The foreground `task` tool gains the same progress note and the same completed-work summary in its failure message (#1165).

## Engine

- Native sessions now apply product authority end to end (#1159).

## Verification

Each change landed through its own pull request with full CI (#1160, #1164, #1165, #1159): TypeScript type checks, the session runner suite including the new silence and oversize tests, and platform builds. The plain-`exit` behavior was additionally verified against the released 0.2.17 and 0.2.18 builds to confirm the regression window.
