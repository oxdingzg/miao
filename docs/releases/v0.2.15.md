# [0.2.15] - 2026-10-18

miao 0.2.15 completes the native (Rust) engine build-out. A session placed on
the engine now carries the full daily-coding surface: product-level tools
through a reverse bridge, trusted model routing end to end, cross-process
timers, incremental tool progress, hardened MCP, ambient context, and
declarative provider routes.

### Added

- **Product-tool reverse bridge**: native sessions register host-supplied
  product tools (`send_message`, `push_notification`, `workflow`, …) and
  reverse-dispatch execution to the server over the engine's stdio bridge;
  replies settle as durable, model-visible tool results (#1027).
- **Declarative provider manifests**: Azure (`api-key` header + `api-version`
  query) and Vertex-Anthropic (bearer + `rawPredict`) model routes are now
  configuration, not code — any base-url provider or gateway is a route
  manifest (#1026).
- **Monitor tool**: run a shell command in the background and stream matching
  stdout lines as filtered, batched notices, on the jobs lifecycle (#1025).
- **Timers across restarts**: durable timers are adopted on restart with
  process re-arm, a heartbeat-owned lease, and a supervisor sweep that
  re-owns engines holding timer sessions (#1021, #1022, #1023).
- **Incremental tool progress**: process tools stream `tool.started` and
  `tool.progress` checkpoints, and cascade cancel settles the run as one
  path (#1019).
- **MCP hardening**: deterministic catalogs refresh on `list_changed`
  notifications; HTTP servers gain Streamable HTTP and OAuth refresh grants
  (#1018, #1014, #983).
- **Trusted model routing end to end**: host manifests feed the engine
  catalog, the product API exposes the routes, and the TUI selects and
  persists them per session (#999, #1016, #1001, #1002, #971).
- **Ambient context and hooks**: product instructions, skills, and references
  map into host-owned manifests, with nested-instruction discovery and
  product hooks configuration (#1008, #995, #972, #996, #1020).
- **Native web tools**: permission-aware webfetch and websearch in the
  engine (#975).
- **Knowledge sharing**: source-bound workspace knowledge with invalidation,
  shared between core and the engine (#1003, #977).
- **Recovery surface**: recovery decisions exposed through the API and TUI,
  with explicit unknown-tool recovery admission (#974, #968).
- **Responses WebSockets**: session-scoped connections with strict deltas,
  and fork cache affinity without shared ownership (#970, #1005).
- **Provider accounts**: TUI account management, config-selected accounts,
  and per-session account pinning (#976, #984, #990).
- **iOS**: the conversation becomes the home screen with a collapsible
  session drawer (#1010).

### Fixed

- Knowledge tool result values are narrowed before parse (#1024).
- Read-batch executor ownership and bounded prefixes survive mixed tool
  turns (#986).
- The long-task provider turn budget is configurable (#978).
- Auxiliary provider usage is accounted for and covered (#973).
- Background jobs run under a concurrency permit (#994).
- Credential refresh is honored before token expiry, and the daemon-owned
  guard is scoped to the account being replaced (#979, #980).
- A stalled tool-argument stream is replayed instead of ending the turn
  (#981).
- Provider retries pause for as long as the provider asked, and Responses
  cache writes are accounted (#992, #957).
