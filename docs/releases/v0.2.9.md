## [0.2.9] - 2026-10-15

miao 0.2.9 is the engine release: the native engine gained the editing,
reading, context, and delegation behaviour the baseline suite measures, the
product now settles its steps with the engine's own usage evidence, and macOS
builds are codesigned and notarized.

### Added

- **engine**: editing recovers instead of failing. A stale edit is rebased onto
  the file the model last read, its snapshots are anchored, and drift can be
  injected to exercise the path. `edit_file` also accepts a concise `anchor` and
  `new_text` beside the exact-match pair (#804, #805, #823).
- **engine**: large files are readable in windows (`offset`, `limit`), oversized
  reads explain themselves instead of failing opaquely, and the frozen suite
  carries large-file, multi-line, and typed-repair carriers (#811, #818, #815).
- **engine**: the language server warms on read and reports post-edit
  diagnostics, and a configured `--verify-command` gates a run's completion: a
  failure becomes a classified continuation and a persistent failure closes the
  run (#808, #822).
- **engine**: context management is honest about what it removes. An elided tool
  output stays recoverable by the handle its marker names, elision selection is
  budget-aware and removes the oldest output first, compaction summaries retain
  durable state and bounded inputs, and the gate is reachable from the CLI at
  last (#826, #846, #839, #851).
- **engine**: a turn's declared reads dispatch together under a bound of four and
  settle in call order, membership is declaration-driven, and each tool reports
  the window it ran in (#844, #834, #841).
- **engine**: delegation reaches the parent's archived output by reference and
  records its outcome, and purpose-role model bindings escalate once to the
  primary when a bound model fails (#843, #847, #845).
- **engine**: usage evidence carries per-turn time-to-first-token and cache
  lineage, ACP authenticate/resume/close follow the protocol honestly, and the
  prompt-cache policy is explicit (#842, #852, #827).
- **release**: macOS binaries are codesigned and notarized, and the engine binary
  ships through the release channel (#840, #854).
- **miao**: product steps settle with usage evidence from the engine journal, and
  the engine configuration maps fallback models and role bindings (#850, #848).
- **remote-control**: the default Hub's browser pairing entry ships, with an
  opt-in custom Hub (#833, #825).

### Fixed

- **engine**: an empty provider completion is classified instead of ending a run
  silently, loop classification counts land in the evidence, and a bounded
  summarizer pass means a silent provider can no longer hold a turn (#813, #814,
  #855).
- **eval**: the comparison runner forwards every ablation it declares and drives
  the engine's context limits, so a measured arm is the arm that ran (#830,
  #851).
- **llm**: streamed tool calls are finalized when the stream halts, not when a
  finish frame arrives (#836).

### Known issues

- Automatic compaction fires on the baseline carrier, but every summarizer
  request against the sweep provider stalls: eleven attempts, eleven failures and
  five breaker skips in one measured run. The bound above keeps such a turn alive
  at about 20 s per attempt; the request shape itself is still to fix (#855).

### Validation and upgrade

- The engine and evaluation work is measured on the frozen suite carried by this
  repository (edit carriers, large-file and multi-line carriers, the long-session
  carrier, and a read-batch carrier) and is pinned by the engine, evaluation, and
  blackbox suites; the whole set passed on all three platforms for every pull
  request above.
- Upgrade through the usual `miao` auto-update channel, or use the repository
  installer.
