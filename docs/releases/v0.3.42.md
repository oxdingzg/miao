# miao v0.3.42

v0.3.42 finishes the landing strip that 0.3.41 introduced.

## The launcher reads the model this machine already uses

- **The landing strip falls back to the newest Session's model (#2562).** 0.3.41
  named the operator's last pick, which left an install that never made one
  blank — the common case, because the model was chosen in Sessions that
  already exist. The strip now reads the newest Session's model (the same
  newest-first order `--continue` uses) and resolves a route id against the
  catalog's model key, so the launch screen shows what the next prompt will
  actually run on.
