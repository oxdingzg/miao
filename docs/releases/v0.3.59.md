# miao v0.3.59

v0.3.59 turns the sidebar into the session's command center and finishes the
background-job story: per-model spend and context-window occupancy at a
glance, cron and wakeup schedules you can edit, a confirmation-guarded stop
for every background job, and a transcript that speaks PowerShell and Astro.

## The sidebar shows where your context and money go (#2800)

- **Context-window occupancy at a glance.** The Context section now paints the
  session's share of the model window, so "how full am I" no longer requires
  opening the status dialog.
- **Per-model spend on its own rows.** Every model that served the session
  keeps its own lineage row (#2736), and spend now follows the same split —
  a switch is visible in both the model name and the money.

## Schedules you can edit (#2792, JOB-05)

- **Editable, displayable cron and wakeup schedules.** The schedules dialog
  lists what is armed and opens each entry for editing — pattern, delivery and
  recurrence are no longer write-only.
- **A stop gate for the whole list (#2791, JOB-02).** Stopping every background
  job asks first, names what stops, and the reopened list shows the true state
  the engine holds — including the output tail a stopped job produced.

## A transcript that speaks more languages (#2799, #2801)

- **PowerShell and Astro join the grammar set**, and the diff band keeps the
  product's green and red all the way to the row edge (#2783) — the tint no
  longer fades into the panel mid-block.

## Safer defaults (#2798)

- **Automatic compaction arms on the default model** for a Session, so a
  session created before any explicit model choice still gets the context
  ladder and never runs unbounded past the window.
