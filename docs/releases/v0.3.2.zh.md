# miao v0.3.2

[English](https://github.com/oxdingzg/miao/blob/v0.3.2/docs/releases/v0.3.2.md)

本版本统一原生模型/账号选择与实际请求，改善过程可读性，并修复 OAuth 恢复、快照、预览安装和多窗口启动。

## 改进与修复

- **一条常驻状态栏**集中显示模型、剩余上下文、目录、Git 分支、Agent 活动和命令快捷键。窄终端优先保留模型与上下文；原生用量估算带 `~`，未知数据不伪造百分比（#1348）。
- **首次原生请求使用选中的模型、账号和 variant**，已有会话重试保留原绑定。供应商筛选、账号标签和会话内账号选择采用引擎发布的逻辑路由身份（#1344、#1347）。
- **Google 账号 OAuth 可通过原生 Chat 桥接调用**，只展示账号发现的模型。过期后由所属刷新器更新原账号，再通过原生 inbox 恢复任务；不因历史失败重放触发恢复，也不无限重试（#1345、#1350）。
- **执行过程更可读**：提供必要的进展说明、服务端生成的思考摘要和真实工具名。工具步骤不再重复最终回答的模型页脚；命令默认预览六行输出，明确标识非零退出与超时；缺失时间不再显示 `Thought for 0ms`（#1349、#1353）。
- **发送回执超时**将准备与入队分开计时，传输重试保留同一消息 ID，等待首个回执时显示耗时（#1352）。
- **文件快照**使用工具校验后的资源路径，修复工作区内绝对路径触发的 `invalid snapshot path`（#1342）。
- **标题与 LSP 诊断**保持产品、引擎状态一致。诊断冷启动在首个空推送后继续有界等待；从未收到分析结果时明确报错（#1337、#1343、#1346）。
- **多窗口启动**对 SQLite 共享锁交接进行有界异步重试，排他升级失败后可重新取得共享锁（#1355）。
- **预览版保留配套原生引擎**，优先使用它，并在回滚时一并保留。安装命令：`./script/install-local.sh --binary /path/to/miao --engine-binary /path/to/miao-engine`（#1356）。
- **CI**按 main 提交隔离检查，避免后续合并取消旧提交的检查。可选 Issue 模型检查必须显式配置凭证与模型（#1351、#1354）。
- 原生 shell 超时按引擎实际原因投影（#1338）。

## 验证

已核对本机保留的 20 个原生 SQLite 数据库、32 条历史运行失败（包含验证会话），稳定版与原生数据库完整性检查通过。早期未保留响应正文的 HTTP 400 无法事后还原原因；现在会保留供应商错误摘要。

真实 Google 账号自然过期后自动刷新，原生会话选定 Gemini 后首次请求成功。隔离关闭客户端与引擎后重新启动，完整消息、模型绑定及后续对话记忆均保留。受控真实引擎测试另验证中途过期恢复，Rust 引擎不写凭证。

Windows 实机通过 21 项所有权/存储检查及连续 10 轮并发启动压力测试。真实 HTTP 超过十秒才返回的回执验证通过。安装测试覆盖引擎配对、版本保留、回滚与版本不匹配拒绝；宽窄终端均检查单行状态栏。

真实余额不足和网络失败仍属于外部错误；请求使用界面选定的路由，不会自动重放结果不确定的请求。
