# miao v0.3.53

v0.3.53 makes the transcript's tool rows readable. A `task_list` used to paint
its whole serialized result — including every finished child's full report — as
one wall of JSON, and the same fall-through swallowed `task_result`,
`session_state`, `goal`, the schedule family, the job family and
`worktree_list`.

## Tool rows read as rows (#2733)

- **One line per item, never the ledger.** `task_list` now reads
  `[✓] close #1974 · completed` per background child, with a header counting
  tasks and how many are running. `task_result` names the task in its header and
  shows the child's report as the body. Session state paints the checklist and
  the goal, schedules show pattern and fire counters, jobs show command and
  state, worktrees show branch and path.
- **A changed diff row keeps its syntax colours.** 0.3.51's block flattened the
  row into one hue and the operator lost keyword colouring entirely; the scanner
  now colours the code inside the product's diff block, the way a fenced snippet
  does.
- **The sidebar's model follows the picker.** Choosing a model repaints the
  Session summary's pin at once instead of waiting for the engine's next
  projection.
