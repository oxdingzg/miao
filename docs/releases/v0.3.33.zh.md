# miao v0.3.33

v0.3.33 让完成的回合一行读完,让每一轮按 provider 自己的币种计价,并让首页
接受粘贴。

## 完成的回合一行读完

- **Claude Code 式折叠 (#2519)。** 以前一个完成的回合把每条工具行和各自的
  thinking 头一路平铺下来。现在它收敛为 prose 之上的一行摘要——
  `Thought for 1m 43s, searched for 2 patterns, ran 11 shell commands`——
  reasoning 耗时在回合的各段 thinking 之间累加,工具按类型计数(patterns、
  files、shell commands,其余归并)。散文保留在摘要之后,用户消息的
  `[Image #N]` 附件以 Claude 画的树形列出(`├─ [Image #28]`、
  `└─ [Image #29]`),回合进行中时仍在 draft 区实时流式显示——最后一组
  保持动态。

## 按记账币种计价

- **每轮按 provider 自己的币种计价 (#2518)。** 跨两个 provider 的运行以前
  会把美元和人民币直接相加。成本汇总现在按币种分桶并报告拆分
  (`byCurrency`),混合运行能读出每个 provider 实际记了多少钱。
- **钩子耗时与失败计入任务报告 (#2509、#2517)。** usage 报告点名每一次
  hook 调用,统计钩子花费的时间与抛出的失败,慢在哪一步、是不是钩子拖的,
  有据可查。

## 首页接受粘贴

- **往启动页粘贴文本和图片 (#2515)。** 以前粘贴落在首页时无处可去。现在
  composer 接收它,图片也收。

## 挂载的 MCP 服务可以接 websearch

- **`SearchConfig::mcp` 选择目录别名 (#2521)。** `websearch` 以前只认 REST
  provider 的词汇,搜索藏在 MCP 服务后面的部署无从使用。现在 web 客户端通过
  该服务自己的搜索工具作答。

## 可靠性

- **引擎失败写入 miao.log (#2507)。** 引擎崩溃或回合失败以前只记在自己的
  journal 里;miao.log 现在同样记录,用户附给报告的日志不再是半截故事。
- **Chat 回合在任一终结帧上完成 (#2504)。** 以 `response.done` 而非
  `message_stop` 收尾的 provider 流会让回合一直等下去;现在任一终结帧都能
  完成它。
- **到达即显示 (#2502)。** 投影在它消费的每一种 journal 事件上刷新:提示
  被受理就上屏,工具在跑就有行,usage 与压缩状态不再慢一拍。
- **`miao upgrade` 对失败的下载说实话 (#2500)。** 安装脚本先落盘再执行;
  下载失败会明确说明旧构建仍在原位。
