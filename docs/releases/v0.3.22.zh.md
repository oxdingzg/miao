# miao v0.3.22

v0.3.22 让 TUI 的模型/provider 选择真正可用，并让窗口跨引擎重启保持存活：引擎死掉后下一条消息即自动唤醒，普通列表边打字边过滤，窗口当前使用的绑定有明确标记。

## TUI

- **引擎死掉后，下一条消息自动唤醒（#1897）。** 请求循环此前只持有一个引擎客户端；引擎一旦退出（空闲回收、崩溃或更新时二进制被替换），之后的每个请求都返回 `engine_closed`，窗口要重启才能用。现在循环持有连接（游标与事件流跨重启保留）并惰性重连——发消息即唤起引擎并无缝回放；重启失败会以提示呈现，而不是静默死管道。
- **`/exit` 可用（#1897）。** `exit` 成为 `quit` 的别名；Ctrl+C、Ctrl+D 与 ctrl+x q 仍然可用。
- **模型、账户与主题列表支持边打字边过滤（#1898），模型列表用 `●` 标记当前会话正在使用的绑定。** 长目录变得可导航，当前绑定一眼可见。

## 引擎

- **压缩窗口跟随操作者的 provider 配置（#1886）。** catalog 不认识的自定义 provider 从 `providers.<id>.models.<model>.limit.context` 取窗口，自动压缩在这些路由上得以武装，而不是让会话一路增长到 provider 拒绝请求。它与 v0.3.20 发出的紧急截断互补。
