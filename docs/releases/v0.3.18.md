# miao v0.3.18

v0.3.18 keeps the terminal steady while a turn runs, makes opencode-go work from the native engine, and lands the first slices of the shared permission authority. Upgrade and start `miao` as before; nothing here needs a configuration change.

## TUI

- **Submitting while a turn runs (#1842).** `ctrl+enter` submits immediately instead of waiting for the running turn to finish, and queued prompts now show their count in the composer and the status line (#1836).
- **The terminal keeps its size and its title (#1840, #1839).** Console size changes on Windows settle without leaving a stale frame, and the terminal title carries a liveness marker while a run is in flight, still honoring `MIAO_DISABLE_TERMINAL_TITLE`.
- **Shell job control returns the terminal to the TUI (#1823).** Suspending and resuming a job no longer leaves the terminal in the child's state.

## Engine and permissions

- **opencode-go turns send their session header (#1838).** The Effect LLM path now sends `x-opencode-session` on every turn (the session id's digest, the same routing key the native transport resolves from `$session`), so the gateway no longer rejects the request with `MissingSessionID`.
- **Shared permission authority, first slices (#1761, #1762, #1763, #1765, #1766).** Source transactions, persisted Root assertions, settlement by live source ownership, completed directory handoffs, and run fencing behind those handoffs.
- **Background cancellation stays with its run (#1819).** One run's cancel can no longer tear down another run's work.

## Configuration and ACP

- **Migration keeps absent keys absent (#1835).** A key a V1 document never set no longer appears with a default after migration.
- **ACP drops the unscoped stdout rewrite (#1829)** and surfaces fixture stderr when a replay times out (#1831).

## Docs

- **The mtty gateway provider is documented (#1844).**
