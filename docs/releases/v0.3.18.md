# miao v0.3.18

v0.3.18 brings the Rust TUI's screens onto the same theme tokens as the TypeScript layout, fixes a configuration migration that silently reset a configured model, and makes two provider-stream failures explain themselves instead of ending a turn with a cryptic frame error.

## TUI

- **The sessions screen reads like the product, not a different app (#1857).** The Rust TUI already carried the theme's token set but applied it thinly: the pane border used the near-invisible `border` step and the selected row carried no chip. The sessions pane and dialog lists now use `border_active`, sit on the `surface` elevation, and draw the selected label on the `element` chip in `primary`, matching the TypeScript list selection.

## Configuration

- **A V1-shaped project config no longer resets the configured model (#1835).** `migrate()` materialized every absent field as an explicit `undefined`-valued key, and the merge treats a present key as a leaf, so a project `.miao/miao.jsonc` without `model` overrode the global default with nothing and sessions fell back to the catalog's newest (rate-limited) entry. Absence now stays absent.

## Engine

- **An 8 MiB runaway reply explains itself (#1837).** The response-stream guard's message was "message exceeds 8 MiB", surfaced as `invalid request: invalid provider stream: message exceeds 8 MiB` — reading like a malformed request. It now states that the response was discarded and the request itself was fine.
- **A gateway's nested tool-call index is accepted (#1846).** The opencode-go gateway nests the call `index` inside `function`; the parser rejected such frames as `invalid Chat Completions frame` and killed the turn. Both shapes are now understood.
- **The shared permission chain lands (#1761–#1795).** The permission engine's shared changefeed, settlement, handoff binding, run fences, source metadata, orphan cleanup, event projection, runtime activation, startup selection, managed authority, TUI selection, Windows shim, supervision, and source-transaction fence recovery all arrive as the S7/S6 shared-authority line.
