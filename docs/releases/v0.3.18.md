# miao v0.3.18

v0.3.18 fixes a configuration migration that silently reset a configured model, accepts a gateway variant that used to kill whole turns, and lands the shared permission chain (#1761–#1795).

## Configuration

- **A V1-shaped project config no longer resets the configured model (#1835).** `migrate()` materialized every absent field as an explicit `undefined`-valued key, and the merge treats a present key as a leaf, so a project `.miao/miao.jsonc` without `model` overrode the global default with nothing and sessions fell back to the catalog's newest (rate-limited) entry. Absence now stays absent.

## Engine

- **A gateway's nested tool-call index is accepted (#1846).** The opencode-go gateway nests the call `index` inside `function`; the parser rejected such frames as `invalid Chat Completions frame` and killed the turn. Both shapes are now understood.
- **The shared permission chain lands (#1761–#1795).** The permission engine's shared changefeed, settlement, handoff binding, run fences, source metadata, orphan cleanup, event projection, runtime activation, startup selection, managed authority, TUI selection, Windows shim, supervision, and source-transaction fence recovery all arrive as the S7/S6 shared-authority line.
