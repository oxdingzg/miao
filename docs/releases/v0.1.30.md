## [0.1.30] - 2026-10-09

### Fixed

- Tool schemas are now normalized at the protocol boundary, so a tool whose input schema omits a top-level `type` — or carries a top-level `anyOf`, `oneOf`, or `allOf` — no longer breaks the whole turn. Anthropic, Bedrock, and Gemini were rejecting the entire request with `tools.N.custom.input_schema.type: Field required`, which failed every message in the turn, not just calls to the offending tool. Only the OpenAI-style routes happened to normalize their schemas, so this is now enforced once for every non-Gemini route: an object-rooted schema with no top-level combinator passes through unchanged, and a top-level combinator is merged into a `properties` object with `additionalProperties: false` (#491).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes.

### Distribution notes

Windows binaries are currently unsigned.
