# miao v0.3.67

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.67.md)

v0.3.67 内置了代码索引：miao 可以直接从本地符号图回答「这个符号在哪、谁在调用它」，不必再走
「先 grep 再逐个读文件」的往返，覆盖 41 种语言与单文件组件。

## 内置代码索引（#2937）

- 四个只读工具，默认关闭。`codegraph_explore` 一次调用返回查询所命名符号的逐行原文与它们之间的
  调用路径，并说明还有哪些没有展开；`codegraph_node` 读一个文件（附带导入它的文件）或一个符号
  （附带调用者与被调用者）；`codegraph_callers` 列出调用点；`codegraph_status` 报告覆盖率。
- 索引是源码树的缓存而不是项目产物：它位于引擎存储旁 `codegraph/<工作区哈希>.db`，按 size/mtime
  增量刷新，每次调用有预算上限，且不会产生任何工作树变更。
- 开启方式：配置里写 `"codegraph": { "enabled": true }`，或单次运行用 `MIAO_CODEGRAPH=1`。
- 同一任务、每一臂跑两次、同一二进制/模型/工作区快照的实测：输入 tokens −32%，模型轮次 −33%，
  工具调用 −27%，答案正确性相同。

## 41 种语言与组件格式（#2940、#2941）

- JavaScript 系：TypeScript、TSX、JavaScript。组件与标记：Vue、Svelte、Astro（取其 `<script>`
  或 frontmatter）、HTML（取内联 `<script>`）。
- 系统语言：Rust、C、C++、Zig、Objective-C。JVM/.NET：Java、Kotlin、Scala、C#、F#。函数式：
  Elixir、Erlang、Haskell、OCaml。脚本：Python、Ruby、PHP、Lua、Shell、PowerShell。数据与科学：
  Go、Julia、R、SQL。接口与基础设施：Protobuf、GraphQL、Terraform/HCL、Solidity。其他：Dart、
  Swift、Elm、Nim、GDScript、Crystal。
- 遮罩解析保持字节偏移与行号与原文件一致，因此组件模板不会被当成代码，返回的行号就是你会读到的行。
- 跨文件解析遵循各语言自己的导入写法（相对路径、`use crate::`、点分 Python 模块、Go 包、
  `import a.b.Type`、`#include`、`source`、`alias`、`open`、`using`），并回退到同目录兄弟文件。
- 代价：语法表会让发布二进制变大（arm64 85 MB → 159 MB），全新 release 构建从约 1 分钟增到 3 分钟；
  日常增量构建不受影响。

## TUI（#2942）

- 控制台宿主报告尺寸变化时，界面会重新同步，而不是继续按旧几何绘制。

## 引擎（#2943）

- metadata-budget 用例自己拥有文件名，不再依赖宿主 PATH，因此不会随机器工具链时通时不通。

## 已知问题

- `tests/web.rs` 在 Windows 上以 `STATUS_STACK_OVERFLOW` 崩溃（#2926）。
- Windows 专属腿仍会按原因跳过无法在该平台通过的用例（#2873）。

## 升级

`latest` 渠道上的 `miao` 会自行更新；否则重跑安装脚本。
