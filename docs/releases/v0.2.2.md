## [0.2.2] - 2026-10-10

miao 0.2.2 is a patch release on the 0.2 line.

### Added

- **engine**: delegate a task to a child Session (#514), and add LSP diagnostics, definition, and references tools (#511).
- **engine**: carry inline image attachments on prompts (#509).

### Fixed

- **core**: a provider request the endpoint rejects (HTTP 400) is no longer given up on immediately. Before any output is published the turn makes one immediate extra attempt, so a 400 a gateway wraps around a transient upstream failure recovers without waiting for the user to continue; a deterministic rejection still fails, at the cost of a single replay (#510).
- **tui**: after a terminal restarts and restores its tabs, the current Session's tab re-asserts `miao | <title>` on focus or resize instead of keeping a stale title from before the restore (#512).
