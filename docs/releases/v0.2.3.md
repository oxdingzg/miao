## [0.2.3] - 2026-10-10

miao 0.2.3 improves recovery from interrupted model connections, preserves image input on compatible routes, and makes background waits visible in the terminal.

### Connection recovery

- Connection resets have a dedicated budget of up to five transport retries, with structured `llm.transport.retry` logs (#535).
- After a connection reset, HTTP requests temporarily stop reusing pooled sockets so retries establish a fresh connection (#540).
- A provider turn that drops before text or tool-call output can be retried even if reasoning has already arrived (#538). Resuming a partially delivered answer is not implemented.
- ChatGPT/Codex turns default to the pooled Responses WebSocket transport (#533).

### Images and background activity

- Preserve image input on the CommandCode route and recover from context overflow before visible output (#542).
- Show live wakeup countdowns, background-job elapsed time, queued notifications, and completion outcomes above the prompt. Timer observation is read-only; disconnected timers pause, and untracked jobs report unknown outcomes without replaying commands (#544).

### Rust engine development

- Add loopback HTTP commands and committed-event SSE, plus ACP stdio lifecycle, session listing, tool notifications, permissions, modes, and plans (#519, #520, #522, #524–#529).
- Add revert/unrevert, billed usage aggregation, skill discovery, and host-authorized read-only references (#534, #539, #543, #545, #547, #554).
- Enforce Windows AppContainer sandboxing for process tools and add the extension compatibility worker (#550, #557).
- Extend engine-to-product bridges for deterministic identities, status, admitted prompts, assistant text, tool calls/results, approvals, and questions (#555, #558–#561, #564, #568–#570, #572).
- Add engine release artifacts, manifests, a local installation/rollback script, recovery scenarios, and recorded capability/live-evaluation evidence (#536, #541, #562, #565, #566, #571).
- Recover engine requests interrupted before output and retain finalized Responses items when completion output is empty (#521, #523).

These engine changes are development infrastructure; this release does not replace the default TypeScript session runtime with the Rust engine.

### Downloads

CLI archives are published for macOS arm64/x64, Linux arm64/x64, and Windows x64. Windows binaries are currently unsigned.
