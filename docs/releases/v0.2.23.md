# miao v0.2.23

This release turns the native engine on from configuration, fixes the two failures that broke native CLI continuation and server-owned native Sessions on explicit routes, and closes the plugin and client-coverage gaps recorded in the enablement matrix.

## Highlights

- **Native engine opt-in from config**: `engine.storage` in the global config places new Sessions on the Rust engine; `MIAO_ENGINE_STORAGE` still overrides it. The installer ships the engine binary, and `miao doctor` now reports the discovered binary, its protocol/schema/version, the storage root, and warns when storage is on with no compatible binary (#1201).
- **CLI continuation fixed**: a declared reference whose path was deleted (a removed worktree or an uncloned repository) made the engine exit with `InvalidInput` before serving, so `miao run --continue` failed. Missing grants are now skipped instead of killing the child (#1202).
- **Explicit routes fixed on the server**: an explicit provider/endpoint route exposes one primary entry with no route id, and server-owned native Sessions could not bind it — every prompt failed with `Model is not in the native host route catalog`. The primary route now binds by identity, while id-qualified routes keep matching first (#1206).
- **Restart without replay**: a new real-engine acceptance test boots the server twice on the same storage and proves the transcript is durable and no settled turn is replayed — the provider receives exactly one request per prompt (#1211).
- **Downgrade guard documented**: opening a 0.2.22 store with a 0.2.15 engine refuses with `unsupported database schema version`, writes nothing, and the current engine continues afterwards — recorded with SHA-256 evidence in the rollback verification document (#1209).
- **Client coverage recorded**: slow-client backlog bounds (a paused raw TCP SSE client overflows independently while a healthy client keeps receiving), reconnection, and cursor-resume without duplicates are covered by product tests; the remaining client gap is a third-party ACP editor UI and the app transcript retype (#1208).

## Engine and platform

- Plugin `tool.definition` hooks reverse-dispatch to the host (#1198), and plugin providers without an AI SDK package map onto openai-chat routes, so native Sessions compact and route automatically (#1199, #1195).
- Delegation reports progress from native sessions (#1194); product-tool dispatch names the calling tool call and cancels pending calls on settle (#1192).
- Per-provider turns publish TTFT into per-model usage rows (#1200), and the TUI sidebar shows mean time-to-first-token (#1203).
- The installer falls back to the newest engine archive when a release lacks one (#1196).
- The Windows rollback path is accepted end to end on `windows-2025`: per-version archive extraction plus backoff retries against antivirus locks (#1204).
- Provider stream watchdogs are separated by phase (#1210), and the engine cost benchmark harness with its pilot report lands under `script/` (#1207).

## Verification

Full CI passed on every merged change, including the Windows installer upgrade/rollback suite. The two engine fixes carry real-engine regression tests (a server-owned native Session completes a turn on an explicit route; a missing reference grant is omitted), the restart acceptance runs two server generations against a deterministic provider, and the downgrade drill is recorded with byte-level hashes.

## Updating

Run the installer again, or let the running `miao` background update pick up v0.2.23 on its next check. Existing sessions, credentials and configuration are retained.
