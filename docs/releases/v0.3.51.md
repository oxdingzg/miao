# miao v0.3.51

v0.3.51 puts a changed diff row in the product's own colours. The tinted block
that 0.3.50 introduced was mixed from the theme's success and error hues, and
the code inside it kept the syntax scanner's colours — so a diff read in greens
the product never uses, with a teal string sitting inside a green row.

## A changed row wears the product's diff colours (#2722)

- **The block and its text come from the product's diff variables.** Dark
  canvases read `#1a2919` behind `#9bcd97` for additions and `#42120b` behind
  `#fc533a` for deletions; light canvases read `#e3fae1`/`#3a8437` and
  `#feefeb`/`#ed4831`. The same luminance test that picks the syntax twins picks
  the set, so a custom theme on either canvas follows without new tokens.
- **A changed row is one flat hue.** The scanner no longer colours tokens inside
  the block; an unchanged row is still code and keeps the file's own colours. A
  colourless terminal keeps the glyphs alone, as with every other colour.
