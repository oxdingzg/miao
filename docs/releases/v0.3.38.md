# miao v0.3.38

v0.3.38 makes the task list real: the model sees it, so the checklist on the right fills up.

## The task list reaches the model on every turn

- **Every model is told how to keep the checklist (#2544).** The engine
  announced durable state only once a list already existed, and the persona
  assets name `todowrite` only for Anthropic models. A session on any other
  model — DeepSeek, GPT, Gemini, Kimi — never heard of the tool, so nothing
  wrote the first list and the right-hand panel read `Todo 0/0` for whole
  sessions. The system prompt now closes with the task-list protocol (track
  multi-step work, mark `in_progress` when starting and `completed` after
  verifying, use ids with `depends_on`, say what a blocker means), and the
  recorded list keeps arriving in the per-turn state note.
- **`todowrite` reads as a planning tool.** The description now leads with
  tracking multi-step work instead of describing the storage call, which is
  what the TypeScript tool tells the model.

## The input wraps instead of scrolling sideways

- **A long draft wraps inside the box (#2540).** The composer clipped the
  caret's line at a horizontal offset while the box grew by the wrapped row
  count, so typing past the edge hid everything but the tail. It paints the
  wrapped rows now, the caret follows them, and a draft that fills a row
  exactly keeps a cell for the caret.
- **The landing prompt grows with its draft.** It was sized from the whole
  window instead of `prompt.max_width`, and added two rows on top of a height
  that already carried the borders.
- **Queued prompts are named beside the input (#2540).** A prompt sent during
  a running turn used to be a `1 queued` count in the title; the waiting
  prompts now print above the input as `❯ text · queued` (three newest, older
  ones folded into a count), where the operator typed them.

## Diagnostics that say what to do

- **Cache health recommends a fix (#2535).** `cacheDiagnostics` carries
  `recommendations` — invalid breakdown, unreported cache reads, no cache
  reads — with the counts behind each, instead of a bare `null` ratio.
- **Unknown configuration keys are named (#2534).** `config explain` gains a
  `warnings` array with the source and the closest known key, and
  `miao debug config` prints the sources, the resolved leaves and those
  warnings. The read still succeeds.

Everything else from 0.3.37 stays: the flat transcript, `ctrl+o`'s provider
fallback, the arrival contract, and the honest `miao upgrade`.
