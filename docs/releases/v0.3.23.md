# miao v0.3.23

v0.3.23 reworks the Rust TUI's three main surfaces toward the TypeScript layout: the home list groups by recency, the session sidebar shows context and todos, and the transcript folds tool output to a single readable line.

## TUI

- **Home groups sessions by day (#1903).** Today / Yesterday / This week / Earlier sections replace one flat wall of titles; times right-align as a muted column, the key cheat-sheet moved to a bottom hint line, and the header collapsed to one slim line.
- **The session sidebar is a live column (#1903).** `context` shows the serving model's lineage with in/out tokens, cache reads and turns; `todo` shows done/open counts and the list itself, projected from the engine snapshot's durable `state.todos` with ✓ ▸ ✗ · glyphs.
- **Tool output folds to one line (#1903).** A call renders as its glyph, name and one preview line, with `… N more lines · <leader>u 展开` for the rest; success output is muted so assistant prose stays primary, errors stay red.
- **Transcript and sidebar are borderless (#1903)**, matching the TypeScript layout; frames no longer steal columns from the text.
