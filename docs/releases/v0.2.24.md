# miao v0.2.24

This release is about trustworthiness of the CLI: a failed run now says so, headless runs stop leaking engine processes, the todo panel survives hostile model output, and `migrate-back` works against a real engine.

## Fixed

- **Headless failures are visible**: `miao run` whose provider turn fails (model binding rejected, provider error before the first step) used to print nothing and exit 0. The run now reports the failure event and exits non-zero (#1228).
- **Engine processes no longer leak**: every `miao run` left its `miao-engine serve` child behind — 170+ accumulated on one machine in a day and pushed it into swap. Headless runs now terminate their engine child on exit; interactive hosts keep the daemon behaviour (#1223).
- **Todo panel survives carriage returns**: model output containing bare `\r` rewound the terminal cursor and rendered the todo list one word per line. Task text is normalised at the write boundary, on read (existing rows heal), and in the transcript parser (#1226).
- **migrate-back works end to end**: the reverse delta receipt now verifies the exact bytes written; a completed forward transfer turns its audit row in place so the reverse direction can share the id; and a transferred session's projected variant binds the primary route. Verified against a real engine, forward then back, with placement flipping both ways (#1219).
- **ACP accepts provider-prefixed models** and provider run failures are surfaced instead of swallowed (#1225).

## Added

- `miao remote` signs in to a Hub account from the terminal (#1222).
- The engine's prompt cache defaults to on (#1216), and native stream watchdogs are layered by phase so one slow phase no longer trips the whole request (#1213).

## Verification

Full CI passed on every change. The migrate-back fix was verified against a real engine with forward and back legs flipping placement both ways, the headless-failure fix by two models × rust placement reproductions that now print the error and exit 1, and the engine-child fix by asserting no serve process survives a run. A widened seven-task acceptance batch (including interrupt+resume and refusal families) ran across two priced model families — see `docs/experiments/engine-cost-benchmark.md`.

## Updating

Run the installer again, or let the running `miao` background update pick up v0.2.24 on its next check. Existing sessions, credentials and configuration are retained.
