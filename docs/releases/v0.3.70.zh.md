# miao v0.3.70

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.70.md)

v0.3.70 修复 Windows 上的 `miao upgrade`：升级器现在运行 PowerShell 安装器，而不是 WSL 的 `bash` 启动器——后者让每一台没有 WSL 镜像的机器升级必挂。

## Windows 上 `miao upgrade` 可用了 (#3004)

在 Windows 上，`PATH` 里的 `bash` 指向 `C:\Windows\System32\bash.exe`——WSL 启动器——所以升级器的 `bash install` 一步在所有没有 WSL 镜像的机器上以 "no installed distribution" 失败。升级器现在下载 `install.ps1`，以 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <暂存文件> -Version <已解析版本>` 运行——这正是安装器文档化的参数形式。「先下载、后运行」的流程不变：下载失败依然绝不会执行空脚本，暂存文件在每次退出时都会清理，POSIX 路径零改动。

其余无变化：v0.3.69 以来的其它提交都是文档、测试调度与死代码清理。
