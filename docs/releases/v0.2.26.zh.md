# miao v0.2.26

本版强化 MCP 身份体系并继续补齐原生引擎:OAuth 凭证按授权服务器 issuer 分键存储,引擎新增 skill、plan、后台任务与 PDF 工具以及持久化后台作业,auto-mode 请求改由本地分类器裁决;核心修复是原生会话终于上报真实 token 成本并持久化每回合用量。

## 新增

- **按 issuer 分键的 MCP OAuth 凭证**:凭证按授权服务器 issuer 存储,并支持 CIMD client-metadata URL 与 RFC 9207 issuer 校验(#1288、#1282)。
- **原生引擎工具面**:新增 skill、plan、后台任务与 PDF 工具(#1255);`job_list`/`job_wait`(#1253);workflow 工具经 product-tool 桥执行(#1193);插件工具 hook 上报宿主(#1180)并反向分发 `tool.definition` 族(#1198);worktree 桥工具接入产品工具(#1178、#1177);native move bundle 启用(#1175)。
- **持久化 worker 流程**:worker 的 `context.ask` 接入持久化提问流(#1262);原生会话上报 delegation 进度(#1194);派发时标注发起的 tool call,settle 时取消挂起调用(#1192)。
- **凭证生命周期**:凭证过期触发所属 broker 刷新(#1183),过期错误携带规范化身份(#1182)。
- **auto-mode 分类器**:auto 权限请求改由原生分类器本地裁决,不再绕行模型(#1281)。
- **压缩**:压缩后的首个请求携带 restore 预算(#1280);显式路由同样派生自动压缩(#1195)。
- **前缀缓存亲和**:原生 context 目录稳定化,提供方侧提示缓存得以保持(#1283);提示缓存默认开启(#1216)。
- **流与遥测**:原生流 watchdog 按阶段分层(#1213、#1210);每回合 TTFT 经用量报告进入按模型行(#1200),TUI 侧栏显示平均 TTFT(#1203)。
- **提供方**:长尾插件提供方经宿主网关路由(#1263)并映射到 openai-chat 路由(#1199);路由清单 v2 为角色请求携带按模型容量(#1185);新会话按全局 `engine.storage` 键放置(#1201)。
- **原生会话标题**在首轮对话后生成(#1273)。
- **运维工具**:提供方请求体可经环境变量开关转储(#1284);引擎成本基准工具持久化证据与 results.csv(#1207、#1278)。

## 修复

- **原生成本核算**:所有投递路径均对原生回合用量计价并持久化到 `session_turn_usage`,run 投影与累计用量终于显示真实成本(#1294)。
- ACP 入口默认采用 workspace 策略(#1277);空工具输入以 object schema 呈现(#1264);assistant 身份事实写入原生 assistant 行(#1260)。
- 引擎在 provider 回合配额耗尽时优雅暂停(#1259),首轮 provider 拒绝后可恢复(#1261)。
- 瞬态 image-parse 400 在既有预算内重试(#1258);Chat Completions 流中的显式 null delta 字段可容忍(#1252);GLM coding-plan 模型按标准 API 参考价计价(#1251);富项目上下文保持可选(#1250);窗口冲突中标识会话属主(#1249);TUI 关机期间的刷新取消不再刷屏(#1248);musl 交叉构建保留 PATH(#1247)。

## 验证范围

所有改动合入前均通过完整 CI(含 engine corpus 与 native sandbox 套件)。0.2.25 的制品验收在本版扩展:Windows 与 Linux 跨版本升降级演练(`ENGINE_ARTIFACT_DRILL=PASS`,分别在实际 Windows 主机与 glibc 2.43 容器内完成)、macOS x64 的 Rosetta 2 演练,以及新增的 AppContainer + ConPTY 受限启动回归测试(真机通过)(#1292、#1293)。原生成本修复以真实探针验证:付费费率模型上 `step_finish` cost > 0,且存在对应的持久化 `session_turn_usage` 行(#1294)。

## 更新方式

重新运行安装脚本,或让正在运行的 `miao` 在下次检查时通过后台更新获取 v0.2.26。已有会话、凭据和配置都会保留。
