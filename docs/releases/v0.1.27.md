## [0.1.27] - 2026-10-09

### Sidebar cost display

- Models whose price table quotes nothing — custom providers and coding-plan endpoints project as an all-zero rate — now read `— saved` / `— spent` instead of a fake `$0.00`, so an unknown amount no longer reads as free. Real usage totals (`read` / `write`, cache hit rate, tokens, turn speed) are unchanged (#462).
- Sessions that mix priced and unpriced models keep recorded spend visible: amounts already charged render as usual even when the selected model is unpriced, and the em dash is reserved for zero amounts whose turns no table covers. Per-model and subagent rows apply the same rule per model (#465).
- Both changes ship 8 new sidebar render tests alongside the existing 427 TUI tests.

### Agent runtime

- New autonomous-continuation scheduling skill: sessions can schedule their own follow-up wakeups for long-running work (#461).

### Remote control

- Select a private default Hub before desktop login, fixing first-time sign-in when no Hub has been chosen yet (#457).
- Browser pairing now resumes across social login, so completing an OAuth round-trip no longer restarts the pairing flow (#464).

### Maintenance

- Remove the inherited Korean IME fix installer script, unreferenced since the fork (#460).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes.

Operators who serve custom models through config-defined providers can now quote real amounts by adding a `cost` block (`input` / `output` / `cache.read`, per million tokens) to the model entry; models without one display the em dash.

### Distribution

Windows binaries are currently unsigned.
