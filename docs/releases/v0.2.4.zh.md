## [0.2.4] - 2026-10-10

miao 0.2.4 统一终端 tab 圆圈、右侧 todo 与实际 Session 活动的状态，并改善后台任务
完成和输出中断后的继续执行。

### 一致的 Session 与任务状态

- 终端上报和 todo 侧栏共用对执行状态、待处理决定、任务清单、最终回答与后台活动
  的观测；后台计时器使用同一份活动快照（#583）。
- 执行处于 idle 不再等同于任务完成。区分执行中、等待用户决定、等待后台工作、
  未完成暂停、完成、失败和状态未知。mtty 的绿色实心圆要求没有未完成 todo、没有
  等待项，并且最终回答正常结束（#583）。
- 完成后的 todo 清单继续保留，显示完成/总数和取消数。执行边界立即刷新观测，避免
  短回合根据旧快照误报完成。共享 Runtime 不再向启动它的 pane 上报其他 Session
  的活动；客户端退出上报状态未知（#583）。
- 完整 tab 状态显示需要 [mtty v0.2.1](https://github.com/oxdingzg/mtty/releases/tag/v0.2.1)
  或更新版本。两端都更新后才能实现完整协同。

### 继续执行与恢复

- 后台 bash 任务结束后唤醒所属 Session，等待中的工作可继续执行，无需手动追加
  一条提示（#585）。
- 从已提交历史继续被截断的模型输出，保留已经记录的内容（#584）。
- 限制上下文溢出恢复摘要的大小，同时保留持久历史（#580）。
- 预览通道没有自己的凭据时，可以只读继承稳定通道凭据（#586）。

### Rust 引擎开发进展

- 新增 EngineSession 门面，不另建日志地分发已校验的客户端事件，并使用可稳定
  重放的来源身份（#574、#576、#577）。
- 持久化消息和事件的记录时间，在客户端交付时保留这些时间（#581、#587）。
- 保留同版本预览的回滚二进制，并修复分支与 tag 的 CI 触发条件（#579、#582）。

这些引擎改动仍属于开发基础设施；本次发布继续使用默认 TypeScript Session runtime。

### 验证与下载

版本 PR 运行必需类型检查和 Linux 测试。发布前在构建机生成 macOS 二进制，并通过
独立预览入口进行冒烟验证。发布流水线构建 macOS arm64/x64、Linux arm64/x64 和
Windows x64 的 CLI 压缩包。Windows 二进制目前未签名。
