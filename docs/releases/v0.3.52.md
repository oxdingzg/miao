# miao v0.3.52

v0.3.52 makes a new Session run the model the landing strip promised. The strip
named the remembered choice, but the first prompt never carried it — only a pick
made inside the model dialog reached the engine — so a brand-new Session ran the
engine's own default route while the strip said otherwise: this machine's strip
said `glm-5.3-flash · zhipuai-coding-plan` and the turn answered on
`deepseek-v4-1-flash-261017`.

## The first prompt pins the remembered model (#2724)

- **The promise and the turn are one decision now.** Before a prompt is admitted
  into a Session that carries no model pin, the TUI sends the remembered
  choice's binding when the catalog still resolves it. The engine worker answers
  requests in order, so the pin lands first and the turn runs the model the
  strip named.
- **An existing choice is never overridden.** A Session that already carries a
  pin keeps the model its operator chose, and a remembered value the catalog no
  longer serves leaves the engine default in charge rather than guessing.
