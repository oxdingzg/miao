# miao v0.3.71

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.71.zh.md)

v0.3.71 makes a compaction pass stop paying for its own summary, lets an operator give automatic passes a standing retention target, and brings two smaller fixes: clipboard images no longer collide on a name, and the desktop window runs a conversation instead of only watching one.

## A checkpoint's summary no longer counts toward the next threshold (#3017)

A checkpoint replaces the summarized history with a single `<history-summary>` message, and the automatic trigger counted that message toward the next threshold. Every pass therefore paid for its own output: the Session compacted, started the next stretch already partway to the trigger, and a verbose summary compacted again sooner than the history had actually grown.

Two optional keys on the compaction `context_limits` JSON (both default to the previous behavior):

- `prefixScope` is `total` (the default — the request the provider counted) or `bodyAfterPrefix`, which discounts the carried summary so the threshold reads growth since the checkpoint.
- `retention` gives automatic passes a standing retention target, the same idea as a manual `/compact <focus>`; a request-scoped focus still wins, and the target now also reaches the prefix summarizer, the higher-fidelity path.

`history_summary_text()` is the single place that carried text is built, so the discount and the history selection can never disagree about what was carried.

## Copied images get distinct names (#3015)

Two clipboard images staged in the same nanosecond produced identical file names. The suffix now mixes in a per-process monotonic copy counter, so a burst of pastes no longer overwrites itself. The nanosecond base still distinguishes separate turns.

## The desktop window runs a conversation (#3014)

The Tauri window could watch a Session but not run one. `engine-reader` gains the two writes a conversation needs — `initialize` (idle Session, `protocol: 2`) and `admit` (durable prompt, delivery defaults to steer) — and stays read-only until a caller asks. `SessionSurface` gains a **New** button and an Enter-to-send composer, so the transcript grows from the live subscription without polling.

Verified end to end against `miao serve` (`initialize` → `admit` → `input.promoted` → `run.started` → a real provider call → `message.committed` → `run.finished`), with `tsgo -b` and `vite build` green and the bundle re-signed and launched on macOS arm64. Part of #3012.

## Upgrade

`miao upgrade` (or the install script) moves you to v0.3.71. Nothing in this release changes configuration: existing `context_limits` values keep the behavior they had, and the two new keys are opt-in.
