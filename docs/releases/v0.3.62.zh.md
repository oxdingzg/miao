# miao v0.3.62

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.62.md)

v0.3.62 收束了委托、调度与历史三个闭环：按你给定的上限停止的预算、带闸门的回滚边界、可就地编辑的调度，以及不再空转烧 token 的等待编排。

## 等待中的编排不再空转（#2871、#2882、#2880）

- **子会话运行时不再注入续跑提示**：循环把运行中的委派子会话计入后台工作，等待中的会话不再按退避周期自我重发提示。
- **失败的子会话留下回执**：以 `stop_failure` 结束的委派会记录失败原因，编排方可直接读取而非事后发现静默停摆。
- **尊重 429 的 retry-after**：provider 要求等待时先等再试。
- **预算提醒对齐真实上下文**：wrap-up 与用尽提醒按 `ctx/window`（与压缩同一口径）触发，不再用累计计费 token 冒充。

## 按你给定的上限停止的预算（#2861，COST-02）

- **成本、时间、轮次预算与停止条件**：成本预算在给定上限处停止 run，时间预算在轮次之间停止，委派任务可自述目标与验收条件（#2855，AGT-03）。

## 可以走回的历史（#2866，HIS-03）

- **显式回滚边界**：回滚声明其边界，来自会话外的编辑经过闸门而非静默落地。

## 可就地编辑的调度（#2872、#2875，JOB-05）

- **从调度面板直接编辑**，每行声明其时区、下一次运行与存活时长。

## 更安全的落地与更清晰的界面

- **移动受保护分支的落地动作会被拒绝**（#2852，HIS-05）。
- **委托按净收益结算**并留结构化报告（#2857，AGT-03）。
- **待批计划拥有独立侧栏区块**（#2851，AGT-04），生效行与光标用颜色区分（#2858），对话框导航以键盘为先、可选鼠标选择（#2833、#2787）。
