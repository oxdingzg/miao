# miao v0.3.41

v0.3.41 补上屏幕底部状态行本该说出、却一直缺失的信息。

## provider 与模型并排出现

- **Session 状态行会说出 provider。** 原来读作 `deepseek-v4-1-flash-261017 · openai-chat`——
  只有模型和传输协议，服务它的 provider 不见踪影，而 provider 恰恰是操作者会改变主意的那一项。
  现在这行是 模型 · provider · 协议 · variant；picker 仍用自己的标签，因为它的行本来就位于
  provider 分组标题之下。

## 首页会说明下一条提示将用哪个模型

- **启动页带上模型。** 在任何 Session 存在之前，状态行会被整体清空，而引擎 settings 里只有
  `unavailable/model` 这个占位值，于是"下一条提示会跑在什么之上"这块本应回答问题的界面一无所有。
  现在 miao 把上一次的选择记进 TUI 自己的 preferences，并在首页用目录里的信息标注它，与产品
  首页状态行读取本地选择的做法一致。

首页输入框仍遵循 `prompt.max_width`（默认 75 列）：产品同样对首页做这个限制，只有 Session 的
输入框是整宽。
