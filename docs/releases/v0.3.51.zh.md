# miao v0.3.51

v0.3.51 把变更过的 diff 行换成了产品自己的配色。0.3.50 引入的整行底色取自主题的
success/error 色相，行内代码又保留了语法扫描器的颜色——于是 diff 读起来是一种
产品从未用过的绿，绿底里还嵌着青色的字符串。

## 变更行穿上产品的 diff 配色（#2722）

- **底色与文字色来自产品的 diff 变量。** 深色画布：新增 `#1a2919` 底配 `#9bcd97`
  字，删除 `#42120b` 底配 `#fc533a` 字；浅色画布：`#e3fae1`/`#3a8437` 与
  `#feefeb`/`#ed4831`。挑选哪一组用的还是 `syntax()` 那套亮度判定，自定义主题在
  两种画布下都自动跟随，不需要新增令牌。
- **变更行是单一纯色。** 扫描器不再给块内上色；未变更的行仍是代码，保留文件
  自己的颜色。无色终端和其它颜色一样，只靠字形与文字表达。
