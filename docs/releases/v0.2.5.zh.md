## [0.2.5] - 2026-10-11

miao 0.2.5 改善 Session 恢复能力，并在部分任务等待后台结果时继续执行依赖已满足的独立任务。

### 依赖感知的任务执行

- todo 支持稳定 `id`、`depends_on` 前置依赖及 `waiting`、`blocked` 状态。等待只阻塞依赖它的任务；4 等待、5/6 依赖它时，独立的 7–9 仍可执行（#618）。
- 获得明确自主执行授权的目标，可在 idle 边界继续可执行任务，同时保留迭代、provider 回合和无进展限制。仅剩等待任务及未解锁依赖时正常空闲，不轮询；暂停、阻塞或完成的目标停止此自动续跑（#618）。
- 持久化前拒绝重复 ID/依赖边、未知依赖、循环依赖和提前执行/完成。重载后保留依赖关系（#618）。
- 终端上报、侧栏和调度共用可执行性判断，区分独立任务未完成与整个 Session 等待（#618）。

### Provider 与后台恢复

- 未完成的工具参数默认限制为 1 MiB、120 秒，即使流停止发送片段也会到时中止。可通过 `MIAO_TOOL_INPUT_MAX_BYTES`、`MIAO_TOOL_INPUT_TIMEOUT_MS` 调整。限制针对参数生成，不限制工具执行（#615）。
- 尚未执行的本地工具调用遇到无效 JSON，可从持久历史有限纠正最多两次；保留已完成操作，不盲目重放 provider 已执行的调用或未知副作用。中间错误保留可见，CLI 退出状态反映最终续跑结果（#614）。
- 恢复可重试的 WebSocket 异常断开，包括 1006，并为慢消费者保留帧；协议和策略错误仍终止（#590、#593）。
- 在 Location drain 中保留进程级执行路由，使后台完成通知持久化并唤醒空闲 Session；保留后台结果和待处理 todo（#610、#617）。

### Provider 与客户端兼容

- 保留 Copilot 交错 reasoning 和 opaque 续轮状态；ACP reasoning 块具有稳定且不同于回答文本的身份（#598、#613）。
- 支持 OpenAI `ultrafast` service tier 和带命名空间的 Session/父 Session 身份 header（#604、#605）。
- 识别 C++ module 后缀，使用原执行文件恢复 Session，客户端退出后保留已确认结果，并区分中断与失败（#606、#597、#609、#619）。
- 验证 XAI 原生 Responses 和显式 Chat 请求准备路径中的工具图片续轮契约（#622）。

### Rust 引擎开发

- 新增严格 Session blackbox 录制/回放，以及不重复 executor 副作用的原生工具结果回放（#589、#592）。
- 持久化并校验原生任务依赖，将计算后的可执行任务交付给 provider（#623）。
- 将新增 Session 恢复与调度行为列入跨引擎验收门槛（#621）。原生状态和上下文支持不代表完整原生自动续跑或产品接线已完成。

**默认 Session runtime 仍为 TypeScript。** 切换 Rust 默认仍需代表性质量/效率证据、原生行为对等、实际客户端交付、单一 ownership 和安装/回退验收。

### 验证与升级

已合并改动通过各自适用 CI。组合 CLI 回归和远程构建的 macOS preview 已验证，包括真实模型/HTTP Session 在后台依赖完成前执行独立任务，随后由持久通知自动唤醒并依次完成串行依赖，全程无需追加用户提示。

发布流水线要求精确发布 commit 的 CI 成功，并构建 macOS arm64/x64、Linux arm64/x64 和 Windows x64 压缩包。升级后重启现有 miao 进程，加载新 runtime 与工具定义；数据库迁移保留不含依赖字段的历史 todo。
