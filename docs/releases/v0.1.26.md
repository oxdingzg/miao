## [0.1.26] - 2026-10-08

### Background continuation and message reliability

- **monitor**: Admit background output and completion notices into the durable notification inbox before waking an idle Session. Fixes CI completion appearing in the UI while the agent waits for another human prompt. A regression verifies automatic follow-up tool execution without user input (#447).
- **Scheduled continuation**: Machine notices no longer queue as user prompts. Each schedule keeps at most one unread notice, preventing identical QUEUED cards from accumulating during long-running work. Notices wait for the current tool continuation to finish and respect the machine wake allowance (#450).
- **Send retries**: Reuse stable admission IDs when retrying failed transport, avoiding duplicate submissions while retaining failure feedback and recoverable input (#448).
- **Todo**: Refresh the sidebar task panel immediately on `todo.updated` events (#429).

### Windows sandbox

- Run Windows commands in an AppContainer: only work directories and explicitly allowed paths are writable, network access is disabled by default, and the child process tree is cleaned up when its runner exits (#435).
- Fix directory permission inheritance, short-path resolution, managed PowerShell console initialization, Bun standard-handle inheritance, and cmd script quoting. Concurrent invocation leases do not overwrite one another; normal teardown revokes the invocation's own permissions.
- Twelve real-host file, network, stdio, concurrent-lease, short-path, and process-tree tests passed, along with positive/negative Bun Native addon checks. Platform CI also passed the actual CLI self-exec checks.

### Display, input, and runtime stability

- Fix adaptive transcript viewport coverage and scrolling regressions (#445), and complete the Web timeline's V2 record-native rendering cutover (#428).
- Support Ctrl+Home / Ctrl+End in the input editor (#439).
- Unwrap nested Responses errors, preserve error details, and correctly retry transient streaming errors (#440).
- Correctly recognize standalone Windows installations and upgrades (#437).
- Serialize CLI subprocess tests by platform, scope CI checks to the changed areas while retaining required release checks, and correct browser regressions using an obsolete event format (#443, #444).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes. Session locks retained by an older shared Runtime remain held until that process exits. Updated background-notification and scheduling behavior does not retroactively change tasks created by old processes.

### Distribution

Windows binaries are currently unsigned.
