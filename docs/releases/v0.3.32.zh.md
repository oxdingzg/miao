# miao v0.3.32

v0.3.32 让 `miao upgrade` 对失败的下载说实话,让窗口里能看到正在运行的版本号,
并让侧栏的 todo 与转录里的画法保持一致。

## `miao upgrade` 报告下载失败,而不是一个不存在的升级

- **下载失败不能再宣告成功 (#2500)。** 命令把安装脚本的下载直接管道给 bash,而管道
  返回的是末端的退出码:当脚本的 raw URL 返回 404 时,curl 给 bash 喂了一个空脚本,
  bash 以 0 退出,命令随即打印 `Updated: 0.3.30 → 0.3.31`——而安装根本没发生。现在
  安装脚本先落到临时文件再执行;下载失败会返回一个错误,明确说明旧构建仍在原位。

## 版本号在窗口里可见

- **状态栏右缘显示版本。** `miao 0.3.32` 常驻底部一行的右下角,验证升级是否生效
  不再需要退出 TUI 去跑 `miao --version`。

## 侧栏的 todo 与转录一致

- **两栏共用一套符号。** 侧栏以前画自己的一套(`▸` 进行中、`✓` 完成);转录里
  todowrite 行画的是括号风格(`[•]` 进行中用警示色、`[✓]` 完成)。侧栏现在使用
  相同的符号与颜色,一个任务在两处读起来一致。

## 升级

    miao upgrade
