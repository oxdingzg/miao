# miao v0.3.34

v0.3.34 makes `miao upgrade` work, and makes a blank first frame draw.

## `miao upgrade` asks for the path that exists

- **The staged download asks `/raw/main/install` (#2523).** Every upgrade
  since the command learned to download died on a 404: it asked
  `github.com/<owner>/<repo>/main/install`, a path GitHub does not serve,
  while the manual bridge used the raw host and worked every time. The URL
  now follows GitHub's raw redirect, and the download retries four times
  across error classes for the flapping a proxied link adds.

## A blank first frame draws

- **The loop polls for a real window size while the frame has no cells
  (#2524).** A terminal whose pty had no window size set by the time the TUI
  drew its first frame painted nothing — a zero-sized area produces no cells
  — and the loop parked waiting for an event, leaving a blank screen that
  reads as a dead process. A resize repaired it, but a resize may never
  come. The loop now wakes every 200 ms and paints the moment a real size
  arrives.

## Upgrading

    miao upgrade
