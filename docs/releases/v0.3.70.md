# miao v0.3.70

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.70.zh.md)

v0.3.70 fixes `miao upgrade` on Windows: the updater now runs the PowerShell installer instead of the WSL `bash` launcher, which is what made every upgrade die on a machine without a WSL image.

## `miao upgrade` works on Windows (#3004)

On Windows, `bash` on `PATH` resolves to `C:\Windows\System32\bash.exe` — the WSL launcher — so the updater's `bash install` step failed with "no installed distribution" on every machine without a WSL image. The updater now downloads `install.ps1` and runs it with `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <staged> -Version <resolved>` — the parameter form the installer documents. The download-first-then-run flow is unchanged: a failed download still never executes an empty script, the staged file is removed on every exit, and the POSIX path is untouched.

Nothing else changed: the rest of the range since v0.3.69 is documentation, test-scheduling and dead-code housekeeping.
