# miao v0.3.59

v0.3.59 把侧栏变成会话的指挥台，并补完后台任务的故事：一屏看清分模型花费与
上下文占用，cron 与 wakeup 调度表可以编辑，停止全部后台任务前会先确认，
transcript 还学会了 PowerShell 与 Astro。

## 侧栏显示上下文与花费的去向（#2800）

- **上下文窗口占用一目了然。** Context 区现在绘制本会话占模型窗口的比例，
  「我还剩多少」不再需要打开状态对话框。
- **分模型花费各占一行。** 服务过会话的每个模型都有自己的 lineage 行
  （#2736），花费按同样方式拆分——切换模型时，模型名与金额同步可见。

## 调度表可以编辑了（#2792，JOB-05）

- **可编辑、可展示的 cron 与 wakeup 调度表。** 调度对话框列出所有已武装的
  条目并可逐条编辑——模式、投递与循环不再只写不可读。
- **整表停止前先确认（#2791，JOB-02）。** 停止全部后台任务会先询问并写明
  停止哪些，重开的列表显示引擎当前真实状态——包括被停任务产生的输出尾部。

## transcript 学会更多语言（#2799、#2801）

- **PowerShell 与 Astro 加入语法集**；diff 色带把产品的绿与红一直铺到行尾
  （#2783）——色带不再在中途淡入面板底色。

## 更安全的默认（#2798）

- **自动压缩在默认模型上武装。** 未显式选择模型的会话也能获得上下文阶梯，
  不会无界地跑出窗口。
