# miao v0.3.37

v0.3.37 makes `ctrl+o` show something on every machine.

## `ctrl+o` no longer opens an empty list

- **The provider list stands in when no account is stored (#2533).** `ctrl+o`
  opens the providers that hold an account, and those rows come only from
  model-catalog routes that name a credential. A configuration that
  authenticates per provider — an `auth.json` key, an OAuth login — names
  none, so the dialog painted a single `all accounts  0 accounts` row and read
  as broken. An empty account catalog now falls back to the provider list,
  which is never empty.
- **The provider rows are selectable.** `Enter` narrows the model picker to
  that provider, the way `ctrl+o` inside `/models` does, and a provider this
  engine serves no model of says how to add one instead of opening an empty
  picker.

Everything else from 0.3.36 stays: the flat transcript, the live fold's engine
work, the arrival contract, and the honest `miao upgrade`.

## Upgrading

    miao upgrade
