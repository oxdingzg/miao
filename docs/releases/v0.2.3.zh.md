## [0.2.3] - 2026-10-10

miao 0.2.3 改善模型连接中断后的恢复，保留兼容路由中的图片输入，并在终端显示后台等待进度。

### 连接恢复

- 连接重置使用独立的传输重试预算，最多重试五次，并记录结构化 `llm.transport.retry` 日志（#535）。
- 遇到连接重置后，HTTP 请求临时停止复用连接池中的 socket，让重试建立新连接（#540）。
- 在输出正文或工具调用之前断开的回合，即使已有 reasoning，也可以重试（#538）。目前尚未实现已输出部分回答的断点续传。
- ChatGPT/Codex 回合默认使用池化 Responses WebSocket 传输（#533）。

### 图片与后台活动

- 保留 CommandCode 路由中的图片输入，并在可见输出前恢复上下文溢出（#542）。
- 在输入框上方显示实时唤醒倒计时、后台任务耗时、排队通知与完成状态。计时器只读观察状态；断连后暂停，不受追踪的任务报告结果未知，不会重新执行命令（#544）。

### Rust 引擎开发进展

- 新增本地回环 HTTP 命令与已提交事件 SSE，以及 ACP stdio 生命周期、Session 列表、工具通知、权限、模式与计划（#519、#520、#522、#524–#529）。
- 新增撤销/恢复、计费用量汇总、技能发现和由宿主授权的只读参考目录（#534、#539、#543、#545、#547、#554）。
- 为进程工具落实 Windows AppContainer 沙箱，新增扩展兼容 worker（#550、#557）。
- 扩展引擎到产品的事件桥接：确定性身份、状态、已接纳 prompt、助手正文、工具调用与结果、权限审批及问答（#555、#558–#561、#564、#568–#570、#572）。
- 新增引擎发布产物、manifest、本地安装与回滚脚本、恢复场景测试，以及能力门槛和线上评测记录（#536、#541、#562、#565、#566、#571）。
- 恢复尚未输出内容就中断的引擎请求，并在 Responses 完成输出为空时保留已完成条目（#521、#523）。

这些引擎改动属于开发基础设施；本次发布仍使用默认 TypeScript Session runtime。
