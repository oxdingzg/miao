# [0.2.14] - 2026-10-16

miao 0.2.14 修复原生 Session 事件投递、重连恢复、Windows 进程工作目录，以及自动压缩的截断边界。

### 新增

- **Windows 交互终端**：ConPTY 输入/输出、调整尺寸、有界回放、Session 隔离和进程树清理；强制 AppContainer 隔离，并在终端存活期间保留可写 ACL（#949）。
- **工作区自定义工具**：可选的原生 worker host 加载项目 TypeScript 工具，授权由引擎执行，工具失败独立处理（#947）。

- **时间展示**：TUI 与 Web/Desktop 显示 Session、消息和完成时刻，并提供精确时间详情（#934）。
- **项目自动接受**：支持项目级权限偏好，优先级低于显式 Session 祖先链及目录级选择（#936）。
- **按轮次查看文件改动**：可开启时间线摘要及轮次审查视图，读取已记录的轮次 diff（#939）。
- **多个 provider 账户**：Core/API/CLI 凭据管理保留同 provider 的其他账户，支持切换当前账户，并在删除当前账户后选择剩余账户（#944）。

### 修复

- **工具参数流**：TS 与原生引擎的 watchdog 仅对停滞的参数输入超时，持续收到参数片段时不会因总时长被误杀（#946）。
- **iOS 运维诊断**：正确执行构建状态 lane，失败会真实上报，并查询构建处理及加密声明状态（#948）。

- **Responses 缓存亲和**：原生会话续跑时保留 Session 的 provider 缓存身份（#933）。
- **MCP 兼容**：权限输入元数据统一为对象；服务端未声明 tools 能力时跳过工具目录请求（#930、#932）。
- **快照捕获**：使用字面路径参数，约束作用域，并原子创建快照存储（#945）。

- **原生实时输出**：共享进程级客户端事件分发，并向已连接客户端投递原生 bridge 事件。原生 Session 汇总用量读取引擎账本，定价通过产品模型目录解析；缺失价格保持未知（#910、#911、#915、#918）。
- **重连恢复**：SSE 重连后重新加载可见及固定 Session 的历史、执行状态与待处理权限/问题请求；使隐藏快照失效，并拒绝会覆盖较新状态的过期读取（#916）。
- **Windows 工作目录**：受保护进程遵循已验证的工作目录，包括嵌套目录；在进程边界简化 Windows 规范路径，避免 `cmd.exe` 将其误认为 UNC 路径并退回 Windows 目录（#919）。
- **自动压缩**：等待完整回答后再截断，避免切开工具续接；在提升新 prompt 前生成摘要；允许同一 run 提交多个检查点。ACP 输出及加载的历史独立于模型使用的压缩输入，保留原始回答（#937、#940）。
- **并发创建 Session**：将已投影的创建者绑定作为路由权威，避免误报冲突（#925）。
- **评测退出**：显式取消上游 SSE reader，并在释放代理时解除持久请求额度锁（#924、#928）。

### 验证

- 独立 ACP SDK 覆盖权限、取消、恢复、长 Session、host 配置的 MCP/LSP、子会话委派及父取消（#912、#921、#923、#927）。
- 真实 TCP 验证慢 SSE 订阅者隔离和持久游标恢复（#922）；发布物 drill 验证账本保留、升级/回滚、进程写入隔离及完整回答后的压缩（#920、#940）。
- 限额 live 试跑属于诊断证据，未达到完整 G5 验收：只读与 multi-read 通过，低阈值压缩暴露了本版修复的问题。获准的 24 次上游请求已全部消耗；不宣称本版取得了新的真实模型复测结果。

### 升级

通过常规 miao 自动更新或仓库安装脚本升级后，重启已有进程。单独安装的 `miao-engine` 也需通过引擎安装脚本更新。本版不改变默认引擎选择；正式发布资产的验收记录与源码测试证据分别记录。
