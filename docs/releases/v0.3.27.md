# miao v0.3.27

v0.3.27 is the first release where the native single binary is the primary
way miao is used and tested: the standalone start answers the model picker
with every provider the operator's credentials cover, streams thinking and
answers into the transcript as they arrive, and asks for approval exactly
when the configuration has not already granted it. The release also carries
the native retention tooling, a read-only VCS diff tool, and a round of
layout and startup repairs across the TUI and CLI.

## Native standalone start

- **The model picker answers with every credentialed provider (#2380).** The
  standalone start derives its route manifest from the merged configuration
  and the catalog snapshot: configuration first, then every catalog provider
  a stored key credential covers (zhipu, xiaomi, deepseek, the coding
  plans), with disabled or uncapable entries stepping aside. The picker
  groups the list by provider, and a chosen row resolves through its id
  instead of assuming dialog indices match the catalog.
- **Configured permissions reach the approval path (#2393, #2391).** The
  policy the engine derives from configuration translates the operator's
  `permissions` ruleset into engine rules, so `run_command` under a wildcard
  allow no longer asks, and the golden policies pin the new `auto` field.
- **Streaming works in-process (#2363).** The in-process engine adapter now
  forwards the runtime's progress and config broadcasts beside the durable
  event poll, so the transcript streams thinking and answers instead of
  painting one finished block. Thinking streams verbatim before the answer
  starts (#2375), and a scrolled-back viewport names the question its top
  row belongs to (#2380).
- **The landing list owns the keyboard (#2380)**: the arrows move the
  selection (including the new-session action), printable keys filter, Tab
  hands the keys to the prompt, and `exit`/`quit` quit instead of becoming
  prompts. Enter submits a completion the query already names (#2380), and
  a one-row list keeps its row (b161d714, 2acfb625).

## Engine

- **Snapshot-then-truncate retention (#2361)**: an event-log retention plan
  with never-delete kinds, a `retention` subcommand to plan and apply cuts,
  and message kinds materialised onto `engine_message` (#2359).
- **Read-only `vcs_diff` (#2368)** for one changed file, with the whole VCS
  path measured (#2377) and oversized payloads externalised.
- **One directory, one Location (#2364)**: whatever the spelling, the same
  directory resolves to the same Location and ledger; the session catalog
  answers on a read-only connection (#2360), and MCP tool validators
  compile on first call (#2370).
- **MCP at scale (#2382, #2388)**: oversized catalogues fold into a
  search/detail discovery pair, and the disclosed MCP set is surfaced with
  its digest recorded per provider turn.
- **Doctor grows WAL, foreign-key, and transfer diagnostics (#2354)**, the
  ledger digest is pinned where its path is stable (#2348, #2393-era tests),
  and the CLI reports what a headless run cost as NDJSON events (#2386).

## CLI and installation

- **The single binary carries its product version and build identity
  (#2371, #2369)**: `--version` answers with the real version, unsupported
  TUI options are refused by name with the legacy escape, and worktree
  flows gained a copy-as-worktree command with session-aware removal
  (#2383) and a removal preview (#2358) plus an uninstall command (#2356).
- **Session move previews its impact (#2365)**, and a cold/warm start
  benchmark harness (#2353) joins the measurement kit.

## Repairs

- Paint failure holds the frame instead of exiting (#2374); Escape answers
  a pending approval (#2343-era follow-ups); the landing screen keeps the
  session's column (#2340); the composer starts on the transcript's column
  (#2337); the terminal title is bounded by cells (#2341); and the sidebar's
  todo text follows the transcript's weight (#2346).
- The native single-binary start was repaired end to end (#2352): the
  ledger resolves through the engine's placement rule (#2350), the removed
  plugin-hooks argument no longer reaches `with_product_tools` (#2351), and
  the release uploads the artifacts each leg builds (#2349).
