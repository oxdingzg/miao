# miao v0.2.24

本版聚焦 CLI 的可信度：失败的 run 会明确报错，headless 运行不再泄漏引擎进程，todo 面板能承受模型输出的怪字符，`migrate-back` 对真实引擎完整可用。

## 修复

- **headless 失败可见**：`miao run` 的 provider 回合失败时（模型绑定被拒、首个 step 前的 provider 错误）此前什么都不打印且退出码为 0。现在会报告失败事件并以非零退出（#1228）。
- **引擎进程不再泄漏**：每次 `miao run` 都会把 `miao-engine serve` 子进程留在后台——一台机器一天累积了 170+ 个并把系统推进 swap。headless 运行退出时会终止引擎子进程；交互式宿主的 daemon 行为不变（#1223）。
- **todo 面板承受回车符**：模型输出中的裸 `\r` 会让终端光标回退到行首，把 todo 列表渲染成逐词竖排。任务文本现在在写入边界、读取时（旧行自愈）与转录解析器三处规范化（#1226）。
- **migrate-back 端到端可用**：反向 delta 的回执校验实际写入的字节；已完成的前向审计行原位转向，让反向方向共用同一 id；已迁移会话的投影 variant 绑定主路由。已用真实引擎验证 forward→back 双向放置翻转（#1219）。
- **ACP 接受带 provider 前缀的模型**，provider 运行失败会浮出而不是被吞掉（#1225）。

## 新增

- `miao remote` 在终端里登录 Hub 账号（#1222）。
- 引擎的 prompt cache 默认开启（#1216）；原生流 watchdog 按 phase 分层，慢阶段不再拖垮整个请求（#1213）。

## 验证范围

所有改动合入前均通过完整 CI。migrate-back 修复用真实引擎验证 forward/back 两条腿的放置翻转；headless 失败修复用两个模型 × rust 放置复现，现在会打印错误并以退出码 1 结束；引擎子进程修复通过断言 run 结束后无 serve 进程残留验证。七类任务的加宽验收批（含中断续跑与拒绝族）在两个计价模型家族上运行——见 `docs/experiments/engine-cost-benchmark.md`。

## 更新方式

重新运行安装脚本，或让正在运行的 `miao` 在下次检查时通过后台更新获取 v0.2.24。已有会话、凭据和配置都会保留。
