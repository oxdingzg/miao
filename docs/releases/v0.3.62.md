# miao v0.3.62

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.62.zh.md)

v0.3.62 finishes the delegation, scheduling, and history loops: budgets that
stop at the limit you gave, revert boundaries with a gate on outside edits,
schedules you can edit in place, and a waiting orchestration that no longer
burns turns while its children work.

## The orchestration loop stops burning turns while it waits (#2871, #2882, #2880)

- **No continuation re-injection while a subagent runs.** The loop counts
  running delegated children as background work, so a waiting session no
  longer re-prompts itself every backoff tick.
- **A failed child leaves a receipt.** A delegated run that ends in
  `stop_failure` records why, so the orchestrator reads the failure instead of
  discovering a silent stall.
- **429 retry-after is honoured.** A provider that asks for a delay gets one
  before the next attempt.
- **Budget reminders follow the real context.** Wrap-up and exhausted notices
  are keyed to `ctx/window` — the same accounting compaction uses — instead of
  cumulative billed tokens.

## Budgets that stop where you said (#2861, COST-02)

- **Cost, time, and turn budgets with stopping conditions.** A session cost
  budget stops the run at the limit it was given, a time budget stops a run
  between turns, and a delegated task states its own goal and acceptance
  conditions (#2855, AGT-03).

## History you can walk back (#2866, HIS-03)

- **Explicit revert boundaries.** Reverts name their boundary, and edits from
  outside the session go through a gate instead of silently landing.

## Schedules you can edit in place (#2872, #2875, JOB-05)

- **Edit a schedule from the schedule panel**, and every row states its zone,
  the next run, and how long it lives.

## Safer landings and clearer surfaces

- **A landing action that moves the protected branch is refused** (#2852,
  HIS-05).
- **Delegations settle against their net benefit** with structured reports
  (#2857, AGT-03).
- **The pending plan has its own sidebar section** (#2851, AGT-04), the row in
  effect is coloured apart from the cursor (#2858), and dialog navigation is
  keyboard-first with optional mouse selection (#2833, #2787).
