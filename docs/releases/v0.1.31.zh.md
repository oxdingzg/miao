## [0.1.31] - 2026-10-09

### 新增

- git status 可以在进程内运行。`Git.status.entries` 现在在 `MIAO_NATIVE` 下使用原生(gix)status 原语:逐个列出未跟踪文件、映射到生产状态词表,并给出每个条目相对 HEAD 的行级增删统计。`MIAO_NATIVE=0` 或原生失败时回退到既有的 `git status` / `git diff --numstat` 子进程路径,因此原生层关闭时行为不变(#492)。

### 修复

- 模型退化到重复一句带 markdown 强调的短句时,不再刷屏整轮。输出护栏会在 64 行散文窗口内、以重复行为主时中止该轮;但 `**做**。` 这类句子过不了“散文”判定——星号被当成结构——于是每条加粗行都会清空窗口,导致「加粗句 + 普通句」交替的循环刷了几千行也没被发现。现在判定前会先剥掉 markdown 强调符,加粗句与它的纯文本形式按同一行计数(#495)。

### 升级说明

安装新版后请重启 miao 窗口。更新磁盘上的程序不会替换仍在运行的旧进程中的代码。

### 分发说明

Windows 二进制目前未进行代码签名。
