# miao v0.2.19

本版修复运行 TUI 的 exit 退出回归，解释那些本质是上下文超限的供应商 400 报错，让静默运行的后台子代理保持可见，并按目录价格计量原生引擎步骤。

## 运行 TUI

- 在输入框输入 `exit`、`quit`、`:q`、`/exit` 或 `/quit` 可以正常退出。重写后的 run TUI 只认带斜杠的形式，纯文本 `exit` 被当作聊天消息发给了模型（#1160）。

## 供应商报错

- 当供应商以 HTTP 400 拒绝请求、且请求估算大小超过所选模型声明的上下文窗口时，终态报错会同时给出两个数字，例如 `The request carried about 600k input tokens against this model's 128k-token context window; compact the session or switch to a model with a larger context.` 此前这类网关拒绝（`invalid parameter` 报文、不含容量字样）看起来像是请求其他地方的缺陷（#1164）。

## 后台子代理

- 后台子代理无事件静默到静默窗口一半时，会向父会话发一条注明截止期限的进度通知，慢而未死的子代理与真正卡死的子代理在运行期间即可区分。静默上限触发中断时，失败报告会带上子代理已完成的工作，例如 `It had completed 3 tool calls (last: Bash) before stopping.` 前台 `task` 工具获得同样的进度通知和失败信息中的已完成工作摘要（#1165）。

## 引擎

- 原生会话现在端到端应用产品权威（#1159），原生步骤按目录价格计量（#1166）。

## 验证范围

每项改动都通过独立 PR 的完整 CI（#1160、#1164、#1165、#1159）：TypeScript 类型检查、含新增静默与超限用例的会话 runner 套件、多平台构建。纯文本 `exit` 行为另在已发布的 0.2.17 与 0.2.18 构建上复核，确认回归区间。
