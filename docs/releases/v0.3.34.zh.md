# miao v0.3.34

v0.3.34 让 `miao upgrade` 真正可用,并让空白的首帧画出来。

## `miao upgrade` 请求存在的路径

- **下载改为请求 `/raw/main/install` (#2523)。** 自从升级命令学会下载,它
  每一次都死在 404 上:它请求的是 `github.com/<owner>/<repo>/main/install`
  ——GitHub 不提供这个路径;而手动桥接用的是 raw 域,所以每次都成。现在
  URL 跟随 GitHub 的 raw 重定向,下载还按错误类型重试四次,吸收代理链路
  的抖动。

## 空白的首帧会画出来

- **帧内没有 cell 时循环轮询真实窗口尺寸 (#2524)。** 终端的 pty 在 TUI 画
  首帧时若还没有窗口尺寸,首帧画不出任何东西——零尺寸区域不产出 cell——
  循环随后挂起等事件,留下一个看起来像进程死掉的黑屏。resize 能修复它,
  但 resize 可能永远不来。现在循环每 200 ms 醒一次,真实尺寸一到就画。

## 升级

    miao upgrade
