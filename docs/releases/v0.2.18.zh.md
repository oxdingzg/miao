# miao v0.2.18

本版将远程控制改成账号级接入：电脑和 iOS 登录同一个 Hub 账号，在电脑上开启会话共享即可。第一次连接也不需要配对码、扫码、设备批准或初始化签名名册。

## 远程控制

- 电脑使用 `/login` 登录 Hub。在打开的会话里输入 `/remote-control` 静默切换该会话的共享状态；再次输入即停止共享，不影响其他已开启的会话。
- iOS 自动发现账号下在线的电脑，侧栏列出各电脑共享的会话。手机可打开并操作会话，包括重命名、切换 Agent/模型、排队发送提示和回复权限请求。
- 账号授权依据 Hub 认证连接提供的账号身份，并验证客户端密钥持有证明，通信继续使用加密通道。客户端自报账号不能获得授权。未共享会话不可访问，关闭共享后立即拒绝后续操作。
- 账号模式需要电脑端和 iOS 同时更新，Hub 也必须向主机传递认证账号 ID。旧的独立设备授权仍保留兼容，但不再是 iOS 账号流程的前置步骤。

## iOS 恢复与同步

- App 冷启动后恢复账号连接和草稿。
- 刷新目录时保留稳定的主机与客户端身份，避免临时账号查询失败将所有电脑清空。
- 已验证身份仅在当前登录代际内缓存，退出或切换账号时清除。
- Agent、模型与变体使用页面式选择列表，并提供明确的可访问性选中值。

## 验证范围

PR #1124 的完整 CI 已通过：Swift 核心测试、iPhone/iPad 冒烟测试、无设备注册的原生加密账号接入、Keychain 冷恢复、真实 Runtime 的 UI 操作及重连、TypeScript 检查和 Windows Runtime 测试。生产 TestFlight 签名上传属于后续发布步骤，不能以 CI 通过代替。
