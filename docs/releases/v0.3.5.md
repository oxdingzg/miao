# miao v0.3.5

v0.3.5 completes v0.3.4. The v0.3.4 tag was cut at a `main` commit taken before four changes merged, so its binaries ship without them; this patch release carries those four on top of everything v0.3.4 already included. Install v0.3.5 instead of v0.3.4.

## Improvements and fixes

- A soft per-prompt token budget bounds a looping drain. `agent.budget` counts billed input, output, reasoning and cache across the provider turns of one admitted prompt; at 80% the model is told to wrap up, at 100% it gets one tool-free final turn, and the drain ends with a durable pause notice that records why it stopped. Promoting new user input re-arms the budget, so every prompt gets its own allowance.
- Session titles resolve the model that actually served the session. A stale or empty product row can no longer send title requests to an exhausted provider while the conversation runs fine on another model, and exhausted title candidates are logged.
- A caught-up native event subscriber returns an empty page immediately instead of re-decoding and translating the complete journal on every poll. New events and reconnects still rebuild the required prefix and keep their identities; a 2,500-event regression forbids any idle journal read.
- Google account quota errors now say they come from the Antigravity model service rather than the Gemini App's usage limits, and model discovery keeps the backend reason and reset delay instead of discarding them. Rate limits and capacity errors keep their evidence without exposing provider descriptions or adding retries.

## Validation and limits

Each change passed the same required checks as the rest of the release: `guard` and the aggregated `ci-gate` suite, including the Rust engine suite on macOS, the TypeScript unit, typecheck and e2e suites, and the session blackbox replay. The token budget is covered by runner tests that drive each threshold; the journal change by the 2,500-event regression; the title and quota changes by their focused provider and session suites.

The per-prompt token budget is enforced by the TypeScript runner. The native engine's agent manifest is strict about unknown fields, so `budget` is not forwarded to it yet and native drains keep the session-level USD budget as their only cap; engine-side enforcement is a follow-up. Live engine recycling under a production daemon, clustered placement and long-running watcher hosts remain outside the automated evidence.
