# miao v0.2.22

This release keeps the session list working when an engine workspace has disappeared, shows native stop failures in the transcript instead of leaving a draft streaming, and stops routing a summarization request to a model that cannot hold it.

## Fixed

- **Session list after a workspace disappears**: a native Session placement can outlive its directory — a worktree removed out-of-band, or an engine storage adopted from a temporary workspace. Reading that Location failed on `realPath`, and the whole session listing returned 500, hiding every healthy Session with it. An unreadable Location is now skipped with a warning while the catalog and every readable engine location still contribute their page. Session history in that storage is untouched and appears again if the directory returns (#1190).
- **Native stop failures in the transcript**: the app reducer ignored the engine's `session.next.failed` event, so a streaming assistant draft never settled and the error stayed invisible. It now settles like `step.failed`: the message finishes with an error, pending tools are marked interrupted, and the event is an idempotent no-op when nothing is unsettled. Commit-only steps also seed their assistant message, so replayed `tool.called` and `step.ended` events update a real message instead of a missing one (#1186).

## Engine

- Route manifest v2 publishes each model's declared context and output capacity. The summarize role now checks the retention slice's estimated tokens against the bound model's declared context before sending, skips a model that cannot hold the request, records `role.provider.skipped` with `reason: capacity`, and runs on the primary model instead. This closes the case where a large session's summarization request was sent to a small-context model and rejected by the provider (#1185).

## Verification

Full CI passed before each change merged. The session-list fix adds regression tests for both shapes — a Location whose directory vanished during resolution and a dead engine child during snapshot — and asserts that the healthy native Session is still listed. The transcript fix adds five reducer tests built from real wire shapes, including a drained native session whose draft must settle with its error visible. Engine coverage includes the Rust `route_limits` integration test for declared and undeclared limits, the TypeScript manifest test for the published `limit` entry, and type checking on both sides.

## Updating

Run the installer again, or let the running `miao` background update pick up v0.2.22 on its next check. Existing sessions, credentials and configuration are retained.
