# [0.2.15] - 2026-10-18

miao 0.2.15 完成原生（Rust）引擎建设。放置到引擎上的会话现已具备完整的日常
编码能力面：经反向桥调用产品级工具、端到端可信模型路由、跨进程定时器、增量
工具进度、MCP 加固、环境 Context，以及声明式 provider 路由。

### 新增

- **产品工具反向桥**：原生会话注册宿主提供的产品工具（`send_message`、
  `push_notification`、`workflow` 等），经引擎 stdio 桥反向调度到服务端执行；
  回复作为持久的、模型可见的工具结果结算（#1027）。
- **声明式 provider manifest**：Azure（`api-key` 头 + `api-version` 查询）与
  Vertex-Anthropic（bearer + `rawPredict`）模型路由成为配置而非代码——任何
  base-url provider 或网关都是一份路由 manifest（#1026）。
- **Monitor 工具**：后台运行 shell 命令，把匹配的 stdout 行作为经过滤、批量
  的通知流式送达，底层复用 jobs 生命周期（#1025）。
- **跨重启定时器**：重启时接管持久定时器并重臂进程，由心跳持有 lease，
  supervisor sweep 重新接管持有定时器会话的引擎（#1021、#1022、#1023）。
- **增量工具进度**：进程工具流式发出 `tool.started` 与 `tool.progress`
  检查点；级联取消将整个 run 作为单一路径结算（#1019）。
- **MCP 加固**：确定性目录随 `list_changed` 通知刷新；HTTP 服务器支持
  Streamable HTTP 与 OAuth 刷新授予（#1018、#1014、#983）。
- **可信模型路由端到端**：宿主 manifest 供给引擎目录，产品 API 暴露路由，
  TUI 按会话选择并持久化（#999、#1016、#1001、#1002、#971）。
- **环境 Context 与 hooks**：产品 instructions、skills、references 映射为
  宿主持有的 manifest，含嵌套指令发现与产品 hooks 配置
  （#1008、#995、#972、#996、#1020）。
- **原生 web 工具**：引擎内带权限的 webfetch 与 websearch（#975）。
- **知识共享**：源绑定的工作区知识与失效机制，core 与引擎共享
  （#1003、#977）。
- **恢复面**：恢复决策经 API 与 TUI 暴露，支持显式的未知工具恢复接纳
  （#974、#968）。
- **Responses WebSocket**：会话级连接与严格增量，fork 缓存亲和而不共享
  所有权（#970、#1005）。
- **Provider 账户**：TUI 账户管理、配置指定账户、按会话固定账户
  （#976、#984、#990）。
- **iOS**：会话对话成为主屏，配可折叠会话抽屉（#1010）。

### 修复

- knowledge 工具结果值在解析前先行收窄（#1024）。
- 混合工具轮次中保持读批次执行器归属与有界前缀（#986）。
- 长任务 provider 轮次预算可配置（#978）。
- 计入辅助 provider 用量并纳入覆盖（#973）。
- 后台作业受并发许可约束（#994）。
- 凭据在令牌过期前执行显式刷新；守护归属限定在被替换的账户上
  （#979、#980）。
- 停滞的工具参数流改为重放而非结束轮次（#981）。
- provider 重试按其要求时长暂停；计入 Responses 缓存写入（#992、#957）。
