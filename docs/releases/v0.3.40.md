# miao v0.3.40

v0.3.40 fixes the one thing 0.3.39's new key prompt got wrong: pasting.

## A pasted key lands in the prompt

- **Paste goes to the dialog that has the keyboard (#2558).** The paste event
  was routed to the composer for every dialog except the saved-permissions
  view, so pasting into the provider key prompt left the prompt empty and put
  the key in the draft underneath — where it would have been sent to the model
  on the next Enter. The same was true of the clipboard-read path, and of the
  rename and tag prompts, which accept text the same way. A dialog now answers
  whether it takes the paste; when it does, the composer keeps its draft.
