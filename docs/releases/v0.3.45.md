# miao v0.3.45

v0.3.45 fixes the three defects that made sessions read-only — unreadable
history on Chat Completions endpoints, refused writes on Windows, and an
ignored bare `permission` action — and collects the engine, TUI and CLI
work landed since v0.3.44.

## Three fixes for "can read, cannot write"

- **History continues again after an interleaved tool answer (#2648).** The
  engine stores each tool result as its own message, and a result may carry
  images or text alongside it. Lowering one message at a time put a user
  message between the assistant's `tool_calls` and a later tool answer,
  which Chat Completions endpoints refuse — and every retry replayed the
  same refused history, so the Session bricked mid-turn. The lowering now
  holds the text and images back and emits them as one user message after
  the last answer; affected Sessions resume without any migration.
- **Windows writes no longer fail containment (#2649).** The read checks had
  normalized the `\\?\` verbatim prefix away, but three write comparisons
  still stacked a verbatim canonical path against the plain workspace root,
  so `Path::starts_with` never matched and every `write_file`, `edit_file`
  and `apply_patch` was refused with "path is outside the configured
  workspace". All containment comparisons now use the plain spelling the
  read path already used.
- **A bare `permission` action is honoured (#2650).** The product normalizes
  `permission: "allow"` in `miao.jsonc` to a wildcard rule, but the engine
  migration silently dropped the string, leaving every tool at the default
  decision — a config meant to allow writes and process ran read-only. The
  engine now derives the same wildcard rule the product would, so one
  config spelling means the same thing on both sides.

## Also since v0.3.44

- **Engine**: per-task cost, wall-clock and intervention accounting
  (VAL-02, #2645), and provider retries name the wait class and the pause
  source (#2647).
- **TUI**: the account and the model can be switched right where a quota
  retry is offered (#2651).
- **CLI**: the upgrade probe retries like the download already did (#2646).
- **Docs**: the RUN-01 input-receipt acceptance runs are recorded (#2652).

## Upgrading

`miao upgrade`, or reinstall with the `install` script. The Windows binaries
remain unsigned; the release body records that status.
