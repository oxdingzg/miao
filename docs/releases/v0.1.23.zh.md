## [0.1.23] - 2026-10-08

### 新增

- **core**：向模型如实呈现上下文窗口用量——每轮压缩决策后对比 provider 报告的 prompt tokens 与模型上下文上限，自 70% 起按 10% 区间发布一次合成提示，并明确归档与压缩自动完成（#375）
- **tui**：`/clear` 开启新会话前先显示确认，避免误清当前会话（#349）

### 修复

- **miao**：未处理的 promise 拒绝改为记录崩溃日志后继续运行，不再导致整个进程退出；uncaught exception 仍按原语义退出（#392）
- **tui**：客户端请求失败不再杀死窗口——fork、重命名、shell 执行、目录与集成刷新、权限自动回复、输入同步等路径补齐错误兜底（#389）
- **tui**：状态轮询失败不再拖垮整个 TUI（#391）
- **session**：worktree 迁移通知只入账一次，并发请求不再向 transcript 重复注入相同提醒（#393）
- **installation**：Windows 升级对杀软瞬时文件锁按退避重试，失败信息按 HRESULT 分级给出针对性提示（#351）
- **server**：web handler 缺陷持久化到 miao.log，裸 500 不再无迹可循（#398）
- **deps**：`@ai-sdk/xai` 的 promptCacheKey 补丁扩展到 ESM 构建，修复完整 main 运行中 core SDK 契约测试失败（#395/#396）
- **plugin**：清理 V1 hook 退役后遗留的孤儿文档注释（#388）
- **app**：修复 solid-js 测试环境构建——web 重定向 client 构建、合并 client/server 测试构建、`--conditions=browser` 独立传参（#385/#387/#390）

### 变更

- **app**：timeline 内容改经共享 V2 content 模块投影，collapse-state 回归 spec 注入 V2 事件（V2 transcript 切换 Stage 2，#394/#396）
- **ci**：release PR 携带发布集之外的路径时直接失败（#386）
