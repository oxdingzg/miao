## [0.1.24] - 2026-10-08

### 新增

- **core**：新增 `background-waits` 内置 skill——等待 CI、发布、远程构建等长任务时不再占住回合：后台启动、交代一句、结束回合，由完成通知唤醒继续；GitHub 侧盯 run 本体（`gh run watch <id>`）而非 checks 列表，规避推送后 checks 未注册导致的假全绿（#405）
- **core**：bash 对前台开放式等待命令（`--watch`、`watch`、`tail -f`、轮询循环）附加非阻塞告警，指向 `run_in_background`/`monitor` 与 run 级观察（#406）
- **tui**：Esc 在打断前先取消最新一条排队中的 prompt，排队的输入可以一键撤回（#407）

### 修复

- **tui**：todo 列表中已取消（cancelled）的条目渲染为 `[×]`，与待办 `[ ]` 一眼区分，不再误读成未完成（#411）
- **tui**：tool part 的属性改由 V2 结构化状态派生，修正 V2 事件流下工具块的状态显示（#413）
- **app**：V2 step 失败时把挂起中的工具结算为失败，避免工具卡片永久停留在执行中（#404）
- **app**：legacy part 事件与 V2 session_message 记录保持同步，桥接种子的工具块能正确收到进度/成败更新（#401）

### 变更

- **app**：上下文相关界面改为直接读 V2 session 记录，stage-3 消费者完成迁移；timeline-stability 套件改走 V2 事件流（#403/#408/#412）
