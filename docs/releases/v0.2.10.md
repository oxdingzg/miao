## [0.2.10] - 2026-10-15

miao 0.2.10 fixes a startup failure that 0.2.9 introduced on macOS: the released
binary could not open its own terminal interface and exited before rendering
anything. Updating from 0.2.9 is strongly recommended.

### Fixed

- **macOS**: the terminal interface failed to initialize with "Failed to initialize
  OpenTUI render library: ... mapping process and mapped file (non-platform) have
  different Team IDs". The render library is extracted from the binary's own
  resources into a temporary directory and loaded from there at runtime, and the
  hardened runtime that the release signing introduced in 0.2.9 refuses to load a
  library not signed with the same Team ID. The signing step now declares the
  entitlement that permits it (`com.apple.security.cs.disable-library-validation`),
  and the prompt renders again (#887).

### Validation and upgrade

- The fix was confirmed on the published 0.2.9 binary itself: re-signing that
  identical artifact with the entitlement makes its terminal interface start, with
  no other change. The release build is smoke-tested the same way, by launching the
  terminal interface from the published artifact rather than only asking it for its
  version.
- Upgrade through the usual miao auto-update channel, or use the repository
  installer.
