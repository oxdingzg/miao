## [0.1.27] - 2026-10-09

### 侧边栏成本显示

- 价格表没有报价的模型（自定义 provider、coding-plan 端点会被投影成全零价格）现在显示 `— saved` / `— spent`，而不是误导性的 `$0.00`——未知金额不再看起来像免费。真实用量统计（`read` / `write`、缓存命中率、token 数、回合速度）不受影响（#462）。
- 混用有价与无价模型的会话保留已入账的金额：即使当前选中的模型无价格，已实际计费的支出照常显示；`—` 只用于「零且无价格表覆盖」的情况。按模型与子代理明细行按各自模型适用同一规则（#465）。
- 两项改动附带 8 个新的侧边栏渲染测试，与现有 427 个 TUI 测试一并通过。

### Agent 运行时

- 新增自主续作定时技能：会话可以为长时间运行的工作自行安排后续唤醒（#461）。

### 远程控制

- 桌面登录前先选择私有默认 Hub，修复首次登录时未选择 Hub 导致的失败（#457）。
- 浏览器配对现在可以跨社交登录恢复，完成 OAuth 往返不再重启配对流程（#464）。

### 维护

- 移除继承自上游的韩语 IME 修复安装脚本，自 fork 起从未被引用（#460）。

### 升级说明

安装新版后请重启 miao 窗口。更新磁盘上的程序不会替换仍在运行的旧代码。

通过配置自定义模型的运营者可以为模型条目添加 `cost` 块（`input` / `output` / `cache.read`，每百万 token）以显示真实金额；没有该块的模型显示 `—`。
