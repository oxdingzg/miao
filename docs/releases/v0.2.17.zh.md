# miao v0.2.17

本版本新增精确持久权限审批、共享 MCP OAuth 权威、Copilot 与 Bedrock 原生传输、command/skill/synthetic 的持久输入语义、文件快照与暂存回退、原生迁移状态基础接口，以及面向 native Session 的 TypeScript 写入防护。

## 持久权限

- 权限 grant 以请求时精确 scope 持久化（schema 14）。`approve_persistent` 记录可信请求 scope，与审批决议原子提交，并仅在 workspace、authority revision、prepared targets 与输入完全一致时复用。Capability 与 deny 检查仍先于 grant 查找；grant 永远不会变成通配规则。
- MCP OAuth 刷新权威在 SDK HTTP/SSE 消费方与产品侧原生传输之间共享：跨进程锁覆盖重读/交换/保存，代际 CAS 阻止在途轮转覆盖新授权，native manifest 永不携带 OAuth 秘密。

## Provider

- GitHub Copilot 覆盖原生协议：device/refresh 授权、task-local 子发起者、vision、interaction beta，以及来自产品账户列表的多账户路由。
- Amazon Bedrock 提供原生 Converse 传输（AWS SDK 默认链、bearer 每轮重载、CRC 校验）与产品路由：`@ai-sdk/amazon-bedrock` 模型原生执行，region/profile 或 `AWS_BEARER_TOKEN_BEDROCK` 可选，私有/VPC endpoint 保留，AWS SDK 凭据链环境变量可达引擎。因无独立 Copilot/AWS 凭据，未做真实服务请求验收；HTTP 契约由真实 fixture 覆盖。

## 原生输入与 Session

- command、命名 agent 与 subtask 被持久捕获，并在 promotion 后由 actor ownership 准备；operator shell 执行记录持久重试身份。Synthetic skill context 与 replay 身份在两个引擎间均保留。
- Session 文件快照与暂存回退持久化（schema 16），manifest 有界。
- 原生迁移状态基础接口（schema 17）记录 staged/cutover/终态转换并校验存储的事件水位；native `admit` 和 `resume` 会拒绝活跃转换。这尚不构成用户可执行的 TS↔native 迁移：语义导出/导入、产品 placement 切换、崩溃恢复和反向迁移仍未完成。
- TypeScript core 对 native Session 全面设防：ownership claim、直接 inbox admit/cancel/promote、显式 resume 与 runner 入口均检查 placement，直接调用 core 无法造成第二引擎执行。

## 修复

- 仅声明网关端点的 provider（无 npm 包的 catalog/控制台 provider）不再每回合报 `Unsupported API … native`，改为在其端点上走 OpenAI 兼容 chat 客户端。
- Runtime 关闭时 join 定时心跳，运行后立刻关闭存储不再偶发 busy。

## MCP 与杂项

- 产品 MCP 服务名支持 `-` 与 `.`（有界 64），别名做工具安全清洗并以摘要绑定。
- `/remote-control` 为静默开关，session 创建保持在 trust grants 内，iOS 抽屉刷新会话列表。

## 验收

- 最终 main 集成审计：Rust 全量 release **576 passed / 0 failed / 2 ignored**、all-target clippy（警告即错误）与 release build；每个 PR 均以 strict CI 落地。
- TypeScript：core 与 product typecheck 通过；core MCP 25 tests / 70 assertions。
- 真实 native binary 走 HTTP：6 套集成、16 tests / 135 assertions，包括跨代理重启的持久 grant 复用与变更注册拒绝、MCP OAuth 代理共享、Bedrock 路由生成、command HTTP 与会话生命周期。

原生 schema 17 数据库不能被旧引擎打开。请将开发用 native 存储与正式发布存储分开；回滚时使用支持对应 schema 版本的引擎打开存储。
