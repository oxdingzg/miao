# miao v0.3.12

v0.3.12 fixes the two things that made miao feel slow and dull in daily use: pressing Enter on the home screen no longer stalls for seconds before the Session view appears, and the transcript shows syntax colors again. Six more ratatui TUI slices land alongside them.

## Performance

- **Enter starts a Session in ~50 ms instead of ~3 s (#1542).** The first prompt in a window creates its Session in that window's directory, and the old path did that directory's native preparation while the user waited: spawn the engine child, wait for plugins to boot, build model routes and tools. Measured on a real run, `session.create` took 2689–3725 ms, of which 2309–2535 ms was that preparation (`ProductRoutes.prepare` alone spent 1719–1883 ms waiting on `plugins.booted`) plus a duplicated Location boot of 416–760 ms. None of it depends on the prompt, so the listener now warms that directory's native owner as soon as it is reachable, while the home screen is still up. The same probe measured 51 ms afterwards, and the Session opened and ran normally. Warming is best effort: a directory that cannot be prepared is prepared again, inline, on first use.

## TUI

- **Syntax colors are back in the transcript (#1541).** The native markdown renderer rents its 12,000-unit handle pool by cost, but it charged prose per rendered line, so a few long answers exhausted the budget and every code block after them fell back to uncolored text. Prose is now charged per paragraph, the budget is assigned newest-first so the messages on screen keep their colors instead of the oldest ones, and the compact fallback renders a fence as a real code block with its filetype so it is still highlighted. Both the assistant's code blocks and tool output are colored again.
- **Phase 3 T3 through T8 land (#1527, #1528, #1529, #1540, #1531, #1532).** The ratatui TUI can now read Sessions from the engine, compose and admit prompts, interrupt a run and answer approvals, open the model, theme and session dialogs, show status, switch accounts and stash a prompt, and drive a command palette with slash commands and templates. It is still an alternate front end: the TypeScript TUI remains what `miao` starts.
