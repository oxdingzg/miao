# miao v0.3.37

v0.3.37 让 `ctrl+o` 在每台机器上都能显示内容。

## `ctrl+o` 不再打开一张空表

- **没有存储账号时改列 provider 清单 (#2533)。** `ctrl+o` 打开的是持有账号的
  provider,而这些行只来自带 credential 的模型路由。按 provider 逐个认证的配置
  ——`auth.json` 里的 key、OAuth 登录——一条都不产生,于是对话框只画出一行
  `all accounts  0 accounts`,看起来像坏了。账号目录为空时现在回落到 provider
  清单,而清单不会是空的。
- **provider 行可以选中。** `Enter` 把模型选择器缩小到该 provider,与 `/models`
  里按 `ctrl+o` 的效果一致;引擎尚未提供任何模型的 provider 会说明如何添加,
  而不是打开一个空的模型列表。

0.3.36 的其余内容全部保留:平铺的转录、引擎侧的工作、到达即显示,以及诚实的
`miao upgrade`。

## 升级

    miao upgrade
