# miao v0.3.17

v0.3.17 makes the terminal behave like the operator's own again — through background jobs, external editors and crashes — and tightens how configuration errors are reported. The permission engine gains a shared changefeed with durable handoffs, and the ACP entry point prefers the model the operator actually configured. Upgrade and start `miao` as before; nothing here needs a configuration change.

## TUI

- **The terminal comes back intact after shell job control (#1823).** Suspending, backgrounding and resuming a job used to leave the terminal in the child's state; ownership is now restored to the TUI across the whole job-control path, and errors and exit signals restore the terminal before quitting (#1796).
- **External editors get exclusive terminal input (#1800).** While `$EDITOR` is open, keystrokes go to the editor instead of leaking into the TUI's reader, and interrupts return to the UI with the draft intact.
- **Prompt history searches backward from the current input (#1809), and the timeline searches replies alongside prompts (#1776).** The same prefix you just typed is the starting point, so recalling a variant of the last message takes a couple of keystrokes.
- **Workspace file changes are visible from the engine (#1774).** The dialog lists what the engine saw change on disk, formatted for reading (#1778).
- **A redraw no longer costs the transcript or the draft (#1797), and terminal titles persist safely while honoring disable flags (#1799).**
- **Startup failures read like failures (#1814, #1810, #1806).** Errors surface in the empty sessions view instead of a blank screen, product-planning failures stop the engine startup instead of half-starting it, and the error text is preserved without tripping Unicode panics.

## Engine

- **Shared permission state has a durable changefeed (#1753), and directory permissions retire through a durable handoff (#1741).** Invalidations carry their own cursor per authority, source withdrawal happens before a cancel is acknowledged (#1739), and hook cancellation keeps its execution-lease fences (#1655).
- **Background work settles when its parent goes away (#1808), and cancellation is scoped to the run that asked for it (#1819).** A cancelled parent no longer strands its delegations, and one run's cancel cannot tear down another's work.
- **Headless runs count admission in their deadline (#1633), and replayed commands keep their command and test boundaries (#1777).**

## Configuration

- **Bad configuration is refused with the source named (#1640, #1816, #1821).** A non-object config root fails with the file that caused it, a comma without a preceding value is a parse error instead of a silent acceptance, and the native sandbox and LSP section shapes now match what the product's schema accepts.
- **JSONC diagnostics keep their token boundaries (#1639).** Errors point at the real offset instead of the middle of a neighboring token.

## ACP and CLI

- **The operator's configured default model beats the catalog's newest (#1812).** An ACP client that does not pick a model gets the configured default instead of whichever entry happens to be newest in the catalog.
- **Closing the terminal no longer writes a crash log (#1827).** A stream-write EPIPE raised while the terminal goes away is recognized as an expected closure, in both the exception and rejection paths Bun 1.4.2 uses.
