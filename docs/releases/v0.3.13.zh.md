# miao v0.3.13

v0.3.13 让 Rust TUI 真正成为 `miao` 启动的前端，并随本版一起安装下发。转录里的代码块按语言着色，安装器保证两个二进制版本一致。

## TUI

- **Rust TUI 成为默认前端（#1539、#1535）。** 除非用 `--tui legacy` 或 `MIAO_TUI=legacy` 指定 TypeScript 版本，`miao` 启动的都是 `miao-tui`。它能从引擎读取会话，编写并提交 prompt，中断执行并回答审批，打开模型/主题/会话对话框，显示状态栏，切换账号，暂存 prompt，并支持带斜杠命令与模板的命令面板。它渲染转录的 markdown 与工具行（#1533），提供 attention 提示、剪贴板、外部编辑器与 Zed 上下文（#1534），捕获鼠标并应用光标样式（#1549），按 TypeScript 宿主的方式读取主题目录与配置链（#1536），并支持 `tui.json` 里的快捷键覆盖（#1538）。目前只有暗色主题。
- **代码块按语言着色（#1550）。** fence 的 info 串选定语言族——Rust、C 系、井号注释系、shell、JSON——由一个小扫描器用当前调色板给注释、字符串、数字和关键字上色。未知或无语言标记的块保持原样，因此工具输出和示意图不受影响；扫描器从不改字：一行内所有 span 拼起来永远等于原行。着色作用于消息里的代码块，工具输出仍保留状态色与 diff 色。
- **回退是显式的。** 只升级了 CLI、没有同级二进制的安装仍可用：默认路径给出提示并启动 TypeScript TUI；而显式 `--tui rust` 找不到二进制时会报错，不会悄悄换成别的界面。Rust TUI 尚未实现的选项——`--mini`、`--fork`、`--agent`、`--auto` 以及 replay 系列——会明确提示需要 `--tui legacy`，而不是被静默丢弃。

## 引擎

- **保存的权限规则进入引擎存储（#1546），** 产品里保存的规则就是引擎执行的规则。
- **产品策略与 LSP 从有序的配置来源计划推导（#1544），** TypeScript 宿主与引擎的配置优先级因此保持一致。

## 平台

- **安装器会把 Rust TUI 装到 CLI 旁边。** 它下载 `miao-tui-<os>-<arch>`，用 `--version` 探活；归档缺失或二进制在本机跑不起来时，保留 TypeScript TUI。自动更新走的是同一个安装器，所以 CLI、引擎与 TUI 一起升级。

**完整变更**：与 [v0.3.12](https://github.com/oxdingzg/miao/compare/v0.3.12...v0.3.13) 对比。
