## [0.2.4] - 2026-10-10

miao 0.2.4 coordinates terminal tab badges, the todo sidebar and actual Session
activity, and improves continuation after background jobs and interrupted output.

### Consistent Session and task states

- Derive terminal reports and the todo sidebar from one observation of execution,
  pending decisions, checklist items, final responses and live background activity.
  Background timers use the same activity snapshot (#583).
- Idle execution no longer means task completion. Distinguish working, waiting for
  a user decision, waiting for background work, paused unfinished work, completion,
  failure and unknown status. In mtty, a green full circle requires no unresolved
  todos or waits and a successfully finished final response (#583).
- Keep resolved todo lists visible with completed/total and cancelled counts.
  Refresh observations at execution boundaries so a short turn cannot declare
  completion from an old snapshot. Shared Runtimes no longer overwrite their
  launching pane with other Sessions' activity; teardown reports unknown (#583).
- Use [mtty v0.2.1](https://github.com/oxdingzg/mtty/releases/tag/v0.2.1) or newer
  for the full tab-state vocabulary. Both applications must be updated for the
  complete coordination.

### Continuation and recovery

- Wake the owning Session when a background bash job settles, so waiting work can
  continue without a new manual prompt (#585).
- Continue truncated provider streams from committed history instead of losing
  already recorded output (#584).
- Bound context-overflow recovery summaries while retaining durable history (#580).
- Preview channels can inherit stable credentials read-only when no preview
  credentials are present (#586).

### Rust engine development

- Add an EngineSession facade and fan out validated client events without a second
  journal; use replay-stable source identities (#574, #576, #577).
- Persist message/event recording times and preserve them in client delivery
  (#581, #587).
- Preserve same-version preview rollback binaries and correct branch/tag CI
  triggers (#579, #582).

These engine changes remain development infrastructure; this release keeps the
default TypeScript Session runtime.

### Verification and downloads

The version PR runs required type checking and Linux tests. Before publication,
a remotely built macOS binary is smoke-tested in a preview entrypoint. The release
pipeline builds CLI archives for macOS arm64/x64, Linux arm64/x64 and Windows x64.
Windows binaries are currently unsigned.
