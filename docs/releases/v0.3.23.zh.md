# miao v0.3.23

v0.3.23 将 Rust TUI 的三个主要界面向 TypeScript 版对齐：首页按日期分组、会话侧栏展示上下文与 todo、transcript 把工具输出折叠为一行可读内容。

## TUI

- **首页按日期分组（#1903）。** Today / Yesterday / This week / Earlier 分区取代一面平铺的标题墙；时间右对齐为 muted 列，键位速查移到页面底部提示行，页头收为单行。
- **会话侧栏是一条实时信息列（#1903）。** `context` 展示服务模型的 lineage 与 in/out tokens、缓存读取与轮次；`todo` 展示 done/open 计数与清单本体，直接投影自引擎快照里持久的 `state.todos`，带 ✓ ▸ ✗ · 字形。
- **工具输出折叠为一行（#1903）。** 每次调用只显示字形、名称与一行预览，其余收进 `… N more lines · <leader>u 展开`；成功输出降为 muted，让助手正文成为视觉主体，错误保持红色。
- **transcript 与侧栏改为无边框（#1903）**，与 TypeScript 版一致；边框不再占用正文列宽。
