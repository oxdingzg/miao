# miao v0.2.26

This release hardens MCP identity and rounds out the native engine: OAuth
credentials are keyed by authorization-server issuer, the engine gains skill,
plan, background-task, and PDF tools plus durable background jobs, auto-mode
asks settle with a local classifier, and — the headline fix — native sessions
now report real token costs and persist per-turn usage.

## Added

- **Issuer-keyed MCP OAuth credentials**: credentials are stored per
  authorization-server issuer, with CIMD client-metadata URLs and RFC 9207
  issuer validation on authorization servers (#1288, #1282).
- **Native engine tool surface**: skill, plan, background-task, and PDF tools
  (#1255); `job_list`/`job_wait` (#1253); the workflow tool runs over the
  product-tool bridge (#1193); plugin tools dispatch hooks to the host (#1180)
  and reverse-dispatch the `tool.definition` family (#1198); worktree bridge
  tools wire into product tools (#1178, #1177); native move bundles activate
  (#1175).
- **Durable worker flows**: worker `context.ask` relays into the durable
  question flow (#1262); delegation progress reports from native sessions
  (#1194); the calling tool call is named on dispatch and pending calls cancel
  on settle (#1192).
- **Credential lifecycle**: an expired credential triggers its owning broker's
  refresh (#1183) and expired-credential errors carry a normalized identity
  (#1182).
- **Auto-mode classifier**: auto permission asks settle with the native
  classifier instead of a model round-trip (#1281).
- **Compaction**: the first request after compaction rides a restore budget
  (#1280); automatic compaction derives for explicit routes too (#1195).
- **Prefix-cache affinity**: the native context directory stabilizes so
  provider-side prompt caches hold (#1283); the prompt cache defaults on
  (#1216).
- **Streams and telemetry**: native stream watchdogs layer by phase
  (#1213, #1210); per-turn TTFT flows through the usage report into per-model
  rows (#1200) with mean TTFT on TUI sidebar rows (#1203).
- **Providers**: long-tail plugin providers route through a host gateway
  (#1263) and map onto openai-chat routes (#1199); the route manifest v2
  carries per-model capacity for role requests (#1185); new sessions place
  from the global `engine.storage` key (#1201).
- **Native session titles** generate after the first exchange (#1273).
- **Operator tooling**: provider request bodies can be dumped behind an env
  flag (#1284); the engine cost benchmark harness persists evidence and
  results.csv (#1207, #1278).

## Fixed

- **Native cost accounting**: every delivery path prices native turn usage and
  persists it to `session_turn_usage`, so run projections and lifetime usage
  finally show real costs (#1294).
- ACP entry defaults to the workspace policy (#1277); empty tool inputs
  advertise as object schemas (#1264); assistant identity facts carry onto
  native assistant rows (#1260).
- The engine pauses gracefully when the provider-turn allowance runs out
  (#1259) and recovers after a first-turn provider rejection (#1261).
- Transient image-parse 400s retry within the existing budget (#1258); explicit
  null delta fields in Chat Completions streams are tolerated (#1252); GLM
  coding-plan models price at standard-API reference rates (#1251); rich
  project contexts stay selectable (#1250); session owners are identified in
  window conflicts (#1249); TUI refresh cancellations go silent during
  shutdown (#1248); the musl cross-build keeps PATH (#1247).

## Verification

Full CI passed on every change, including the engine corpus and native
sandbox suites. The 0.2.25 artifact acceptance was extended with Windows and
Linux cross-version drills (`ENGINE_ARTIFACT_DRILL=PASS` on the physical
Windows host and inside a glibc 2.43 container), a macOS x64 drill under
Rosetta 2, and a new confined AppContainer + ConPTY regression test that
passes on real Windows hardware (#1292, #1293). The native cost fix is
verified by a real probe: `step_finish` cost > 0 on a paid-rate model and a
matching durable `session_turn_usage` row (#1294).

## Updating

Run the installer again, or let the running `miao` background update pick up
v0.2.26 on its next check. Existing sessions, credentials and configuration
are retained.
