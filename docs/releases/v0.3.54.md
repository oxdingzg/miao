# miao v0.3.54

v0.3.54 makes the sidebar's Context section honest about every model that served
the session. The section painted only the first lineage entry, so a session
that switched models kept naming the model it had already moved off.

## Every serving model gets its own row (#2736)

- **One row per model:** `model · protocol ×turns`, painted for every entry in
  the usage lineage — the same data the status strip reads — so a switch is
  visible in the column the moment the next turn answers.
