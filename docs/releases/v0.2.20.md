# miao v0.2.20

This release fixes the interactive-exit hang reported on v0.2.19: typing `exit`, `/exit`, or pressing ctrl+c twice tore the interface down but left the process alive and deaf.

## Fixed

- **Interactive exit hangs**: the TUI's engine client ended the engine's stdin and then waited forever for the engine process to exit. An engine serving attached product-tool clients keeps running by design, so teardown never completed. The client now detaches immediately — the engine exits on its own once its last client is gone (#1173).
- The interactive run command also arms a five-second unref'd fail-safe before teardown, so a future leaked handle can hold the terminal for at most five seconds (#1173).

## Engine

- Plugin tools are bridged into native sessions (#1172), native move bundles export and stage (#1170), and the product agent applies before native admission (#1171).

## Verification

#1173 landed through full CI, and the failure mode was reproduced A/B from source on the v0.2.19 tag (hang) versus this fix (exit in under four seconds) before release.
