# miao v0.3.13

v0.3.13 makes the Rust TUI what `miao` actually starts, and ships it with the release. Code blocks in the transcript now carry syntax colors, and the installer keeps both binaries on the same version.

## TUI

- **The Rust TUI is the default front end (#1539, #1535).** `miao` starts `miao-tui` unless `--tui legacy` or `MIAO_TUI=legacy` asks for the TypeScript one. It reads Sessions from the engine, composes and admits prompts, interrupts a run and answers approvals, opens the model, theme and Session dialogs, shows the status line, switches accounts, stashes a prompt, and drives a command palette with slash commands and templates. It renders the transcript's markdown and tool rows (#1533), adds attention alerts, clipboard, an external editor, and Zed context (#1534), captures the mouse and applies the cursor style (#1549), reads the theme catalog and the config chain the way the TypeScript host does (#1536), and honours keybind overrides from `tui.json` (#1538). It is dark-theme only for now.
- **Code blocks are highlighted by their language (#1550).** A fence's info string selects a family — Rust, C-like, hash-comment, shell, or JSON — and a small scanner colors comments, strings, numbers and keywords from the active palette. Unknown or unlabelled fences render exactly as before, so tool output and diagrams are unchanged, and the scanner never alters text: a line's spans always add up to the original line. Highlighting applies to code fences in messages; tool output keeps its status and diff colors.
- **Falling back is explicit.** An installation that upgrades the CLI without the sibling binary still works: the default path warns and starts the TypeScript TUI, while an explicit `--tui rust` without the binary fails with a message instead of starting something else. Options the Rust TUI does not implement — `--mini`, `--fork`, `--agent`, `--auto`, and the replay flags — report that they need `--tui legacy` rather than being dropped silently.

## Engine

- **Saved permission rules reach the engine store (#1546),** so a rule saved in the product is the rule the engine enforces.
- **Product policy and LSP derive from the ordered config source plan (#1544),** which keeps config precedence identical between the TypeScript host and the engine.

## Platform

- **The installer installs the Rust TUI next to the CLI.** It downloads `miao-tui-<os>-<arch>`, probes it with `--version`, and keeps the TypeScript TUI when the archive is missing or the binary cannot run on the machine. Auto-update re-runs the same installer, so the CLI, the engine and the TUI move together.
