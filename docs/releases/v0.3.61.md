# miao v0.3.61

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.61.zh.md)

v0.3.61 closes the retrieval, editing, and delegation loops the roadmap opened:
a session now reads only what it needs and remembers what it read, edits carry
stale recovery, delegated work gets a real budget, and a waiting task is no
longer mistaken for a stalled one.

## Reads only what it needs (TOOL-01, #2832)

- **A session read ledger.** Every read a session performs lands in a durable
  ledger; a repeat read that the ledger already covers is not re-delivered,
  and compaction clears the scope so a reread delivers again. Precise
  retrieval and least-necessary reads are pinned together in the read-ledger
  suite.

## Edits carry their own recovery (TOOL-03, #2834)

- **Low-cost editing carriers.** Short anchors, whitespace-drifted targets,
  and batch edits ride one carrier; a drifted target with a unique recovery is
  recovered and explained instead of failed, and the fuzzy-unit tests pin the
  behaviour end to end.

## Delegation gets a working budget (#2831)

- **Step and time budgets that fit implementation work.** Delegated
  implementations get 96 turns and one hour (up from 32 turns and thirty
  minutes), so a from-zero subagent no longer caps out mid-task and stalls
  into an external-resume loop. Explicit grants stay capped by the parent and
  the absolute maximums are unchanged.

## A waiting task is not a stalled one (#2829, #2844)

- **The no-progress pause honours a minimum stall window.** The drain now
  requires the stall to persist past `MIAO_NO_PROGRESS_MIN_SECS` (default 120
  seconds) instead of pausing after two fast continuation turns — sessions
  legitimately waiting on background work with an unchanged todo list keep
  waiting. Sessions with in-flight subagents already count as waiting.
- **An interrupted turn is recorded.** A turn interrupted before the model
  answered now lands in the ledger, so history shows why the loop stopped.
