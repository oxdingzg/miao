# miao v0.3.52

v0.3.52 让新会话真正跑在首页承诺的那个模型上。首页左下角显示的是「记住的
选择」，但首条提示从未把它带给引擎——只有手动在模型选择器里挑过才会发送，
于是全新会话跑的是引擎自己的默认路由：这台机器上首页写着
`glm-5.3-flash · zhipuai-coding-plan`，回合却在 `deepseek-v4-1-flash-261017`
上回答。

## 首条提示会固定记住的模型（#2724）

- **承诺与执行是同一个决定。** 向尚无模型 pin 的会话投递提示之前，若目录仍能
  解析记住的选择，TUI 会先发送该选择的绑定。引擎工作线程按顺序应答请求，
  pin 先落地，回合跑的就是首页写明的模型。
- **已有选择不会被覆盖。** 已带 pin 的会话保留操作者自己选的模型；目录里解析
  不到的旧记录交给引擎默认，而不是瞎猜。
