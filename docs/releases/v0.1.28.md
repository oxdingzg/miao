## [0.1.28] - 2026-10-09

### Diagnostics

- A stall no longer reads as a crash: the self-sampler records a `gap` entry whenever a tick fires more than one full interval late — memory thrash, machine suspension, or a blocked main thread — and `miao doctor report` shows a `stalls` line plus a `[stall]` finding for each one, with the resume time. Gap entries are not counted as samples, so the rss, cpu, and loop trends stay clean. The check runs before the pending-sample skip, so a slow in-flight probe can never masquerade as a stall (#478).

### Remote control

- Roster members are admitted with bounded grants over an account-isolated signed transport (#476, #480).
- Local account delegation now has an explicit consent and cancellation flow (#473), and the authenticated Hub account identity persists across restarts (#471).

### Fixed

- The TUI keeps reading history stable while the tail streams (#474).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes.

### Distribution notes

Windows binaries are currently unsigned.
