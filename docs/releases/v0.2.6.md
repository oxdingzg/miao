## [0.2.6] - 2026-10-13

miao 0.2.6 makes context compaction visible and controllable, and lands the first production slices of the Rust engine: durable admission, streamed reasoning and tool fragments, and automatic compaction with explicit limits.

### Context compaction is visible while it runs

- The Session drain reports a `compacting` phase while a summary is in flight, so a long compaction no longer looks like a stalled turn (#709, #715).
- The App renders the streaming compaction summary mid-flight instead of waiting for the boundary (#732).
- Staged slice progress is published per compaction segment (#701), and the first provider turn after a checkpoint gets an explicit restore budget (#724).
- The small model is chosen by price within its provider instead of by name (#699).

### Native engine: automatic compaction, activated by configuration

- Context management ships as six explicit gates on the engine side: usage-anchored triggers with explicit headroom versus window ratio (#717), provider token counting with an estimate fallback that can never fail the turn (#718), hot-prefix summary planning with segmented fallback (#722), tool-output pruning with a protected recent window (#726), a circuit breaker after repeated rejections (#727), and progress notices between the transactional `pre_compact` and `post_compact` events (#730).
- The executor commits through the run-owned checkpoint contract, which requires an active run, a settled provider turn, and no outstanding tools (#711, #730).
- The run loop performs the check at the settled boundary, and the serve command accepts `--context-limits <json>` (camelCase: `window`, `ratio`, `headroom`, `perPass`); the TypeScript spawner forwards limits through `EngineOptions.contextLimits` / `MIAO_CONTEXT_LIMITS` (#734, #735, #739). Without configured limits, automatic compaction stays off.
- A runtime regression proves a configured engine compacts a live run and replaces the selection with its summary (#735).

### Native engine: streaming and durability

- Normalized delta vocabulary now covers reasoning and tool-input fragments plus streamed tool-call starts across Anthropic, Responses, Chat, and Gemini, and `one frame may carry several fragments` publishes one notice per fragment (#719, #721).
- The session bridge translates those fragments into `session.next.reasoning.delta`, `session.next.tool.input.started`, and `session.next.tool.input.delta` with part ids anchored to the durable step start, and the App and TUI seed a native assistant placeholder when no `step.started` exists (#714, #725).
- Uncommitted live assistant drafts are discarded at run finish, with committed partials retained (#702).
- Native owners live in a server-scoped registry that survives request scopes and releases its database lease on shutdown (#710).
- Native prompt admission is composed behind `MIAO_ENGINE_BIN`: without it, native-owned Sessions remain explicitly refused (#716).

### Internal

- MCP, debug, models, snapshot, and LSP surfaces moved onto core services (#728, #731, #733, #736), provider credentials are read and removed through core (#737), dead V1 storage and background-job services were dropped from the app layer (#712), and the last non-harness `AppRuntime` consumers were decoupled (#723).
- Highlight parsers register on the active client, fixing a parser-initialization ordering bug in shell highlighting (#705).
- CI scans only the commits a push sends for secrets (#706) and accepts the enrollment fixture's dummy keys (#707).

### Verification and upgrade

- Every change landed through a pull request with required checks green on its exact head, including unit, typecheck, and the native blackbox suites (identity, connection, owners, reads, receipts).
- The Rust engine work was verified with full `cargo test` and `cargo clippy -D warnings` on Linux, macOS (arm64), and Windows, plus genuine provider stream tests against local peers.
- Upgrade with the usual channel: `miao` auto-updates from `oxdingzg/miao` releases; a local checkout can preview with `./script/install-local.sh`.

### Status

- The default runtime remains TypeScript. The Rust engine's automatic compaction is opt-in through `MIAO_CONTEXT_LIMITS`; native Session read routes (sync, messages, event stream) are the next slices, followed by the seven-task live client acceptance and the measured roadmap review before any default switch.
