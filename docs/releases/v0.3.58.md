# miao v0.3.58

v0.3.58 normalizes the sidebar's section rhythm and fixes the gateway session header for opencode-go routes.

## Uniform section rhythm (#2793)

- Every `▾` section in the sidebar now opens after one blank row, wherever it sits — previously Changes and Goal opened glued to the rows above them, and the spacing depended on whether a goal was active.

## opencode-go gateway session header (#2762)

- Derived opencode-go routes now carry the gateway session header the upstream gateway expects, matching the primary route.
