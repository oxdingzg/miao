# miao v0.2.17

This release adds durable exact permission approvals, shared MCP OAuth authority, Copilot and Bedrock native transports, durable command/skill/synthetic input semantics, file snapshots with staged reverts, native migration-state primitives, and a TypeScript write fence for native-owned sessions.

## Durable permissions

- Permission grants persist with exact request-time scopes (schema 14). `approve_persistent` records the trusted request scope, grants atomically with the approval resolution, and replays only on an exact match of workspace, authority revision, prepared targets and input. Capability and deny checks still precede grant lookup; grants never become wildcard rules.
- MCP OAuth refresh authority is shared between SDK HTTP/SSE consumers and product-owned native transports. A cross-process lock covers re-read/exchange/save, a generation compare-and-set fences in-flight rotations, and native manifests never carry OAuth secrets.

## Providers

- GitHub Copilot works across the native protocols: device/refresh grants, task-local child initiators, vision, interaction beta, and multi-account routing from the product's account list.
- Amazon Bedrock has a native Converse transport (AWS SDK default chain, bearer per-turn reload, CRC checks) and product routing: `@ai-sdk/amazon-bedrock` models route natively with region/profile or `AWS_BEARER_TOKEN_BEDROCK`, private/VPC endpoints are preserved, and the AWS SDK credential-chain environment reaches the engine. Live provider requests were not verified because no independent Copilot/AWS credentials were available; the HTTP contract is covered by real fixtures.

## Native input and sessions

- Commands, named agents and subtasks are captured durably and prepared under actor ownership after promotion; operator shell execution records durable retry identity. Synthetic skill context and replay identity survive across both engines.
- Session file snapshots and staged reverts persist (schema 16) with bounded manifests.
- Full operator-facing TS↔native session migration: semantic source export under an independent lease (durable freezes, snapshots and Context Epoch included), inactive native staging, provider-history preparation, atomic placement CAS, native activation with imported history/provider/skill/state restore, and per-session fencing on both sides.
- Reverse migration: the native engine exports the retained payload and the native-era delta (non-text parts are refused explicitly rather than dropped), the TypeScript catalog replays them with original message identities, and authority flips back atomically.
- Operator commands `miao session migrate` and `miao session migrate-back` drive both directions with restart-safe, idempotent recovery.
- TypeScript core fences native-owned sessions: ownership claims, direct inbox admission/cancellation/promotion, explicit resumes and runner entry all respect placement, so no second engine can execute through a direct core call.
- Imported snapshots are assembled for native revert; sessions migrated before this release keep full reverse fidelity only when their native-era turns are text-only.

## Fixed

- Gateway-only providers (catalog/console providers that publish an endpoint without an npm package) no longer fail every turn with `Unsupported API … native`; they route through the OpenAI-compatible chat client at their endpoint.
- Runtime shutdown now joins its timer heartbeat, so closing a store right after a run no longer races into a spurious busy state.

## MCP and misc

- Product MCP server names with `-` and `.` are accepted (bounded 64), with tool-safe alias sanitization bound by digest.
- `/remote-control` is a silent toggle, session creation stays inside trust grants, and the iOS drawer refreshes session lists.

## Verification

- Final main integration audit: full Rust release suite **576 passed / 0 failed / 2 ignored**, all-target clippy with warnings denied, and release build on the pre-merge implementation plus strict CI on every merged PR.
- Migration and reverse-migration units are covered by focused Rust suites (stage/activate/delta export, injected-failure rollback, 20 close/reopen cycles) and TypeScript suites (coordinator sequencing, catalog replay, delta append, reverse CAS), all green on the build host.
- Outstanding acceptance: a cross-process round-trip with crash injection through the real engine binary has not been executed yet, and live Copilot/AWS traffic remains unverified for lack of credentials.
- TypeScript: core and product typechecks passed; core MCP suites 25 tests / 70 assertions.
- Real native binary over HTTP: 6 integration suites, 16 tests / 135 assertions, including persistent-grant reuse across a proxy restart with changed-registration rejection, MCP OAuth proxy sharing, Bedrock route emission, command HTTP and session lifecycle.

Native schema 17 databases are not readable by older engines. Keep development native storage separate from release storage, and when rolling back, open storage with an engine that supports its schema version.
