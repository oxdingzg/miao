## [0.1.5] - 2026-10-04

### 新增
- **core**：新增 `miao db retention`，报告可裁剪的持久事件（#77）
- **remote-control**：新增不透明鉴权中继 hub（#70）
- **remote-control**：暴露执行感知的中断（#67）
- **core**：新增由操作系统支持的运行时存储所有权（#69）
- **core**：新增 `miao db gc-blobs`，删除无引用的 blob（#61）
- **core**：新增 `miao db externalize-blobs`，把内联载荷移入 blob 存储（#55）
- **db**：`db stats` 报告 blob 存储与剩余内联 base64（#56）
- **core**：托管项目元数据写入与目录注册（#35）

### 变更
- **core**：fork 会话改为从投影（projection）重建（#75）
- **miao**：退役旧的项目 facade（#46）
- **app**：移除 identity server 兼容层（#40）
- **miao**：将项目服务委托给 core 持久化（#36）

### 修复
- **core**：当其它 channel 库共享 blob 存储时，拒绝 blob GC（#68）
- **core**：GC 跨所有共享该存储的 channel 库标记引用（#66）
- **core**：按列类型（而非 `data.type`）外部化 `session_message` 载荷（#65）
- **cli**：移除 db 命令中重复的 `Blob` 导入（#62）
- **core**：阻止工具调用重复输出，且不重放工具（#53）
- **llm**：重试瞬时连接与超时失败（#47）
- **tui**：阻止陈旧的 full-sync todo 快照覆盖 live 更新（#42）
- **tui**：用历史快照对齐排队的流式文本（#45）
- **tui**：删除会话时丢弃更早的历史（#32）
- **core**：删除会话时释放会话缓存（#31）

### 性能
- **core**：工具结果大文件外部化到 blob 存储（#54）
- **core**：durable 日志读取分页，不再一次性读完整尾部（#52）
- **tui**：输入 `@` 时对文件搜索做防抖（#51）
- **core**：durable 事件为 no-op 时不重写 assistant 行（#50）
- **core**：已完全投影的会话跳过 legacy 读取（#49）
- **core**：跨轮缓存不可变 blob 的 base64（#48）
- **core**：compact 事件按主键删除，不再重复全表扫描（#44）
- **core**：revision 变化但不涉及行改动时复用历史缓存（#29）
