## [0.2.8] - 2026-10-14

miao 0.2.8 fixes the remote-control device pairing QR code in the terminal.

### Fixed

- **tui**: the device dialog rendered the pairing QR code with inverted colors, and every light module depended on the terminal font filling block glyphs edge to edge — renderers that under-fill the glyphs cut striped gaps through the code and phones could not scan it. The QR now renders from the module matrix with explicit colors per cell: dark modules are black on a white quiet zone, and each cell's lower half is painted by the terminal background itself, so no glyph coverage can distort the code (#824).

### Validation and upgrade

- The change carries unit coverage for grid consistency, quiet-zone polarity, finder-pattern colors and run merging, and passed TUI typecheck and the full `packages/tui` suite (#824).
- Upgrade through the usual `miao` auto-update channel, or use the repository installer.
