# miao v0.3.32

v0.3.32 makes `miao upgrade` honest about a failed download, shows the running
build in the window, and paints the sidebar's todos the way the transcript
paints them.

## `miao upgrade` reports a failed download instead of a phantom update

- **A failed download can no longer announce success (#2500).** The command
  piped the installer download straight into bash, and a pipe reports the
  tail's exit code: when the raw script URL returned a 404, curl fed bash an
  empty script, bash exited 0, and the command printed `Updated: 0.3.30 →
  0.3.31` over an installation that had not changed. The installer script is
  staged to a temp file first; a failed download returns an error that says
  the previous build is still installed.

## The build is visible in the window

- **The status strip carries the version at its right edge.** `miao 0.3.32`
  sits in the row's bottom-right corner, so verifying an upgrade no longer
  means leaving the TUI for `miao --version`.

## The sidebar's todos match the transcript's

- **One glyph style for both columns.** The sidebar painted its own symbols
  (`▸` running, `✓` done); the transcript's todowrite row paints the bracket
  style (`[•]` running in the warning color, `[✓]` done). The sidebar now uses
  the same glyphs and colors, so a task reads identically in both places.

## Upgrading

    miao upgrade
