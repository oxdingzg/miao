# miao v0.2.25

This release completes the native engine's migration story and extends the opt-in switch: `migrate-back` now works for sessions that were **born native**, native reasoning and compaction events reach every client, and a `--engine` flag opts a single command in or out of the rust engine.

## Added

- **migrate-back for native-born sessions**: `session migrate-back` no longer requires a prior forward migration. Sessions created natively export their whole timeline as the reverse delta — user and assistant turns included — and flip placement back to TypeScript. The delta receipt records the empty-input digest (no forward bundle exists to re-verify) and the file's own digest for byte verification (#1242).
- **Native reasoning and compaction replay**: committed assistant reasoning blocks project as `reasoning.ended` and the journal's compaction lifecycle as `compaction.started`/`ended` with stable ids — so replayed or projected native histories keep their reasoning and make auto compaction visible in every client (#1239).
- **`--engine native|ts`**: `miao run` and `miao serve` accept an explicit engine switch. `native` opts new sessions into the rust engine with a sensible default store (no config edit needed); `ts` overrides a configured storage for a single command. Without the flag, behavior is unchanged (#1234).
- **Lifetime usage per model** in the App context panel (#1237).

## Fixed

- `--engine ts` correctly overrides a configured `engine.storage` (#1240).
- The engine archive fallback works on Windows (#1238); the Linux engine ships against musl (#1235).
- Acceptance evidence recorded: a product-level G1 placement acceptance test (singular ownership across retries, migration, and takeover rejection) and G2/G3 evidence including a third-party **Zed** editor session over miao's ACP proxy with a full JSON-RPC recording (#1229, #1243).

## Verification

Full CI passed on every change. The native-born delta export has Rust integration tests (timeline contents, baseline, empty-input digest on the receipt, file digest matching `delta_sha256`, unknown-session conflict) and the reasoning/compaction replay has a dedicated projection suite. The engine-child leak fix was verified by asserting no serve process survives a headless run.

## Updating

Run the installer again, or let the running `miao` background update pick up v0.2.25 on its next check. Existing sessions, credentials and configuration are retained.
