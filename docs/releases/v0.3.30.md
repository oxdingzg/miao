# miao v0.3.30

v0.3.30 makes an answer appear while it is being written, makes `miao upgrade` do
what its name says, and stops the window from showing the terminal's own
background between panes.

## A turn streams as it happens

A running turn showed nothing until the operator typed again, and then the whole
answer appeared at once. The cause was one level of nesting: the engine publishes
`{"kind":"provider.delta","data":{"kind":"delta","delta":{…}}}`, and the reader
looked for the delta on `data` instead of `data.delta`. It never matched, so
nothing streamed. The tests missed it because their helper built `data.delta` — a
shape no provider sends — so they passed against the reader while a real turn
painted nothing.

- **Prose and tools keep the order they arrived in (#2479).** Fixing the read
  exposed the next gap: the draft kept prose and tool calls in separate fields, so
  it painted every paragraph and then every `bash` row. A turn interleaves them,
  and so does the committed message, so the transcript rearranged itself the
  moment the turn committed. The draft now keeps one ordered list of parts —
  reasoning, text, call — and paints them in arrival order.
- **`provider.delta` is a delivery-critical frame (#2479).** Each delta carries one
  streamed chunk and has no durable cursor to replay from, so it now joins the
  frames that must be delivered rather than dropped under load.

## Done means done

- **The run label retires when the stream ends (#2484).** After the answer was on
  screen the status still read `Working`, because the label waited for the durable
  projection to retire the run. It now reads `Done` and keeps the frozen total,
  which is the honest middle: the answer is complete, and the elapsed time still
  shows while a stalled projection holds the run open.

## `miao upgrade` upgrades

- **The command updates instead of refusing (#2477).** `miao upgrade` printed the
  version and `feed none configured; reinstall the build to upgrade` — a message
  that could never change, because nothing set `MIAO_UPGRADE_FEED`. It now reads
  the newest release, compares it against the running build, and runs the
  published installer when there is something newer. The download, the platform
  asset name, the checksum and the rollback all stay in `install`, the one path CI
  exercises, so a second copy cannot drift from it.
- **`--check` only reports.** A script can ask whether an update exists without
  touching the installed build.
- **The comparison is numeric per field.** A string compare calls `0.3.9` newer
  than `0.3.29` and would refuse that update.

## `/models` groups by provider, and a queued prompt is visible

- **Models are listed under provider headers (#2481).** `ctrl+o` opens a provider
  filter list, so a provider with many models stays usable, and selecting a
  provider that still needs auth surfaces the way in (`miao auth login`) instead
  of failing the parse silently.
- **A queued prompt is echoed for exactly as long as it is queued (#2481).** A
  submitted prompt used to vanish into the queue; it now shows as a queued row
  until it is promoted.
- **The engine answers `provider_catalog` (#2481).** The shipped models snapshot
  is merged with the configured-route status, so the list reflects what this
  machine can actually reach.

## Every cell belongs to the page

- **No stripe between panes (#2480).** `body_columns` handed the transcript
  everything up to the divider column and the sidebar everything after it, so that
  column belonged to neither pane and kept the terminal's own background — a
  visible stripe on a dark theme. The sidebar's rectangle now starts on the
  divider column and is one wider than the content it holds, so the pane that
  draws the rule owns the cells around it.
- **The sidebar, the status strip and the composer fill their own area (#2480).**
  The sidebar fills its column before drawing the rule; the status strip paints
  its row even when it has no hints; the composer no longer reserves a blank row
  above and below itself, because its box already draws both rules.
- **A test paints a whole window and checks every cell (#2480).**
  `no_cell_falls_back_to_the_terminal_default` renders 120x20 and fails on any
  cell still holding the default background.

## Upgrading

    miao upgrade

`miao upgrade` now fetches and installs the newest release itself. Use
`miao upgrade --check` to ask whether an update exists without touching the
installed build, and `MIAO_UPGRADE_FEED` to point the command at an internal
mirror.
