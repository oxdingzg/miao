# miao v0.3.17

v0.3.17 让终端在后台任务、外部编辑器和崩溃场景下都表现得像操作者自己的终端，并让配置错误的报错更精确。权限引擎获得带持久交接的共享 changefeed，ACP 入口也会优先使用操作者真正配置的模型。升级后照常启动 `miao` 即可，这里没有任何需要改配置的项。

## TUI

- **shell 任务控制之后，终端完整回到 TUI 手里（#1823）。** 以前挂起、后台化再恢复一个任务，终端会停留在子进程的状态里；现在整条 job-control 路径都会把所有权交还给 TUI，错误与退出信号也会先恢复终端再退出（#1796）。
- **外部编辑器拿到独占的终端输入（#1800）。** `$EDITOR` 打开期间，按键进入编辑器而不是漏进 TUI 的读取器；中断后回到界面时草稿还在。
- **提示词历史从当前输入向后搜索（#1809），时间线在回复里一并搜索（#1776）。** 刚输入的前缀就是搜索起点，找回上一条消息的变体只要几次按键。
- **工作区文件变更直接来自引擎（#1774）。** 对话框列出引擎看到磁盘上变化的文件，并做了阅读性排版（#1778）。
- **重绘不再丢 transcript 和草稿（#1797）；终端标题安全持久化并尊重禁用开关（#1799）。**
- **启动失败读起来像失败（#1814、#1810、#1806）。** 错误会出现在空会话视图里而不是一片空白，产品规划失败会终止引擎启动而不是启动一半，错误文本保留完整、不再触发 Unicode panic。

## 引擎

- **共享权限状态有了持久 changefeed（#1753），目录权限通过持久交接退役（#1741）。** 失效记录按 authority 自带游标，来源撤销先于取消确认（#1739），hook 取消保留执行租约围栏（#1655）。
- **父任务消失时后台工作会收尾（#1808），取消只作用于发起它的那次运行（#1819）。** 被取消的父任务不再丢下它的委派，一次取消也不会拆掉别处的工作。
- **headless 运行的截止时间把准入也算进去（#1633），重放的命令保持命令与测试边界（#1777）。**

## 配置

- **坏配置会被拒绝，并指出来源文件（#1640、#1816、#1821）。** 非对象的配置根失败时点名文件，前置值缺失的逗号是解析错误而不是被默默接受，原生 sandbox 与 LSP 段的形状校验与产品 schema 对齐。
- **JSONC 诊断保留 token 边界（#1639）。** 错误指向真实偏移，而不是相邻 token 的中间。

## ACP 与 CLI

- **操作者配置的默认模型优先于目录里的最新条目（#1812）。** ACP 客户端不指定模型时，拿到的是配置里的默认模型，而不是目录里恰好最新的那一条。
- **关闭终端不再写 crash log（#1827）。** 终端离开时的 stream-write EPIPE 被识别为预期关闭，覆盖 Bun 1.4.2 的 exception 与 rejection 两条路径。
