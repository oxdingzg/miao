# miao v0.3.49

v0.3.49 gives the model an honest view of its own context. The self-enforced
"round budget" story that made sessions stop mid-task is gone, and as a
conversation approaches the automatic-compaction threshold the model now sees
real occupancy figures and what happens next instead of discovering the
compaction by losing its history.

## The budget story is gone (#2711)

- **Turn-limit guidance states measurement, not a grant.** The engine's
  per-turn allowance notes used to read like a budget the model could spend
  and justify ("budget nearly exhausted"), and models answered by declaring
  the round over mid-task. The wrap-up and exhausted notes now state
  re-measured facts, ask for a text-only close, and never invite the model to
  police its own allowance.
- **Fewer false stops.** A Session that still has durable work keeps its
  provider-turn allowance; only the real measurement pauses it, and the
  operator can always continue with the next prompt.

## The model can see its context filling (#2712)

- **A context-pressure ladder rides the session's own turns.** At 60% of the
  window the model learns its occupancy and is asked to keep reads targeted;
  at 80% it gets concrete instructions (finish the current operation, keep
  durable state in files); at 88% it is told compaction runs at the next turn
  boundary and to wrap the current step cleanly. The figures lead with the
  window, are re-measured every turn, and void numbers from earlier
  reminders; a compaction checkpoint re-arms the ladder from zero.
  Delegated children never see it - the anchor belongs to the parent
  Session's window.
- **Request bounding plans against the same window as compaction.** The
  effective window now resolves the same way for both: operator override,
  then the session model's declared route capacity, then a window an endpoint
  stated when it refused the history. A session whose window was known only
  through its route used to arm compaction while its requests stayed
  unbounded.
