# miao v0.3.3

[简体中文](https://github.com/oxdingzg/miao/blob/v0.3.3/docs/releases/v0.3.3.zh.md)

This release repairs long native tasks, missing progress, session-title recovery and misleading Google errors, and adds native product regression gates.

## Improvements and fixes

- Product sessions no longer silently stop after 25 provider turns. The product policy has no implicit turn-count limit; explicitly configured agent limits remain enforced and their pause notices survive transcript replay. Standalone engine configurations retain their documented default.
- Native execution uses the same model-family persona assets as the TypeScript runner. After three consecutive tool-only batches, a request-scoped reminder asks for a concise update in the user's language without creating a durable user prompt or changing tool-result ordering.
- Bare `New session` titles are recognized consistently. Idle sessions and historical unnamed sessions accessed again can regenerate titles, with bounded auxiliary requests and model fallback. Manual renames synchronize native and catalog state and take precedence over background generation.
- Google rate limits, service quota exhaustion, temporary capacity failures and unknown 429 responses retain their actual classification. Provider reset hints are preserved, including weekly limits. The gateway avoids hidden SDK retries and console stack traces; native errors preserve provider status instead of misreporting a malformed stream.
- Session pages consolidate their model, variant, context, directory, branch and agent into one persistent status row. Clicking the model still opens its selector.
- CI runs actual native-binary HTTP tests when the product's native session, provider, system-context or projection code changes. Tests use an existing checked-in model fixture with network discovery disabled, avoiding cold-start catalog downloads and silently skipped native checks.

## Validation and limits

The final combined Rust suite passed 645 tests with zero failures. The remaining CLI tests passed 1,043 tests across 144 isolated file processes. A compiled preview was checked in an actual PTY for a single model/status row. The complete native HTTP suite passed 343 tests across 119 files with a compiled engine. Controlled real HTTP scenarios exercise the same 27-request task through both TypeScript and native execution, explicit turn-limit notices, restart persistence, model binding and title recovery. Persona hashes are checked against 21 cases generated by the actual TypeScript selector. A real Google session completed ten sequential tool calls with three readable progress updates before its service quota was exhausted.

Google web-app usage does not establish the allowance of a separately connected model service. Actual upstream quota exhaustion remains an external failure; miao preserves the evidence and reset hint and does not silently change accounts or providers. Live acceptance with an unconnected provider account remains outside the automated evidence.
