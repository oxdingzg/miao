# miao v0.3.68

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.68.md)

v0.3.68 让内置代码索引对所有人默认开启，为发布下载加了镜像，并修掉了会让引擎连不上自己回环服务的代理边界问题。

## 代码索引默认开启（#2955）

原来要写一行配置才会启用，结果是升级的人大多从没用上这个功能。现在除非你显式关闭，它都是开的：

- 无配置即开启；`MIAO_CODEGRAPH=0` 关闭单次运行，`"codegraph": { "enabled": false }` 关闭某台机器或某个工作区。
- 默认开启的代价：引擎存储旁多一个库文件，且在某工作区首次调用时花几秒建索引（有单次预算，输出会说明索引是否仍在构建）。
- 值得默认开启的理由：同一任务、每臂两次、同一模型的实测——输入 tokens −32%，模型轮次 −33%，工具调用 −27%，答案正确性相同。

四个工具不变：`codegraph_explore`、`codegraph_node`、`codegraph_callers`、`codegraph_status`，覆盖 41 种语言与单文件组件。

## 发布下载有了镜像（#2946）

`install` 与自更新在 GitHub 发布主机缓慢或不可达时可改走 `dl.mtty.dev`；镜像探测失败也不会再让安装脚本整体退出（#2950）。

## 引擎能连上自己的回环服务（#2947）

设置了全局 `HTTP_PROXY` 时，引擎现在直达自己的回环 sidecar，不再把这部分流量交给代理。

## 其他修复

- `miao status` 会把未跟踪文件的行数计入新增行（#2954）。
- 引擎的格式与 lint 门恢复干净（#2956），Windows TUI 腿的 `needless_bool` 已修（#2960）。
- 测试卫生：monitor 夹具命令有了 Windows 等价写法（#2958），忙等重试用例会关掉第二条连接（#2949），heal 通知的断言不再依赖 JSON 格式（#2953）。

## 已知问题

- Windows 上 `tests/web.rs` 的 `runtime_fetch_waits_for_bound_controller_approval_before_any_http_request` 仍会栈溢出；加到 64 MB 栈也无效，说明是无界递归，需要抓取调用栈（#2926）。
- 被暂停的 autonomous goal 可能被自己的暂停通知重新唤醒（#2948）；修法是把闸门持久化到会话状态。

## 升级

`latest` 渠道上的 `miao` 会自行更新；否则重跑安装脚本。
