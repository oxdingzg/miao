# miao v0.3.50

v0.3.50 让两件「你已经做过的事」真正生效：引擎重启时留在队列里的消息会真的开跑；
变更过的 diff 行读起来是一整块，而不是一条上色的文字。

## 重启会发出它留下的那条排队消息（#2720）

- **排队输入不再等一个无关事件。** 引擎只在客户端请求的边界提升排队输入。重启后
  打开的会话仍持有你已经发出的消息，却再没有谁来提升它：输入框一直显示为已排队，
  实际什么也没跑，真正让它启动的往往是再发一条、或 Esc 打断后重发。现在打开这样的
  会话会请求引擎把等待中的输入发出去——每次打开只请求一次，且仅在没有任何回合运行
  时请求。
- **不会悄悄重试 provider 工作。** 唤醒只排空仍未提升的输入；被打断的那个回合不会
  被继续，因此打开会话不会背着操作者发起第二次 provider 调用。

## 变更的 diff 行是一整块（#2719）

- **行本身承载变更，而不只是标记。** 过去只有 `+`/`-` 取变更色，眼睛只能一行
  一行重新寻找变更的边界。现在由一行自己承载：主题把变更色按四分之一混进画布，
  并把该行补齐，使这一块的右边界笔直。
- **由主题派生，不引入第二张色表。** 全部内置主题、浅色画布与自定义
  `themes/*.json` 共用同一条规则；无色终端（`NO_COLOR`、`TERM=dumb`）与其它
  颜色一样不着底色。
