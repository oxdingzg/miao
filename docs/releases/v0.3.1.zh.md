# miao v0.3.1

本版本修复直接登录 Hub 时 Esc 无法关闭弹窗的问题，同时修正个人 Google 账号的 OAuth 注册，并优化 Bash 工具输出的 token 开销。

## Fixed

- **Hub 登录取消**：直接进入登录后，在“选择 Hub”或后续输入步骤按 Esc 会关闭登录界面并回到会话，不再因为保留 `startInLogin` 而重复打开登录流程（#1330）。
- **Google 账号登录**：将个人 Google 账号 OAuth 正确注册到 `google` integration，修复登录入口与 provider 不匹配的问题（#1328）。

## Added

- **按模型配置压缩预算**：通过 `max_context` 为模型设置上下文预算，控制会话压缩的触发预算（#1331）。
- **精简 Bash 输出**：折叠终端进度重绘、移除 ANSI 控制序列、脱敏常见凭据并缩短过长单行，降低发送给模型的输出体积。托管输出文件保留原始输出；可通过命令注释 `# nofilter`、`# raw` 或环境变量 `MIAO_BASH_RAW=1` 使用原始输出（#1327）。

## Verification

- Hub 登录相关 17 项测试通过，新增用例覆盖 Hub 选择和电脑名称输入阶段取消，以及延迟后不再弹出和不发起登录请求。
- TUI 类型检查、格式检查通过；两个新增回归用例在修复前均失败。

## Upgrade

使用现有安装方式升级到 `0.3.1`，然后重新启动 miao。
