# miao v0.3.1

本版本让上下文预算从"只能被动遵守"变成"可以主动调控"：用
`compaction.max_context` 按模型收窄工作窗口，checkpoint 注入整体纳入渲染时
预算，并用新的 `history` 工具找回被压缩移出的细节。native engine 侧同时修复
了工具结果进入会话记录的方式——shell 输出恢复为可读文本，成功的 `todowrite`
不再误报失败。

## Added

- **每模型 `compaction.max_context`**：让模型在比其声明窗口更小的范围内工作——
  一个作用于所有模型的值，或以 `"<providerID>/<modelID>"` 为键、支持通配的
  映射（最长匹配键胜出）；可以是 token 数、`"300K"`/`"1.5M"` 简写，或窗口的
  `"50%"`。只会被钳制到真实窗口之内，绝不抬高；`0` 恢复模型默认（#1331）。
- **`history` 工具**：按位置分页读取完整的历史消息，与 `recall` 配对使用——
  `recall` 返回摘要与 `#seq` 定位，`history` 负责读回全文，每页有预算上限
  （#1334）。
- **checkpoint 渲染预算**：`<conversation-checkpoint>` 注入在渲染时受限
  （summary 4,096 / recent 12,000 tokens），旧配置或更宽松配置下写入的记录
  无法再撑大当前窗口；截断提示指向 `recall`（#1333）。

## Fixed

- **native engine 工具结果遵循产品契约**：引擎工具完成事件此前被投影为原始
  JSON 且 structured 为空，shell 调用把整个 `{stdout, stderr, ...}` 渲染成
  正文，成功的 `todowrite` 显示 "Todo update failed"。现在 shell 结果投影为
  可读输出加结构化字段，会话状态变更解包为渲染端期望的载荷（#1335）。
- Hub 登录对话框支持 Escape 关闭（#1330）；google-account OAuth 归入
  google 集成（#1328）。

## Tooling

- token 高效的 bash 输出管线（#1327）。
