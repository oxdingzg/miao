# miao v0.3.20

v0.3.20 让会话中「给人看」的一侧更诚实也更安静：Todo 面板会显示清单多久没更新并在陈旧时警示，监控唤醒读起来像一条 watch 而不是内部报文，新窗口也不再被旧窗口持有的共享存储挡住。

## TUI

- **Todo 面板显示清单年龄并标注陈旧（#1876）。** 几小时前同步的清单不再冒充当前计划：面板显示 `updated 3m ago`，超过 30 分钟仍有未完成项时明确提示该清单可能已过期、请 agent 刷新。
- **最新消息可在可滚动详情视图中打开（#1863）；排队中的问题只应答一次，单选题支持自定义输入（#1866、#1867）；宿主的 MCP 服务器在只读面板中展示（#1864）。**
- **未知斜杠命令会被直接报错，而不是当作提示发给模型（#1868）。**

## 引擎

- **监控唤醒读起来像一条 watch（#1878）。** 每个生命周期只发一条消息——`watch "<描述>" matched:` 后跟匹配行——没有 job UUID、没有重复的 `Matched output:` 标签；已完成并交付过匹配结果的运行不再补发第二条。异常终止仍会说话：`watch "…" failed (exit code 1).`
- **追加式存储升级不再要求独占（#1872），需要独占时错误会点名在线的旧引擎（#1862）。** 新窗口可以在旧窗口打开了同一 schema 的情况下启动，而不是死在 `cannot upgrade Session storage while an older engine run owner is alive`；格式修复仍然要求旧引擎先退出。
- **网关重放同一 tool-call id 时只保留一次调用（#1870）。**
