# miao v0.3.67

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.67.zh.md)

v0.3.67 ships the built-in code index: miao can answer "where is this symbol, and who calls it" from a local symbol graph instead of a grep-then-read loop, across 41 languages and single-file components.

## Built-in code index (#2937)

- Four read-only tools, off by default. `codegraph_explore` returns the verbatim, line-numbered source of the symbols a question names plus the call paths between them, in one call, and says what it left out. `codegraph_node` reads one file (with the files that import it) or one symbol (with its callers and callees). `codegraph_callers` lists call sites. `codegraph_status` reports coverage.
- The index is a cache of the source tree, not a project artifact: it lives beside the engine store at `codegraph/<workspace-hash>.db`, refreshes incrementally by size and mtime under a bounded per-call budget, and never shows up as a working-tree change.
- Enable it with `"codegraph": { "enabled": true }` in configuration, or `MIAO_CODEGRAPH=1` for a single run.
- Measured on one task with two runs per arm, same binary, model and workspace snapshot: input tokens -32%, provider turns -33%, tool calls -27%, with identical answer correctness.

## 41 languages and component formats (#2940, #2941)

- JavaScript family: TypeScript, TSX, JavaScript. Components and markup: Vue, Svelte, Astro (through their `<script>` block or frontmatter), HTML (through its inline `<script>`).
- Systems: Rust, C, C++, Zig, Objective-C. JVM and .NET: Java, Kotlin, Scala, C#, F#. Functional: Elixir, Erlang, Haskell, OCaml. Scripting: Python, Ruby, PHP, Lua, Shell, PowerShell. Data and science: Go, Julia, R, SQL. Interface and infrastructure: Protobuf, GraphQL, Terraform/HCL, Solidity. Other: Dart, Swift, Elm, Nim, GDScript, Crystal.
- Masking keeps byte offsets and line numbers identical to the file, so a component's template is never parsed as code and a returned line number is the line you would read.
- Cross-file resolution follows each language's own import spelling (relative paths, `use crate::`, dotted Python modules, Go packages, `import a.b.Type`, `#include`, `source`, `alias`, `open`, `using`) and falls back to sibling files of the same directory.
- The release binary grows with the grammar tables (arm64: 85 MB to 159 MB) and a clean release build from about one minute to three. Incremental builds are unaffected.

## TUI (#2942)

- The screen resyncs when the console host reports a resize instead of drawing against the previous geometry.

## Engine (#2943)

- The metadata-budget fixture owns its own file name instead of depending on the ambient PATH, so the test no longer passes or fails with the host's toolchain.

## Known issues

- `tests/web.rs` crashes with `STATUS_STACK_OVERFLOW` on Windows (#2926).
- Windows-only legs still skip tests that cannot pass there (#2873).

## Upgrading

`miao` on the `latest` channel updates itself; otherwise re-run the installer.
