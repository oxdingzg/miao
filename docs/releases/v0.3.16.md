# miao v0.3.16

v0.3.16 makes the Rust TUI start where it used to refuse, and makes a failed provider turn report what actually happened instead of claiming retries it never made. Configuration values can now be explained from source, and a native Session can move to an existing workspace. Upgrade and start `miao` as before; nothing here needs a configuration change.

## TUI

- **The Rust TUI starts where credentials live in the product database (#1588).** The TUI spawns `miao-engine` itself and could only forward its environment as a fixed table of flags, which carries no product route or credential source, so those machines died at startup with `API key or explicit credential source is required`. The launcher now points `MIAO_ENGINE_BIN` at a shim that re-enters the same executable and prepares the per-Location plan the TypeScript host would prepare — routes and credentials, MCP, configuration sources, ambient context, hooks, LSP, formatter — keeping those manifests and the local AI-SDK gateway alive for the engine's lifetime while relaying frames between the TUI and the real child.
- **An idle TUI redraws once a minute, not ten times a second (#1581).** Only the clock-derived labels change with time, so they now refresh per minute and missed intervals are skipped; input, engine and resize events still repaint immediately.
- **Preview installs keep the TUI, CLI and engine from one build (#1577).** `install-local.sh --tui-binary` pairs them, verifies versions before changing launchers, and refuses conflicting retained sidecars, while explicit `MIAO_TUI_BIN` / `MIAO_ENGINE_BIN` overrides still win.

## Engine

- **A failed turn is retried inside its window, and the failure says why (#1591).** The retry window used to be armed when the turn started, so a slow first attempt spent it; the turn-level replay then returned `the turn's retry window was spent before another request` without sending a request, and the failure line added `kept failing after retries` even when no retry had happened. The window now arms at the first failure, the last failure is kept and named in the message as `(last attempt: …)`, transport reasons are recorded on `provider.request.result`, and a replay is recorded as `provider.retry` with `scope: "turn"`. A turn that failed on its own now reads `the model endpoint failed: …`. An endpoint that keeps failing for the whole window still ends the turn — but it now tells you what it was failing on.
- **Chat Completions replies are parsed like the TypeScript protocol (#1576).** The Rust port was stricter than the reference in four places that could fail a turn whose answer was already readable, for example by demanding a choice `index` that a gateway may omit or renumber.
- **A native Session can move to an existing workspace (#1573), and the move now finishes (#1568, #1569).** The move goes through the external-directory permission boundary and is scheduled after the running work settles, with history, message IDs, tools, usage and selected context carried over. The freeze is released only after activation and placement are verified, and a Session on the default route no longer exports a null model binding.
- **JSONC is decoded as UTF-8 (#1587).** The scanner appended each byte as a character, silently corrupting Chinese keys and values, accented paths and emoji — including in plain JSON documents.

## Configuration

- **Every effective value can be explained (#1589).** `miao debug config --sources` reports the document that won, the values it overrode, and each document's scope — global, project, local `.miao`, environment override — using the same ordered merge the rest of the product reads, with redaction applied to every leaf.
- **An ignored key is reported with a fix (#1592).** Loading stays tolerant, but each document now gets a strict probe whose refusals name the file, the key path and the ignored value, split into unknown keys, missing keys and wrongly shaped values. Because a typo is usually a key the location uses elsewhere, the suggestion comes from the keys the loaded documents already define at that level.
- **Precedence has one answer in both readers (#1601).** A shared golden case runs the TypeScript reader and the engine over the same ordered source plan and requires the same result for every leaf. It caught two defects: the engine's merge dropped keys no later document mentioned, and `miao debug config --sources` listed a scalar that a later object had replaced as still effective.
