# miao v0.3.0

This release clears the native engine for daily driving: long sessions up to
1M tokens work end to end (runaway guards raised, overflow now compacts and
retries instead of failing), engines reclaim themselves when idle, personal
Google accounts can log in with their browser, and native-session cost
reporting is priced, aggregated and observable.

## Added

- **Personal Google account browser OAuth**: log in with a personal Google
  account (no API key) for personal-Gemini access — browser and manual login
  methods, token refresh and credential storage (#1321) and the provider
  surface that serves it (#1322).
- **Engine auto-reclaim**: product-spawned engines now shut down gracefully
  after 15 minutes without any request, event or progress notice
  (`MIAO_ENGINE_STDIO_IDLE_SECS` to tune; 0 disables) instead of lingering
  forever after a client crash (#1323).
- **Response-side usage dump**: `MIAO_ENGINE_RESPONSE_DUMP` appends one JSON
  line per completed provider call — model, timestamp and the raw usage frame
  including cached and reasoning tokens — pairing with
  `MIAO_ENGINE_REQUEST_DUMP` for prefix-cache triage (#1309).

## Fixed

- **1M-token sessions work end to end**: the snapshot/fork projection,
  history selection and session snapshot runaway guards sat below what a
  legitimate large Session serializes to and rejected whole operations;
  all three now sit at 64 MB / 20k messages, with the compaction budget
  gate above them deciding when compaction runs (#1310, #1324).
- **Open-boundary overflow compacts and retries**: when a read-heavy turn
  overflows the compaction trigger mid-turn, the engine refuses and the V2
  prompt admission now closes the boundary, runs a compaction pass, waits
  for the `history.compacted` event and re-admits the exact prompt once —
  durable-input reconciliation makes the retry idempotent (#1314).
- **Native-session cost reporting**: usage is priced from the matching
  recorded provider identity (#1318) and aggregated atomically across
  session ancestors (#1319); the session projector starts before sessions
  are created (#1317).

## Verified

Live acceptance on this machine and in CI: the R4.1 quality suite (native
42/45 vs TypeScript 39/45, #1295), the cost benchmark rerun (deepseek rust
14/14 for a second consecutive round, #1291), a 12-scenario functional
conformance suite with four product fixes (#1306), real crash-recovery and
1M-window compaction drills (#1290, #1296, #1311), and artifact drills
covering Windows cross-version, Linux cross-version and Intel macOS under
Rosetta 2 (#1303). Remaining known gaps and their dispositions are recorded
in `docs/experiments/`.
