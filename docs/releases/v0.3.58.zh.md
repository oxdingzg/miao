# miao v0.3.58

v0.3.58 统一了侧栏的分节节奏，并修复 opencode-go 路由的网关会话头。

## 分节节奏统一（#2793）

- 侧栏每个 `▾` 分节现在都在一个空行后开始，无论它位于列中哪个位置——此前 Changes 与 Goal 会紧贴上方内容，间距还取决于是否有活跃目标。

## opencode-go 网关会话头（#2762）

- 派生的 opencode-go 路由现在携带上游网关所期望的会话头，与主路由一致。
