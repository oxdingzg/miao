## [0.2.0] - 2026-10-10

miao 0.2.0 开启 0.2 系列,并汇总了 0.1.x 的全部工作。0.1.x 期间,会话核心重建在持久的 V2 记录之上,远程控制端到端落地,编辑、补丁、git 等热路径迁移到原生 addon 并接入操作系统沙箱,成本与延迟控制也逐步调优。0.2.0 在此基础上延续,并加入 Rust M0 引擎。本页汇总整个系列,每个版本的细节见 changelog。

### 会话核心与存储

- V2 成为唯一的会话运行时。V1 运行时以及旧的 session、permission、question、sync 路由均已移除,所有客户端都读取持久记录(#324、#299、#427、#416、#418)。
- 存储支持多窗口共享与独占迁移,运行时会话按窗口归属,窗口采用 attach-first 启动,schema 升级不再阻塞打开窗口(#256、#259、#336、#421)。
- 载荷改为内容寻址:超大的附件与工具输出移入 blob store,提供 `miao db externalize-blobs`、`gc-blobs`、`retention`,并由 `miao db status` 报告 V1 到 V2 的迁移指标(#55、#61、#77、#305、#329)。

### 远程控制

- Hub 账号基础:持久认证、中继角色,以及一次性的 Runtime 升级票据(#98、#99、#110)。
- 签名设备授权与按账号隔离的签名花名册(带边界授权),并支持同账号一键连接设备与可信浏览器设备登记(#469、#476、#480、#482、#487)。
- 浏览器配对可跨社交登录续接,使用私有 cookie 与加密的会话工作区(#124、#128、#130、#464)。
- 推送与原生 iOS 应用:账号绑定的推送注册与加密的通知上下文,通过有界的 APNs 投递(#146、#147、#155、#158、#159、#97、#119、#150)。

### 原生加速与沙箱

- `@miao/native` addon 内嵌进二进制,承载编辑匹配与补丁推导,`MIAO_NATIVE=0` 时回退到 TypeScript(#76、#103)。
- `git status` 在 `MIAO_NATIVE` 下通过 gix 在进程内运行,失败时回退到子进程路径(#492)。
- 沙箱通过配置或 `MIAO_SANDBOX` 选择性开启,`bash` 在 macOS Seatbelt 或 Linux Landlock 下运行,另有 Windows AppContainer 后端(#435)。

### 成本与延迟

- 工具 schema 在协议边界统一规范化,对象根或顶层组合子不再让整轮失败(#491)。
- 检测并中止重复输出(包括带 markdown 强调的重复句),且不重放工具调用(#495、#53、#127)。
- 缺少终止帧或瞬时失败的流会重试,而不是让整轮失败(#440、#269、#29),并记录可度量的延迟基线(#239)。

### 终端界面

- 流式输出时 transcript 保持吸附在末尾,并能从视口错位中恢复(#322、#424、#445、#474、#488、#497)。
- Esc 中断当前回合,同时排队中的提示得以保留并继续推进;用户消息带提示符(#431、#407、#489)。
- 子代理活动内联显示,Todo 面板随实时更新刷新,`/clear` 就地开启新会话,侧边栏列出最近的跨会话消息(#337、#429、#272、#501)。

### 引擎

- Rust M0 引擎落地:`miao-engine` 作为独立进程运行,配有 stdio JSONL 的 host client 与 headless driver,可订阅它、提交提示、处理审批,并等待 `run.finished`,使用独立的引擎数据库(#498、#499)。
- 引擎新增 `bash` 工具,基于 pty 执行进程(#503)。

### 自 v0.1.31 起

- #503 为引擎加入基于 pty 执行进程的 `bash` 工具,#499 落地 Rust M0 引擎,#498 提供 host client 与 headless driver。
- #501 在侧边栏展示最近的跨会话消息。
- #500 让跨窗口的会话唤醒变为建议性:为其他窗口持有的会话接纳的消息会被保留,而不再报错。
- #497 修复 transcript 窗口来回振荡成空白视图;#494 稳定了 question 提示的测试。

### 升级说明

安装新版后请重启 miao 窗口。更新磁盘上的程序不会替换仍在运行的旧进程中的代码。0.1.x 移除了 V1 运行时与旧的网络 SDK,仍依赖它们的客户端和插件需要迁移到 V2 与 `@miao/client` / `@miao/sdk`。模型目录仅从 miao 自有源读取。

### 分发说明

Windows 二进制目前未进行代码签名。
