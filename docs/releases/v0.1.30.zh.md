## [0.1.30] - 2026-10-09

### 修复

- 工具 schema 现在统一在协议边界规范化:输入 schema 缺少顶层 `type`,或顶层带有 `anyOf`、`oneOf`、`allOf` 的工具,不再让整轮对话失败。此前 Anthropic、Bedrock、Gemini 会直接拒绝整个请求并报 `tools.N.custom.input_schema.type: Field required`,受影响的是该轮的所有消息,而不只是对出问题工具的调用。原先只有 OpenAI 风格的线路恰好做了规范化,现在所有非 Gemini 线路统一兜底:对象根且无顶层组合子的 schema 原样通过,顶层组合子会被合并为 `properties` 对象并设置 `additionalProperties: false`(#491)。

### 升级说明

安装新版后请重启 miao 窗口。更新磁盘上的程序不会替换仍在运行的旧进程中的代码。

### 分发说明

Windows 二进制目前未进行代码签名。
