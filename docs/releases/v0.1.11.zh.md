## [0.1.11] - 2026-10-05

### 新增

- **ios**：支持仅提供 OAuth 的 Hub 登录，并可预配置 Hub 地址（#194）。本次包含 iOS 源代码改动；CLI 下载包不包含 iOS 应用。

### 修复

- **ios**：登录成功后自动返回工作台；已有登录状态下仍可打开账户管理。
- **runtime**：客户端按通信协议兼容性连接经过身份验证的 Runtime，不再要求软件版本号完全一致。更新安装文件后，新开的窗口可继续连接现有 Runtime（#195）。
- **runtime**：状态与停止命令支持跨软件版本；状态显示后台服务的实际版本和协议，停止命令会等待数据库所有权释放（#195）。

### 升级行为

更新安装文件不要求退出所有窗口，也不会停止正在执行的任务。旧窗口继续运行，新窗口使用已安装的新客户端并连接兼容的共享 Runtime。后台 Runtime 的执行代码保持原版本，直到显式重启；自动安装不会重启活动会话。
