## [0.2.1] - 2026-10-10

miao 0.2.1 is a patch release on the 0.2 line.

### Fixed

- **core**: a Session whose auto-title call failed once kept its `New session` placeholder for the rest of the process, so the terminal tab showed a bare `miao` instead of `miao | <title>`. A transient title-model failure (a 5xx, or a plan-limited small model answering 403) stranded the Session, and the gate was also pinned to exactly one user message. The runner now retries titling on a later turn while the title is still the placeholder, and titles a Session whenever it has at least one user prompt (#507).
