# miao v0.3.66

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.66.zh.md)

v0.3.66 lowers the auto-compaction trigger to 88% (from 90%) so sessions get more headroom, and gates the Windows-only TS tests that could never pass there.

## Auto-compaction at 88% (#2938)

- The trigger moved from 90% to 88% of the context window, leaving more room for the summary and the operator's next turn.

## Windows TS unit leg goes green (#2938, #2917, #2919)

- Seven test groups that could never pass on Windows are now gated with documented reasons (Unix-only fd constructs, POSIX-only filenames, process/shell layer retired with the engine migration).
- The permission classifier now sees protected paths whatever separator arrives (#2917).

## /accounts multi-key routing works (#2931)

- Storing a second key for one provider no longer fails the configuration reload.

## Other fixes

- Schedule edit dialog prefills the current expression and validates locally (#2934).
- A running job's output is kept in memory for the jobs answer (#2925).
- The jobs dialog previews output instead of the result envelope (#2923).
- Compaction is planned by size and reports what it is doing (#2920, #2921, #2912).

## Known issues

- `tests/web.rs` crashes with `STATUS_STACK_OVERFLOW` on Windows (#2926).
- `tests/wakeup.rs` can time out under CI load (#2932).

## Upgrading

`miao` on the `latest` channel updates itself; otherwise re-run the installer.
