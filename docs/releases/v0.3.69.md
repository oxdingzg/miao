# miao v0.3.69

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.69.zh.md)

v0.3.69 adds a second account per provider, says when a newer build is waiting on disk, and fixes the request budgeting and argument parsing cases that made long sessions and forwarded flags fail.

## A second account for the same provider (#2975)

- Re-entering a key updates its credential row in place instead of replacing it, so routes and accounts pinned to that id stay attached.
- The model picker gains **add account**; the cockpit dialog collects a label and the engine keeps both rows distinct.
- The routes manifest re-derives from configuration and store rather than patching entries.
- Per-provider tool gates: short anchors, batch edits and the code index can be toggled per provider.

## The status strip says an upgrade is waiting (#2978)

An upgrade swaps the launcher's symlink; a running window keeps its own build, and the footer version is a compile-time constant. When the installed build is newer than the running one, the strip keeps `0.3.69 installed · restart to apply`. It is read once at startup, because restarting is the action it asks for.

## Long sessions stop asking for more output than the window holds (#2985)

deepseek-class routes declare their output capacity beside the context window, and the endpoint counts input plus requested output against that window. Budgeting only used the window, so a 655K-input session could request 393,216 output tokens and be refused by exactly one token, with two overflow recoveries unable to shrink past the bound they had computed from the unreserved window. Compaction and the bound budget now subtract the route's declared output capacity first.

## Forwarded `serve`/`acp` flags are read per token (#2991)

`--auto-approve` followed by any forwarded `MIAO_ENGINE_*` knob failed with `missing option value`: the pair loop let a valueless flag consume the next flag as its value. Flags are scanned per token now — `--auto-approve` stands alone or spells an explicit `true`/`false` — and the accepted grammar is unchanged.

## Oversized Retina screenshots attach (#2988)

A 4–8 MB clipboard PNG pushed its base64 past the engine's 8 MiB attachment cap, so the admit bounced the prompt and read as Enter doing nothing. On macOS, clipboard images over 4 MiB are re-encoded through `sips` as JPEG (quality 80, capped at 2400 px); the original is kept when the re-encode fails or does not shrink.

## A job or monitor that panics now settles (#2992)

A background job whose task panicked was recorded `unknown`, and a monitor whose task panicked stayed `running` with no process behind it. Both settle through the ordinary terminal paths: the job records `failed` with the panic error, and the monitor finishes durably the way a stop would.

## Smaller fixes and maintenance

- The media test's recovery reopen retries through the lease teardown window instead of panicking on `Busy` (#2995).
- App i18n parity no longer compares the retired Electron locale (#2989), and a needless `mut` no longer breaks the Linux clippy leg (#2990).
- The Electron desktop shell is retired (#2986) and the TypeScript engine implementation now lives under `packages/engine-ts` (#2987). Nothing shipped changes: the product is still the Rust binary.
- `bun run lint:dead` gates the tree against files nothing imports (#2980), after the four files found by the first audit were removed (#2974).
- Package layering (#2973) and the development workflow (#2993) are documented as they actually are.

## Upgrading

`miao` on the `latest` channel updates itself; otherwise re-run the installer. A window that was already running keeps its build until you restart it — the status strip tells you when that is the case.
