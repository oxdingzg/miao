## [0.1.26] - 2026-10-08

### 后台续作与消息可靠性

- **monitor**：后台输出及完成通知先进入持久化通知队列，再唤醒空闲会话；修复“界面已显示 CI 完成、agent 却要等用户追问才继续”的问题（#447）。回归测试验证无需用户输入也能执行后续工具。
- **定时续作**：自动消息不再作为用户 prompt 排队；同一定时任务最多保留一条未处理通知，避免长任务期间每次定时触发都累积相同的 QUEUED 卡片。通知等当前工具续作结束后处理，并遵守机器唤醒额度（#450）。
- **发送重试**：重试传输失败时复用稳定的入队 ID，避免重复提交；保留失败提示和可恢复的输入状态（#448）。
- **Todo**：`todo.updated` 实时刷新右侧任务面板（#429）。

### 显示、输入与运行稳定性

- 自适应消息视口覆盖及滚动回归修复（#445）；Web 时间线完成 V2 记录原生渲染切换（#428）。
- 输入框支持 Ctrl+Home / Ctrl+End（#439）。
- 展开嵌套的 Responses 错误，保留错误详情，并正确重试暂时性流错误（#440）。
- 正确识别 Windows 独立安装与升级（#437）。
- CLI 子进程测试按平台串行执行，CI 检查按改动范围触发，发布前仍要求适用检查成功；修正旧事件格式的浏览器回归测试（#443、#444）。

### 升级说明

安装新版后请重启 miao 窗口。更新磁盘上的程序不会替换仍在运行的旧代码；旧版共享 Runtime 持有的会话锁会保留到对应进程退出。新版本中的后台通知与定时任务行为不会追溯改变旧进程已经创建的任务。
