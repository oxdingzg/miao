# miao v0.3.26

v0.3.26 turns the Rust engine into a runtime that can hold more than one
conversation: Sessions can now leave each other durable mail, and the release
ships one native binary per platform instead of packaging a script around a
build directory. The rest of the release goes where an operator feels it —
usage that adds up to a number, a TUI whose layout holds together on wide
terminals, and an engine that stops walking journals to answer simple
questions.

## Engine and context

- **Inter-Session messaging (#2310).** A turn can call `send_message` and the
  mail lands in the peer's durable inbox with attribution ("Message from
  Session a"), so the peer can tell a neighbour's request from its operator's
  instruction. Authorisation is per target, `wake: never` delivers without
  starting the peer, and a denied target receives nothing.
- **A start bills the credential you choose (#2307).** Stored credentials are
  selected per start; a fork uses the account at its requested history
  watermark, and account changes do not promote agent defaults into explicit
  model pins.
- **The catalog stops walking journals.** The Session list is answered in one
  transaction (#2306), and the event kind is indexed so startup recovery and
  the catalog stop scanning every row (#2300, #2326).
- **The storage lock names its holder (#2296).** A contender waits a bounded
  time and the error says who held the lock, instead of blocking forever.
- **Housekeeping:** free pages are handed back on a database created from
  scratch (#2269), a permission database opened mid-switch is retried (#2279),
  and a child answer is read as the object it is (#2313).
- **The host plugin-hook bridge is deleted (#2316).** Routing and permissions
  come from product config; the native path is the only path.
- **Session naming stays with the host (#2293).** The engine no longer derives
  a title from the first prompt — the host owns naming through its title model.
  The TUI, which has no host title model, names a fresh Session from its first
  prompt itself (#2294).

## Usage and cost

- **One number for the run.** The CLI reports what a run cost as a single
  `usage_total` event (#2312), and the benchmark shows it (#2311).
- **Delegated work is on the bill.** The server reports what a Session's
  delegated work cost (#2308) and tracks auxiliary provider calls — compaction,
  titles, background turns — as a separate `auxiliary` group (#2339); the
  client types were regenerated for it (#2342).

## TUI

- **The body fills the window.** The sidebar holds the right edge and the prose
  fills everything left of it (#2291, #2340); the transcript wraps at that
  column instead of a capped, centred measure (#2285), the composer sits in the
  same column (#2286, #2337), the landing list spans the window, and the status
  line lines up with the body (#2295).
- **A hierarchy instead of one grey (#2314).** The sidebar's todo text is muted
  to match the transcript (#2346), and the tab title is cut by display cells
  rather than characters, so a CJK title stays on the strip (#2341).
- **Typing echoes during a run (#2320).** Frames paint once per batch, so the
  composer keeps up while output streams.
- **Escape answers a pending approval (#2343).** An approval the engine no
  longer holds no longer traps the keyboard: Escape answers it like any other
  key reaches the panel.
- **Smaller repairs:** a pasted path is read instead of sent as text (#2282),
  copy takes the selection rather than the last response (#2277) and no longer
  leaves a gap after a wide glyph (#2330), chords come from the live keymap
  (#2302), transient notices expire (#2284), the transcript says when it has
  stopped following (#2283), injected context paints as a note instead of an
  operator prompt (#2309), `--attach` opens the Session the operator asked for
  (#2301), the sidebar's title and age stay in step with the Session (#2303),
  and the home list keeps one line per Session, truncated by cells (#2288,
  #2289).

## Release and packaging

- **One native artifact per platform (#2334).** The release publishes the
  native binary beside the engine (#2315), and each leg smokes the artifact
  where the build wrote it (#2331, #2335), so a packaging mistake fails the leg
  that made it.

## CI and tests

- **Assertions read the screen, not the byte stream (#2317, #2323, #2345).** A
  repaint writes cell runs separated by cursor motions, so matching the raw
  stream passed or failed with the frame diff; the interaction suites now
  reconstruct the terminal, and a layout change no longer flips whichever
  assertion was unlucky.
- **Fixtures place Sessions where the runtime does (#2344).** The messaging
  tests canonicalised one root and not the other, which only Linux forgives;
  macOS and Windows went red on a placement conflict that was a path spelling.
