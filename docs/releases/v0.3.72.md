# miao v0.3.72

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.72.zh.md)

v0.3.72 makes the desktop window a working client and gives the sidebar's usage figures a layout you can read.

## The desktop window runs conversations (#3020)

The Tauri build now does what the terminal does: create a Session, admit a prompt, and read the answer as it streams — Markdown-rendered through the same `@miao/session-ui/markdown` the product uses, with `provider.delta` text filling a live bubble, `tool.started` rows naming what ran, tool results and failed-run reasons in the transcript.

Around the conversation: `/new` and `/clear` from the composer, pasted images travelling as `{data, mime}` attachments, rename a Session by double-clicking its row, and a header that names the answering model and agent. Esc — or the button, which becomes 停止 while a run is open — cancels the turn.

The sidecar starts with `--auto-approve` and answers questions with their first option, so an unattended conversation cannot hang waiting on a prompt the window has no surface for. The app ships as `miao` / `ai.miao.desktop` instead of the development identifier.

## The sidebar's usage rows are a table (#3024, #3023)

Long model names pushed `in`/`out` off the row. The models are now a table with one header:

```
model                        in     out cache
- deepseek-v4-1-flash-…   747.7m  979.4k   94%
- glm-5.3-flash           446.1m   12.0k   93%
```

The name column owns the cells the figures leave and truncates there; `in`/`out`/`cache` stay right-aligned under their headers, and the hover tip keeps the untruncated sentence.

Two figures stopped lying: a row no longer prints `0 attempts` beside a replay (a zero says nothing its absence does not), and `ctx 184.8k / 655.4k · 28%` is spelled `context 184.8k of 655.4k · 28%` with a hover that says compaction starts at 80%.

## Snapshot containment on Windows (#3026)

`snapshot::within()` canonicalized the workspace root and then stripped that root from the path it was handed. On Windows `canonicalize` answers with the verbatim prefix while the caller's path keeps the plain form, so a snapshot plainly inside the workspace was refused as escaping it. Both sides are de-prefixed before the comparison.
