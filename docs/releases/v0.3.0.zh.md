# miao v0.3.0

本版本为 native engine 的日常驾驶扫清障碍：最长 1M token 的会话端到端可用
（runaway 守卫提升、溢出改为压缩后重试而非失败），空闲引擎自动回收，个人
Google 账号可浏览器登录，native 会话的成本报告完成计价、聚合与可观测。

## Added

- **个人 Google 账号浏览器 OAuth**：无需 API key，浏览器登录个人 Google
  账号即可访问个人 Gemini——浏览器与手动两种登录方式、令牌刷新与凭据存储
  （#1321），以及配套的 provider 面（#1322）。
- **引擎自动回收**：产品拉起的引擎在 15 分钟内没有任何请求、事件或进度
  通知时优雅退出（`MIAO_ENGINE_STDIO_IDLE_SECS` 可调；0 禁用），不再在
  客户端崩溃后永久残留（#1323）。
- **响应侧 usage dump**：`MIAO_ENGINE_RESPONSE_DUMP` 为每次完成的 provider
  调用追加一行 JSON——模型、时间戳与原始 usage 帧（含 cached/reasoning
  tokens），与 `MIAO_ENGINE_REQUEST_DUMP` 配对用于前缀缓存分诊（#1309）。

## Fixed

- **1M token 会话端到端可用**：snapshot/fork 投影、历史选择与会话快照的
  runaway 守卫低于合法大会话的序列化体积，会整体拒绝操作；三者统一提升到
  64 MB / 20k 消息，由其上的压缩预算闸门决定何时压缩（#1310、#1324）。
- **开边界溢出改为压缩后重试**：读取密集的回合在回合中途越过压缩触发线时
  引擎拒绝请求；V2 prompt 准入现在会闭合边界、执行压缩、等待
  `history.compacted` 事件并以幂等方式重新接纳同一 prompt 一次（#1314）。
- **native 会话成本报告**：按匹配的已记录 provider 身份计价（#1318），跨
  会话祖先原子聚合（#1319）；session projector 在会话创建前启动（#1317）。

## Verified

本机与 CI 内完成实盘验收：R4.1 质量套件（native 42/45 对 TypeScript
39/45，#1295）、成本基准重跑（deepseek rust 连续第二轮 14/14，#1291）、
12 场景功能 conformance 并修复四个产品缺陷（#1306）、真实崩溃恢复与
1M 窗口压缩演练（#1290、#1296、#1311），以及覆盖 Windows 跨版本、Linux
跨版本与 Rosetta 2 Intel macOS 的 artifact drill（#1303）。剩余已知缺口
及其处置记录于 `docs/experiments/`。
