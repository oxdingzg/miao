# miao v0.3.10

v0.3.10 is a maintenance release on the road to the single kernel: a long diff preview can no longer take the TUI down, the transcript and the composer line now say whether a turn is still running, and a directory keeps one location service map again — the root cause of the permission stalls behind the recent CI failures.

## Product

- **A long diff preview can no longer crash the session.** A collapsed patch preview was cut at a fixed line budget while the final hunk header still promised the unsent lines; the diff renderer parsed that preview and threw `Added line count did not match for hunk at line N` from a render memo, which took the whole TUI with it. The cut hunk's header is now rewritten to the lines actually kept, and the context highlighter parses tolerantly, so a malformed patch costs highlighting rather than the session.
- **The transcript says which step is still running.** The last assistant step keeps a live footer for the whole turn — `✳ Agent · model · working · 12s` while it generates, `◐ Agent · model · waiting for model · 12s` when the request is dispatched but unanswered — and settles into `✓ … completed 12:34 · 1m 2s` or `✗ … stopped · interrupted`. The clock unmounts with the footer, so an idle session holds no timer.
- **The composer line keeps the live state next to a prompt receipt.** While a turn runs with queued or steered prompts, the line shows the receipt (`Received · joins next turn`, `Queued · 2 pending · starts when idle`) and the current phase together instead of only the receipt, so a working session no longer reads as frozen.
- **An unavailable `--model` is reported before the TUI opens.** An explicit id this channel cannot serve exits with `Model not found: provider/model` instead of silently opening the fallback model after a three-second toast; `miao models` now lists what this location can run.

## Engine

- **Every Session is admitted through the engine inbox (S2).** `SessionV2.prompt` admits one durable `session_input` row through `SessionAdmission`; engine placements admit into the engine's storage and the product projects the resulting `input.admitted` event, while `MIAO_INPUT_TS_ADMIT=1` restores the pre-S2 writer for rollback.
- **One location service map per directory.** S2 gave a directory two admission paths, and a provider graph built for one of them could produce a second `LocationServiceMap`; a permission reply then landed in the copy nobody was waiting on, the tool call never resumed, and an ACP session hung until its timeout. The map is now cached by graph shape and built from one shared replacement list, so both paths land on the same map.
- **Permission rules are evaluated in the engine (S6 step 1).** The layered decision was extracted into a pure `PermissionV2.decide` and ported to the engine with a TypeScript-generated golden corpus (`tests/differential/permission_decide.json`, kept aligned in CI), plus a `permission_evaluate` query that returns the effect, the effective ruleset and the authority digest a derived grant must cite.
- **Product config is derived in the engine (S5 step 2).** `serve` and `acp` accept `--config-dir` and derive the product policy — workspace mode, sandbox switch — from the product's own documents and environment; an explicit `--policy` still wins.
- **GLM thinking blocks are no longer sent as Responses content.** Chat Completions reasoning, including GLM's preserved thinking, is not a Responses reasoning item; it stays in the transcript but is no longer sent as visible text or turned into fabricated encrypted state.

## Build

- **A Windows release build survives a locked probe image.** The smoke-test probe could still hold its image open when the disposable directory was removed, failing the build after the test had passed — 0.3.9's `windows-2025` job died exactly there.
