# miao v0.3.21

v0.3.21 为自定义 provider 武装自动压缩：跑在 catalog 不认识的 provider 上的会话（例如在 `miao.jsonc` 里声明的火山方舟路由）现在从操作者自己的 `providers.<id>.models.<model>.limit.context` 取窗口，在 provider 拒绝请求之前先压缩，而不是一路涨到硬上限。

## 引擎

- **压缩窗口跟随操作者的 provider 配置（#1886）。** 自定义 provider 对 models.dev catalog 不可见，`contextLimits` 从未被推导、自动压缩一直关闭——这类路由上的会话会一路增长到 provider 返回 `Input exceeds the context limit (1048568 tokens)`。`engineSettings` 现在读取声明的上限并按 catalog 路径同样的 ratio/headroom 推导；显式 `engine.context_limits` 仍最优先。
- **它配套的溢出重试已在 v0.3.20 发出：** 摘要请求自身溢出时会用硬截断后的正文重试一次，停在边界上的会话因此能自愈而不是死循环。

**完整更新日志**：与 [v0.3.20](https://github.com/oxdingzg/miao/compare/v0.3.20...v0.3.21) 对比。
