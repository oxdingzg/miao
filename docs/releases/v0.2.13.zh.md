# [0.2.13] - 2026-10-16

miao 0.2.13 让 native Session 的路由诚实地交给 operator，并修复自动压缩：TUI 不再对已由引擎 operator 配置完成放置的 Session 套用 TypeScript 侧的 agent/model 偏好，自动压缩背后的 summarizer 调用也不再在真实模型上永久卡死。

### 新增

- **Native operator 路由**：Session 信息新增 `execution: { engine, selection }`，服务端对引擎放置的 Session 报告 `rust`/`operator`。对该策略，TUI 直接收下原始 prompt：跳过此前作为不被支持的调用发出的 admission 前 agent/model 切换，无需目录内模型即可提交，选择器在 operator 提示下保持锁定，并在底栏把路由显示为 `Native`。TypeScript Session 的选择行为保持不变（#904）。

### 修复

- **自动压缩卡死**：summarizer 只消费最终回复，它交给 provider 的进度通道无人读取。流读取器按帧等待发送容量，任何超过通道十六帧容量的真实摘要都会让读取器永久阻塞 —— 首个事件早已解除 first-event 死线，而 idle 超时只盯着网络字节，那些字节早已全部到达。于是对真实模型的每一次自动压缩都退化为 `compaction.failed: summary timeout`，而 provider 数秒内就已答完。现在 summarizer 在调用期间排空该通道；回归测试钉住超出通道容量的回复，且仅在回退 drain 时会在五秒上界处失败（#905）。
- **TestFlight 签名**：TestFlight 签名默认改用云端托管证书（#900），改从 macOS 26 runner 上传构建（#902）。
- **发布写入**：使用专用 token 写入 release（#901）。

### 验证与升级

- 通过惯用的 miao 自动更新渠道升级，或使用仓库安装脚本。引擎修复由端到端回归测试覆盖，并在构建主机上以「仅回退修复」的方式验证：复现测试在没有 drain 时卡到上界，带上 drain 后通过。发布产物以启动终端接口做冒烟验证，而不只是询问版本号。
