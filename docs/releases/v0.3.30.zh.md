# miao v0.3.30

v0.3.30 让回答在生成过程中就显示出来，让 `miao upgrade` 真的去升级，并让窗口在分栏之间
不再露出终端自己的背景色。

## 回合边生成边显示

以前一个正在运行的回合什么都不显示，直到操作者再输入一次，整段回答才一次性出现。原因是
一层嵌套：引擎发布的是 `{"kind":"provider.delta","data":{"kind":"delta","delta":{…}}}`，
而读取端在 `data` 上找 delta，而不是 `data.delta`。匹配永远不成立，所以没有任何流式文本。
测试没发现这一点，是因为测试 helper 造的是 `data.delta`——一个没有任何 provider 会发送的
形状——于是测试对着读取端全绿，真实回合却什么都画不出来。

- **正文和工具调用保持到达顺序 (#2479)。** 修好读取之后暴露出下一个缺口：草稿把正文和
  工具调用分成两个字段，于是它先画完所有段落，再画所有 `bash` 行。一个回合是把两者交错
  在一起的，已提交的消息也是这样，所以回合提交的那一刻转录里的顺序会整体重排。现在草稿
  只保留一个有序的 parts 列表——reasoning、text、call——按到达顺序绘制。
- **`provider.delta` 归入必须投递的帧 (#2479)。** 每个 delta 只携带一段流式文本，且没有
  可重放的持久游标，因此它现在和那些「负载下也不能丢」的帧同级。

## Done 就是结束

- **流结束时运行标签即退场 (#2484)。** 回答已经显示在屏幕上之后，状态仍然写着 `Working`，
  因为标签在等持久投影把回合退掉。现在它显示 `Done` 并保留冻结的耗时——这是诚实的中间
  状态：回答已经完整，而在投影卡住、回合未退的窗口里，已用时间依然可见。

## `miao upgrade` 真的升级

- **命令改为执行升级而不是拒绝 (#2477)。** 以前 `miao upgrade` 打印版本号和
  `feed none configured; reinstall the build to upgrade`——一句永远不会变的话，因为仓库里
  没有任何地方设置 `MIAO_UPGRADE_FEED`。现在它会读取最新 release、与当前构建比较，在有
  新版本时运行官方安装脚本。下载、平台产物名、校验和与回滚全部留在 `install` 里——那是
  CI 唯一演练过的路径，第二份实现会和它漂移。
- **`--check` 只报告。** 脚本可以询问是否有更新，而不动已安装的构建。
- **版本比较按字段数值比较。** 字符串比较会把 `0.3.9` 判成比 `0.3.29` 新，从而拒绝那次
  升级。

## `/models` 按 provider 分组，排队的提示可见

- **模型按 provider 分组列出 (#2481)。** `ctrl+o` 打开 provider 过滤列表，模型很多的
  provider 依然可用；选中一个仍需要授权的 provider 会直接给出入口（`miao auth login`），
  而不是静默解析失败。
- **排队的提示在排队期间一直可见 (#2481)。** 以前提交后的提示直接消失在队列里，现在它会
  以排队行的形式显示，直到被提升。
- **引擎提供 `provider_catalog` (#2481)。** 内置模型快照与已配置路由的状态合并，列表反映
  这台机器真正能到达什么。

## 每个单元格都属于页面

- **分栏之间不再有条纹 (#2480)。** `body_columns` 把分隔列之前的区域全给了转录、之后的
  全给了侧栏，于是分隔列不属于任何一侧，保留着终端自己的背景色——在深色主题上就是一条
  可见的竖条。现在侧栏的矩形从分隔列开始、比它承载的内容宽一列，画分隔线的面板因此拥有
  它周围的单元格。
- **侧栏、状态条和输入框各自填满自己的区域 (#2480)。** 侧栏先填满整列再画分隔线；状态条
  即使没有任何提示也绘制自己那一行；输入框不再为自己上下各留一行空白，因为它的边框已经
  画出了两条分隔线。
- **一条测试画满整个窗口并检查每个单元格 (#2480)。**
  `no_cell_falls_back_to_the_terminal_default` 以 120x20 渲染，任何仍带默认背景色的
  单元格都会让它失败。

## 升级

    miao upgrade

`miao upgrade` 现在会自行拉取并安装最新 release。用 `miao upgrade --check` 只询问是否有
更新而不动已安装的构建；用 `MIAO_UPGRADE_FEED` 可以把命令指向内部镜像。
