# miao v0.3.33

v0.3.33 paints a finished turn as one line, prices every turn in its provider's
own currency, and lets the landing screen take a paste.

## A finished turn reads as one line

- **The Claude Code fold (#2519).** A settled turn used to paint every tool
  row and its own thinking header, wall to wall. It now paints one summary
  above its prose — `Thought for 1m 43s, searched for 2 patterns, ran 11
  shell commands` — with the reasoning time summed across the turn's thinking
  parts and tools counted by family (patterns, files, shells, then the rest).
  The prose keeps its place after the summary, a user message lists its
  `[Image #N]` attachments as the tree Claude paints (`├─ [Image #28]`,
  `└─ [Image #29]`), and the turn still streams live in the draft while it
  runs — the last group shows the dynamic state.

## Cost in the currency it was billed in

- **Each turn prices in its provider's currency (#2518).** A run across two
  providers used to add dollars to yuan. The cost roll-up now keeps one
  bucket per currency and reports the split (`byCurrency`), so a mixed run
  reads what each provider actually billed.
- **Hook time and failures land in the task report (#2509, #2517).** The
  usage report names each hook call and counts the time hooks spent and the
  failures they raised, so a slow turn can point at the hook that slowed it.

## The landing screen takes a paste

- **Paste text and images onto the launcher (#2515).** A paste that landed
  while the home screen was up used to go nowhere. The composer accepts it
  now, images included.

## An MCP server can answer websearch

- **`SearchConfig::mcp` selects a catalogue alias (#2521).** `websearch` only
  spoke the REST providers' vocabulary, so a deployment whose search lives
  behind an MCP server had no way to use it. The web client now answers
  through that server's own search tool.

## Reliability

- **Engine failures reach miao.log (#2507).** An engine that died or failed
  a turn recorded the fact in its journal only; miao.log now carries it, so
  the log a user attaches to a report tells the whole story.
- **A Chat turn completes on either terminal frame (#2504).** A provider that
  ends its stream with `response.done` instead of `message_stop` left the
  turn waiting; either terminal frame now completes it.
- **Everything arriving paints (#2502).** The projection refreshes on every
  journal event it consumes, so a prompt shows when it is promoted, a running
  tool row shows while it runs, and usage and compaction state stop lagging
  one refresh behind.
- **`miao upgrade` reports a failed download instead of a phantom update
  (#2500).** The installer script is staged before it runs; a failed download
  says the previous build is still installed.
