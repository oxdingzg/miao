# miao v0.3.53

v0.3.53 让 transcript 里的工具行变得可读。此前 `task_list` 会把整个序列化结果
——包括每个已完成子任务的完整报告——渲染成一整面 JSON 墙；同样落入兜底渲染的
还有 `task_result`、`session_state`、`goal`、schedule 家族、job 家族与
`worktree_list`。

## 工具行按行阅读（#2733）

- **每项一行，绝不倒账本。** `task_list` 现在每个后台子任务读作
  `[✓] close #1974 · completed`，标题行统计任务数与运行数；`task_result` 在标题
  里写明任务与状态，正文就是子任务的报告。会话状态画清单与目标，schedule 显示
  模式与触发计数，job 显示命令与状态，worktree 显示分支与路径。
- **变更行保留语法配色。** 0.3.51 的色块把整行压成单一色相，关键字着色完全
  丢失；现在扫描器在产品的 diff 色块内照常给代码上色，与围栏代码块一致。
- **侧栏模型跟随选择器。** 选择模型后立即重绘会话摘要的 pin，不再等引擎的下一次
  投影。
