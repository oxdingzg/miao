# miao v0.2.25

本版补全原生引擎的迁移故事，并扩展 opt-in 开关：**原生创建**的会话也能 `migrate-back` 回 TypeScript，原生会话的推理与压缩事件对所有客户端可见，`--engine` 标志可让单条命令进出 rust 引擎。

## 新增

- **原生创建会话的 migrate-back**：`session migrate-back` 不再要求先做过前向迁移。原生创建的会话把整条时间线导出为反向 delta（含 user/assistant 回合），放置翻回 TypeScript。delta 回执记录空输入的摘要（不存在可复验的前向 bundle）与文件自身摘要用于字节校验（#1242）。
- **原生推理与压缩回放**：已提交的 assistant 推理块投影为 `reasoning.ended`，journal 的压缩生命周期投影为 `compaction.started`/`ended`（带稳定 id）——回放或投影的原生历史保留推理，自动压缩对所有客户端可见（#1239）。
- **`--engine native|ts`**：`miao run` 与 `miao serve` 接受显式引擎开关。`native` 为新会话启用 rust 引擎并给出合理的默认存储（无需改配置）；`ts` 对单条命令覆盖已配置的 storage。不带标志时行为不变（#1234）。
- **App 上下文面板按模型显示累计用量**（#1237）。

## 修复

- `--engine ts` 正确覆盖已配置的 `engine.storage`（#1240）。
- 引擎归档回退在 Windows 上可用（#1238）；Linux 引擎改为面向 musl 发布（#1235）。
- 验收证据入档：产品级 G1 placement 验收测试（重试采纳绑定、迁移、拒绝二次接管）与 G2/G3（Zed）证据（#1229、#1243）。

## 验证范围

所有改动合入前均通过完整 CI。native-born 反向 delta 导出有 Rust 集成测试（时间线内容、baseline、回执的空输入摘要、文件摘要与 `delta_sha256` 一致、未知会话冲突）；推理/压缩回放有专属投影测试套件；引擎子进程泄漏修复通过"headless run 结束后无 serve 进程残留"断言验证。

## 更新方式

重新运行安装脚本，或让正在运行的 `miao` 在下次检查时通过后台更新获取 v0.2.25。已有会话、凭据和配置都会保留。
