## [0.1.9] - 2026-10-05

### 新增

- **remote-control**：加密的浏览器会话工作区、浏览器 relay 与账号鉴权、持久化浏览器身份与配对、有界实时文本快照、有界 APNs 推送，以及私有命名隧道部署（#124 #128 #130 #142 #145 #146）
- **core**：Command Code 按套餐隐藏当前账号无法调用的模型（#161）
- **remote**：移除旧的本机 IM 连接器与 router，统一并入 remote-control（#162）

### 修复

- **core**：Command Code 模型改为从 catalog 读取输入模态，修复粘贴图片被判定为“模型不支持图片输入”而丢弃的问题（#164）
- **tui**：不再对客户端未打开的会话重复水合、也不在每次水合时重复拉取更早历史（#166 #167）
- **miao**：runtime 正在运行时仍可执行 doctor 报告（#163）
- **release**：版本变更时同步 `bun.lock`（#157）
