# miao v0.3.72

[English](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.72.md)

v0.3.72 让桌面窗口成为可用的客户端，并给侧栏的用量数字一个能读的版式。

## 桌面窗口可以跑对话了 (#3020)

Tauri 版本现在与终端版本做同样的事：新建会话、提交 prompt、边流边读回答——用产品同款的 `@miao/session-ui/markdown` 渲染，`provider.delta` 逐段填充实时气泡，`tool.started` 行写明执行了什么，工具结果与失败原因都进 transcript。

对话之外：composer 支持 `/new` 与 `/clear`，粘贴图片以 `{data, mime}` 附件随 prompt 发送，双击会话行改名，表头显示回答的模型与代理名。Esc——或运行中变成「停止」的按钮——中断本轮。

侧车带 `--auto-approve` 启动，提问按第一选项自动作答，无人值守的对话不会因为窗口没有审批面而挂起。应用以 `miao` / `ai.miao.desktop` 发布，不再是开发标识。

## 侧栏用量行改成表格 (#3024, #3023)

长模型名会把 `in`/`out` 挤出屏幕。现在模型是带表头的表格：

```
model                        in     out cache
- deepseek-v4-1-flash-…   747.7m  979.4k   94%
- glm-5.3-flash           446.1m   12.0k   93%
```

名称列占用数字列剩下的格子并在自己列内截断；`in`/`out`/`cache` 在表头下右对齐，悬停仍给出完整整句。

两个数字不再误导：有重放时不再并排打印 `0 attempts`（零不提供任何信息），`ctx 184.8k / 655.4k · 28%` 改写为 `context 184.8k of 655.4k · 28%`，悬停说明 80% 开始压缩。

## Windows 上的快照包含性 (#3026)

`snapshot::within()` 先 canonicalize 工作区根，再从传入路径里剥掉这个根。Windows 上 `canonicalize` 返回带 verbatim 前缀的形式，而调用方保留普通形式，于是一个明明在工作区内的快照被判为越界。现在两侧都先去前缀再比较。
