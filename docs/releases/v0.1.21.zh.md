## [0.1.21] - 2026-10-07

### 新增

- **core**：日志排干（drain）生命周期管理，并为步骤边界加上上限（#365）
- **app**：时间线改为 V2 原生的回合（turn）构建（#346）
- **core**：只读子代理默认改为后台运行（#352）
- **core**：借助读取快照，把过期编辑变基到当前文件内容上（#350）
- **core**：读取成功后预热语言服务器（#347）
- **core**：todowrite 标记为可并发（#345）

### 变更

- **app**：权限流程切换到 V2，并清理 V1 应用面（#338）

### 修复

- **core**：工具结果里的图像按模型的图像输入能力过滤——修掉智谱等仅收 `['text']` 内容的端点在读图后报 HTTP 400（code 1210）的问题（#359）
- **tui**：中断请求失败（服务端 500、运行时不可达）不再以未处理 rejection 退出进程，改为 toast 提示（#361）
- **core**：修剪工具输出的标记改用中性措辞（#364）
- **app**：稳定 Linux e2e 时间线用例，并为中断分隔线补上专用 locator（#358）
- **core**：worktree 消失被迫迁回主目录时通知 Session（#356）
- **miao**：Windows 升级分阶段标记并清扫残留阶段目录（#353）
- **llm**：按消息内容重试被误分类的容量抖动（#348）
