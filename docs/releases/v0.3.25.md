# miao v0.3.25

v0.3.25 makes a long Session survivable again, and makes the native engine the
default path for the TUI rather than a mode you opt into. A Session that reached
its model's window used to be uncontinuable; it now compacts against its own
model's window, and when a request is still refused the engine shortens it and
retries instead of replaying it.

## Engine and context

- **A Session recovers from a context overflow (#2058).** The endpoint's own
  refusal is recognised rather than read as a bad input, its window is learned
  from the refusal itself, and the refused step is retried inside the same drain.
- **Automatic compaction plans against the Session's own model (#2068).** The
  process-wide `--context-limits` describes one model; a Session on another model
  now takes the window its route declares, then the one a refusal stated, and an
  operator's explicit `context_limits` still wins over both.
- **A refused request is bounded (#2080).** A refusal of the exact history in hand
  is evidence that the request does not fit, even when no provider count exists
  for a previous request, and the trim targets the window minus its headroom
  instead of the raw window — the difference between a retry that fits and one
  that is refused again.
- **Tool answers stay next to their call (#2080).** A message carrying a tool
  result and an image lowered its image into a `user` message first, which put a
  `user` turn between `tool_calls` and the answers the endpoint requires. Tool
  results now precede everything else the same message carries.
- **A busy permission project waits ten seconds, not two (#2055).**

## Tooling

- **One native binary, engine in-process (`abc8d544`).** The TUI runs the engine in
  its own process by default, and the CLI ships as a single native binary.
- **Routes and permissions come from the product config.** The engine route
  manifest is derived from the product config (`7a46bdf4`, `23213c67`), an
  agent's permissions travel into the engine (`f47a58b1`), and a defaulted turn
  says which model it used (`a49b81b9`).
- **The configured default model is honoured (#90303c18).**

## TUI

- **One draft per Session (#2084)**, instead of one draft for the whole process.
- **A failure names its next step (#2198)**, and narrow layouts stay legible:
  `NO_COLOR` is honoured, the leader expires on `leader_timeout`, and scroll speed
  and acceleration follow `tui.json`.
- **New views:** a Session's goal apart from its todos (#2093), each recent turn's
  timings (#2074), background jobs with a preview and a stop action (#2089,
  #2091), scheduled wakeups and cron jobs (#2099), and `/tag` (#2081) — with
  `/recall` restoring an archived tool output (#2070).
- **Smaller fixes:** the window repaints after returning from the background
  (#2085), the tab title no longer ticks in place (#2072), and a blocked MCP call
  shows the full tool name (#2224).

## CI

- **Engine shards no longer die on a full runner disk (#2062).** The suite has 181
  test targets and a full-instrumentation build reached 70 GB of
  `target/debug/deps` on a runner with ~20 GB free, so whichever shard ran out
  first failed with a rustc I/O error that looked like a broken merge. Test builds
  now use `line-tables-only` debug info, the hosted image's unused toolchains are
  reclaimed, and the free-disk guard covers both legs — it had been gated on a
  matrix value that never matched, so it had never run.

## Core

- **Usage role attribution (#2029)**, closing the breakdown of what a Session
  spent on each role.
