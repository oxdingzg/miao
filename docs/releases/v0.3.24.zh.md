# miao v0.3.24

v0.3.24 修复了四类「长会话看起来像坏了」的问题：引擎自我重启被当成崩溃、只有凭据的
provider 无法被路由、流被截断时整轮回复被丢弃、以及 Rust TUI 首页把最新工作埋在成片的
预览文字下。

## 引擎

- **引擎干净退出视为重启，而不是故障（#2028、#2040）。** 引擎刷新项目副本后会以 0
  退出，并期待下一条请求把它重新拉起。Rust 与 TypeScript 客户端都把它报成
  `engine_closed` 并盖在整个会话上；现在干净退出只标记待重建并用一行提示说明，非 0
  退出仍保留原诊断（stderr 尾巴、`Error: Busy` 归类）。
- **只有已保存凭据的 provider 也能被路由（#2033）。** 通过 providers 界面添加的
  provider 只有凭据、没有注册 integration，路由生成时被整段跳过，固定到它的会话一律
  报 `Model is not in the native host route catalog`。现在会回退到已保存凭据，且该
  错误会点名模型与原因。
- **provider 的 HTTP 失败会带上对方给出的原因（#2034）。** `provider HTTP 500` 现在
  附带限长响应体摘要，限流/服务端失败时还带 `Retry-After`。
- **自动压缩对未声明窗口的模型使用保守默认值（#2046）。** 没有声明上下文窗口的
  provider 过去会让触发器整体关闭，上下文一路增长到模型拒绝；现在未知窗口按
  131,072 tokens 运行，provider 侧报上下文超限时会触发一次压缩检查点。

## TUI

- **转录区重新跟随最新内容（#2022）。** 过去滚动一次后，之后打开的会话都会停在最旧的
  位置；现在打开会话即跟随，滚回最后一行会重新接上。
- **首页默认只显示最近 10 条（#2022）**，空格每次多展开 10 条，提示行显示还剩多少条；
  每行预览压成单行截断，时间按显示宽度对齐，多余的「工作区/分支/版本」行已移除。

## CI

- 三条最长腿做了分片（engine ubuntu、integration、blackbox），并加入 macOS runner
  磁盘守卫（#2037）；macOS 腿改为只在 push 到 `main` 与夜间运行（#2048），因为自托管
  runner 不稳定，会让每个 PR 因与自身无关的原因变红。
- 每次 push 到 `main` 都有独立 run，不再取消上一个（#1930）；`crates/miao-tui/Cargo.lock`
  记录了 `libc` 依赖，使 `--locked` 发版构建通过（#1938）。

**完整变更**：与 [v0.3.23](https://github.com/oxdingzg/miao/compare/v0.3.23...v0.3.24) 比较。
