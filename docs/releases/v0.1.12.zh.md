## [0.1.12] - 2026-10-05

### 新增

- **tui**：折叠态思考改为只显示时长标签 `Thought for <时长>`，对齐 Claude Code，不再把模型的英文推理标题写进转录（#206）
- **miao**：检测本地 Runtime 与客户端版本不一致并在 TUI 提示，新增 `miao runtime restart` 以显式重启到当前版本；`miao run` / `miao acp` 在版本不一致时于 stderr 告警（#199）
- **tui**：暴露渲染与保留文本的诊断信息，并在转录中按生产者标注保留文本（#209 #210）
- **remote-control**：支持在 TUI 内登录仅提供 OAuth 的 relay（#205）
- **session-ui / app**：等待期间显示 drain 阶段名称（#204）
- **session**：在会话状态中暴露 drain 阶段（#201）
- **ios**：交换登录码时声明客户端类型

### 修复

- **tui**：会话斜杠命令统一为 `/clear`（#208）
- **miao**：限制 relay OAuth 的等待时长（#207）
- **core**：把语言规则改成请求末尾独立的 system part，明确覆盖推理、进度更新与正文，不再只约束“回复”（#203）
