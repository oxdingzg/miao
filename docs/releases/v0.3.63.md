# miao v0.3.63

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.63.zh.md)

v0.3.63 makes compaction an operation you can watch and stop. The status strip
names the pass instead of calling it a model wait, Escape ends one in flight and
the ended pass no longer counts against the breaker that refuses the next,
`/compact` can be asked for by hand, and a pass that stopped — or one that
cannot start — says so. It also brings provider keys into the model picker,
closes a child that was re-dispatched into a second run and died without its
stop, and bounds a continuation loop that never moved the todo list.

## Compaction you can watch and interrupt (#2905, #2907, #2912, #2889, #2898)

- **The status strip names the pass.** A summarizer call returns no token for
  its whole duration, so every minute of a pass used to read
  `Waiting for model`; the strip now says which compaction segment is running.
- **Escape interrupts a pass.** The turn's cancel token travels into the
  compaction request and is checked before each segment, and the summary stream
  shares it. An interrupted pass records `compaction.cancelled` and is not
  counted against the breaker — the breaker is what used to refuse the next
  pass after a few summarizer timeouts.
- **A pass that stopped, or one that cannot start, is reported** instead of
  leaving the strip on `working` with nothing arriving.
- **The warning fires once, at the compaction boundary**, rather than at 60 %
  and 80 % (#2889), and the separate context-pressure note is gone (#2898).

## The commands an operator reaches for (#2911)

- **`/compact` and `/init` from the prompt.** The engine has carried a durable
  `request_compact` — one checkpoint at the next settled boundary with the
  breaker reset — but nothing in the TUI sent it, so a Session whose summarizer
  had tripped could not be compacted by hand at all. `/init` writes an
  `AGENTS.md` for the project.

## Provider keys in the model picker (#2906)

- **Add or replace a provider's key where you pick its models.** A provider
  that already served routes no longer needs a detour through configuration to
  gain an account, and several accounts stay distinguishable.

## Delegation (#2904, #2891, #2893, #2888, #2883, #2908)

- **The waiting pause counts this Session's own children**, not every
  `subagent_start` row it can find, so a Session no longer freezes waiting on
  work it delegated (#2904).
- **A side question forks the mainline (AGT-06).** A `task { explore: true }`
  copies the Session's history at its newest closed boundary and admits nothing
  back until the mainline asks for it (#2891).
- **The delegation depth cap is tunable and stays a cap** (#2893).
- **A running child row carries its age**, so working and wedged stop looking
  alike (#2888), and a failed background child tells the Session that delegated
  it (#2883).
- **A child re-dispatched into a second run is closed when it dies without its
  stop.** Recovery read starts and stops separately and dropped any id that
  appeared in either, so a historical stop closed a child forever (#2908).

## Loops that no longer run away (#2895, #2901)

- **A continuation loop that never moves the todo list is bounded** (#2895),
  instead of re-injecting the same continuation while the model answers that it
  is waiting.
- **Each optimization can be ablated behind an explicit toggle (VAL-04)**, so a
  mechanism is measured by turning it off rather than by argument (#2901).

## Release and CI

- **A release PR may carry every workspace manifest** (#2910). The version bump
  touches `apps/desktop/package.json` too, and the release path guard now
  admits it so the bump lands in one pull request.
- The acceptance index gained the records for VAL-03's baselines (#2897, #2894),
  AGT-06 (#2896), the sidebar scopes (#2899, #2900), and the AGT-03/TOOL-01/
  CTX-05 runs (#2890). The narrow-pane tests read the rendered grid cell by
  cell so they also hold on Windows (#2902, #2892).
