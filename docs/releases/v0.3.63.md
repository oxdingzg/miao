# miao v0.3.63

[简体中文](https://github.com/oxdingzg/miao/blob/main/docs/releases/v0.3.63.zh.md)

v0.3.63 is mostly about a Session that would not run. A waiting pause that was
supposed to mean "a background job of mine is still pending" also counted every
child this Session had ever delegated to, including children that had finished
hours earlier, so a long orchestration session woke up, answered once, paused
itself, and never reached its todo list. The pause now scopes to this Session's
own background work, and the rows it reads are repaired instead of trusted
forever.

## A waiting Session runs again (#2904, #2908)

- **The pause is scoped to this Session's own background jobs.** A delegated
  child finishing into its own notification is not a bound the parent waits on.
- **A running child no longer freezes its parent.** It ends the drain without a
  pause note and without re-injecting a continuation, instead of prompting the
  provider once per backoff tick on an unchanged todo list.
- **A re-dispatched child that died is closed by recovery.** The child counter
  needs a `subagent_stop` *after* the newest start, while recovery closed any id
  that had ever stopped once — so a child delegated into a second time and then
  killed stayed "running" for the life of the store. Recovery now folds both
  events in sequence order and closes each open child once.

## Compaction that says what it is doing (#2905, #2907, #2889, #2898)

- **The status strip names compaction** instead of showing it as a model wait.
- **Interrupting a turn stops the compaction pass** it was in, rather than
  leaving the pass to finish against a cancelled turn.
- **One warning, at the compaction boundary**, instead of notes at 60% and 80%,
  and no pressure note at all below the threshold.

## Providers and commands closer to hand (#2906, #2911)

- **Manage a provider's keys from the model picker**, including adding a second
  key for a provider you already use.
- **The everyday slash commands** an operator expects are bound by default.

## Delegation that reads like work (#2891, #2893, #2888, #2883, #2895)

- **A side question forks the mainline** (AGT-06) instead of restating history.
- **The delegation depth cap is tunable** and stays a cap
  (`MIAO_SUBAGENT_MAX_DEPTH`).
- **A running child row carries its age**, and **a failed child leaves a
  receipt** for the Session that delegated it.
- **A continuation loop that never moves a todo is bounded**, so a churning
  list cannot re-prompt itself forever.

## Mechanism toggles for measurement (VAL-04, #2901)

- Each optimization mechanism can be ablated behind an explicit toggle, so a
  claim about a mechanism can be measured against its own absence.

## Verification

- CI green on the release commit for `engine` (four shards), `tui`, `cli`,
  `blackbox`, `unit`, and `typecheck`.
- Windows test harness: the shortcut-binding and narrow-pane suites read the
  rendered grid in a way that can pass on Windows (#2892, #2902).

## Upgrading

`miao` on the `latest` channel updates itself; otherwise re-run the installer
from the README. A Session that was paused by the old waiting list resumes on
the next message: the phantom children are closed by recovery on start.
