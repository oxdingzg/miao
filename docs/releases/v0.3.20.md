# miao v0.3.20

v0.3.20 makes the human side of the session honest and quieter: the Todo panel says when its list was last updated and warns when it has gone stale, monitor wakes read like a watch instead of an envelope dump, and a second window can open while older windows hold the shared storage.

## TUI

- **The Todo panel shows its age and flags a stale list (#1876).** A list the agent synced hours ago no longer looks current: the panel shows `updated 3m ago`, and after 30 minutes with open items it says plainly that the list may be stale and asks the agent to refresh it.
- **The newest message opens in a scrollable details view (#1863); queued questions answer once and typed answers work on single-choice dialogs (#1866, #1867); the host's MCP servers appear in a read-only panel (#1864).**
- **An unknown slash command is reported instead of sent to the model (#1868).**

## Engine

- **Monitor wakes read like a watch (#1878).** One message per lifecycle — `watch "<description>" matched:` followed by the matched lines — with no job UUID, no repeated `Matched output:` label, and no second wake for a completed run that already delivered its match. Abnormal settles still speak: `watch "…" failed (exit code 1).`
- **Additive storage upgrades no longer need exclusive ownership (#1872), and the refusal names the live owners when one is required (#1862).** A new window opens over an older one's schema instead of dying on `cannot upgrade Session storage while an older engine run owner is alive`; format repairs still demand that the old owner exits first.
- **A gateway that replays a tool-call id keeps one call (#1870).**
