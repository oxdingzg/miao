# miao v0.3.44

v0.3.44 retires the TypeScript product and ships one Rust binary, and collects
the engine, TUI, CLI and remote-control work landed since v0.3.43.

## One binary is the product

- **The TypeScript CLI and TUI are gone (#2627).** `miao` is the Rust binary:
  it links the engine and runs the TUI in-process. The TypeScript tree now
  builds only the desktop app and the server it embeds, so the packages
  behind the retired CLI, the TypeScript TUI and the TypeScript ACP server
  left the workspace along with the tests that drove them.
- **The prompt and skill text moved out of `packages/core` (#2621).** Personas
  and built-in skills now live in a repository-level `assets/` directory that
  both hosts read, so compiling the crates no longer requires the TypeScript
  tree to be present.
- **nix packages that binary (#2625).** The `miao` package is a
  `rustPlatform.buildRustPackage` over `crates/miao-cli` instead of a patched
  bun compiling TypeScript, and the release script keeps only the
  `--native-cli` path it actually used (#2631).
- **Three core modules went with their last importer (#2641).** The legacy
  environment-variable migration, Session retention and the public event
  manifest had no caller left: the Rust host owns the first two, and the third
  had none before either.
- **`serve` stays only as test support.** A small `src/serve.ts` starts the
  same server the desktop sidecar embeds, so the integration suites keep
  driving it over real HTTP.

## Also since v0.3.43

- **Engine**: Sessions work with git worktrees in-process (#2608, #2618),
  gateway-reported cost is recorded (#2581), every account is routable and
  named in the picker (#2564), a degraded context budget is named when it
  happens, and unhealthy cache states come with a recommended fix (#2535).
- **TUI**: the worktree dialog (#2615), the sidebar's own chord in the column
  (#2624), provider keys stored from the picker (#2556), the last 24 hours of
  usage in the sidebar (#2568), and queued prompts echoed while a turn runs.
- **CLI**: `miao upgrade` updates instead of only reporting (#2477) with a
  verified database backup (#2485), `doctor` reports routing, sandbox and
  dependencies (#2547), and a managed configuration scope (#2541).
- **Remote control and mobile**: manage Sessions from the phone (#2570),
  configure providers and models remotely (#2566), see what needs you across
  Sessions (#2567), a phone-only mode that does not need a computer (#2584),
  and confirmation when a prompt was queued (#2591).

## Upgrading

`miao upgrade`, or reinstall with the `install` script. The Windows binaries
remain unsigned; the release body records that status.
