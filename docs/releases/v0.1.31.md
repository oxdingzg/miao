## [0.1.31] - 2026-10-09

### Added

- Git status can run in-process. `Git.status.entries` now uses the native (gix) status primitive behind `MIAO_NATIVE`, listing untracked files individually, mapping to the production status vocabulary, and deriving per-entry line stats against HEAD. `MIAO_NATIVE=0` or a native failure falls back to the existing `git status` / `git diff --numstat` subprocess path, so behavior is unchanged wherever the native layer is off (#492).

### Fixed

- A model that degenerates into repeating a short markdown refrain no longer floods the turn. The output guard stops a turn whose 64-line prose window is mostly recurring lines, but a refrain such as `**做**。` failed its prose test — the asterisks read as structure — so every bold line reset the window and a loop alternating a bold and a plain refrain ran for thousands of lines undetected. Markdown emphasis is now stripped before that test, so a bold refrain counts as the same line as its plain form (#495).

### Upgrading

Restart miao windows after installing the update. Replacing the executable on disk does not replace code already running in old processes.

### Distribution notes

Windows binaries are currently unsigned.
