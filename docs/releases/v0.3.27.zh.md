# miao v0.3.27

v0.3.27 是原生单二进制第一次作为 miao 的主要使用与测试方式发布的版本:独立启动时,模型选择器会列出操作者凭证覆盖的每一个 provider,thinking 与回答在到达时流式写入 transcript,而且只有配置没有预先授权的操作才会请求批准。本版本还带来原生 retention 工具、只读 VCS diff 工具,以及 TUI 与 CLI 的一轮布局与启动修复。

## 原生独立启动

- **模型选择器列出所有有凭证的 provider(#2380)。** 独立启动从合并后的配置与目录快照派生路由清单:配置优先,其次是每一条存量 key 凭证覆盖的目录 provider(zhipu、xiaomi、deepseek、各家 coding plan),disabled 或能力不符的条目自动让位。选择器按 provider 分组,选中行通过自身 id 解析,不再假设对话框下标与目录一致。
- **配置里的 permissions 到达审批链路(#2393、#2391)。** 引擎从配置推导的策略会把操作者的 `permissions` 规则集翻译成引擎规则,通配 allow 之下的 `run_command` 不再询问,并且 golden 策略钉住了新的 `auto` 字段。
- **流式在进程内可用(#2363)。** 进程内引擎适配器现在会在持久事件轮询之外转发 runtime 的 progress 与 config 广播,transcript 因此可以流式呈现 thinking 与回答,而不是一次性画出一块成品。回答开始之前 thinking 逐字流式显示(#2375);向上回滚时视口首行会标明它属于哪一个问题(#2380)。
- **landing 列表持有键盘(#2380)**:方向键移动选择(包括新增会话动作),可打印字符进入过滤,Tab 把按键交还给输入框,`exit`/`quit` 直接退出而不是变成 prompt;输入框里回车提交一个查询已经精确命中的补全(#2380);只有一行的列表保住自己那一行(b161d714、2acfb625)。

## 引擎

- **snapshot-then-truncate retention(#2361)**:事件日志的保留计划带永不删除的类别,新增 `retention` 子命令用于规划与应用裁剪,消息类别物化到 `engine_message`(#2359)。
- **只读 `vcs_diff`(#2368)** 面向单个变更文件,整条 VCS 链路完成度量(#2377),超大 payload 外置存储。
- **一个目录,一个 Location(#2364)**:无论拼写如何,同一目录解析到同一 Location 与账本;会话目录在只读连接上回答(#2360),MCP 工具校验器改为首次调用时编译(#2370)。
- **MCP 规模化(#2382、#2388)**:超大目录折叠为 search/detail 发现对,暴露的 MCP 集合随每次 provider turn 记录摘要。
- **doctor 增加 WAL、外键与 transfer 诊断(#2354)**,账本摘要在其路径稳定处钉住(#2348 及同期测试),CLI 以 NDJSON 事件上报一次 headless 运行的花费(#2386)。

## CLI 与安装

- **单二进制携带真实的产品版本与构建标识(#2371、#2369)**:`--version` 回答真实版本,不支持的 TUI 选项按名称拒绝并保留旧式逃生通道;worktree 流程新增复制为 worktree 的命令与会话感知的删除(#2383)、删除前预览(#2358)以及卸载命令(#2356)。
- **会话移动先展示影响(#2365)**;冷/热启动与进程资源基准(#2353)加入度量套件。

## 修复

- 绘制失败时保留画面而不是退出(#2374);Escape 可以回应待审批项(#2343 期后续);landing 屏幕保持会话列(#2340);composer 从 transcript 列开始(#2337);终端标题按显示单元截断(#2341);侧栏 todo 文本跟随 transcript 的字重(#2346)。
- 原生单二进制启动端到端修复(#2352):账本经由引擎的 placement 规则解析(#2350),已删除的 plugin-hooks 参数不再进入 `with_product_tools`(#2351),release 上传每个 leg 构建的产物(#2349)。
