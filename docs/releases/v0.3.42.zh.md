# miao v0.3.42

v0.3.42 补完 0.3.41 引入的首页状态行。

## 启动页读取这台机器实际在用的模型

- **首页在没有记忆时回退到最近 Session 的模型（#2562）。** 0.3.41 只显示"操作者上次在
  picker 里的选择"，而从未选过（很常见，模型是在既有会话里选的）的安装仍然一片空白。
  现在首页读取最近一个 Session 的模型（与 `--continue` 相同的 updated_at 倒序），
  并把 `provider/model` 形式的 route id 解析回目录里的 model key，启动页因此能说明
  下一条提示真正会跑在哪个模型上。
