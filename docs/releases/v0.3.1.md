# miao v0.3.1

This patch fixes Escape dismissal during direct Hub sign-in, corrects personal Google account OAuth registration, and reduces the token cost of Bash tool output.

## Fixed

- **Hub sign-in cancellation**: pressing Escape in the Hub picker or subsequent input steps now closes direct sign-in and returns to the conversation, rather than remounting `startInLogin` and restarting the flow (#1330).
- **Google account sign-in**: register personal Google account OAuth under the `google` integration so the login entry matches its provider (#1328).

## Added

- **Compact Bash output**: fold terminal progress redraws, strip ANSI control sequences, redact common credentials, and shorten long lines before sending output to the model. Managed output files retain the raw output. Use a `# nofilter` or `# raw` command comment, or `MIAO_BASH_RAW=1`, to opt out (#1327).

## Verification

- All 17 Hub sign-in tests pass, including new cancellation cases at the Hub picker and computer-name prompt that check for delayed reopening and unexpected login requests.
- TUI type checking and formatting checks pass; both new regression cases fail before the fix.

## Upgrade

Upgrade to `0.3.1` using your existing installation method, then restart miao.
