# miao v0.3.1

This release makes the context budget something you can steer instead of only
obey: cap a model's working window per model with `compaction.max_context`,
send the whole checkpoint through a render-time budget, and recover details
compaction removed with the new `history` tool. On the native engine it also
fixes how tool results reach the transcript — shell output shows as readable
text again, and successful `todowrite` calls no longer report failure.

## Added

- **Per-model `compaction.max_context`**: work in a smaller window than the
  model declares — one value for every model, or a map keyed by
  `"<providerID>/<modelID>"` with globs (longest key wins), as a token count,
  a `"300K"`/`"1.5M"` shorthand, or `"50%"` of the window. Clamped to the real
  window, never raised; `0` restores the model default (#1331).
- **`history` tool**: read full earlier messages in bounded, position-addressed
  pages — pairs with `recall`, which reports the `#seq` positions and returns
  only excerpts (#1334).
- **Checkpoint render budget**: the `<conversation-checkpoint>` injection is
  now bounded at render time (summary 4,096 / recent 12,000 tokens), so rows
  written under older or looser settings cannot re-inflate the window; the
  truncation note points at `recall` (#1333).

## Fixed

- **Native-engine tool results follow the product contract**: engine tool
  completions were projected as raw result JSON with empty structured output,
  so shell calls rendered the whole `{stdout, stderr, ...}` blob as their body
  and a successful `todowrite` showed "Todo update failed". Shell results now
  project to readable output plus the structured fields, and session-state
  mutations unwrap to the payload the renderers expect (#1335).
- Hub sign-in dialog dismisses on Escape (#1330); google-account OAuth
  registers under the google integration (#1328).

## Tooling

- Token-efficient bash output pipeline (#1327).
