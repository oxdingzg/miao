# [0.2.14] - 2026-10-17

miao 0.2.14 fixes native Session event delivery, reconnect recovery, Windows
process working directories, and automatic-compaction boundaries.

### Added

- **Windows interactive terminals**: ConPTY input/output, resize, bounded replay,
  Session isolation and process-tree cleanup, with AppContainer enforcement and
  writable ACLs retained for the terminal lifetime (#949).
- **Workspace custom tools**: an opt-in native worker host loads project
  TypeScript tools, with engine-side authorization and isolated tool failures
  (#947).

- **Visible timestamps**: Session and message times, precise time details and
  completion times in TUI and Web/Desktop (#934).
- **Project auto-accept**: a project-wide permission preference beneath explicit
  Session-lineage and directory choices (#936).
- **Per-turn changed files**: an opt-in timeline summary and turn-review view
  backed by recorded turn diffs (#939).
- **Multiple provider accounts**: core/API/CLI credential management retains
  sibling accounts, supports active-account selection and promotes a remaining
  account when the active one is removed; Web/Desktop settings list and switch
  accounts (#944, #953).
- **Native host configuration**: attach trusted global MCP manifests or shared
  local MCP settings to native owners, with private per-owner manifests and
  explicit rejection of unsupported settings. Verify configured LSP calls through
  the product client (#954).

### Fixed

- **Tool argument streaming**: TS and native watchdogs now time out stalled
  argument input rather than an actively progressing stream (#946).
- **iOS operator diagnostics**: correctly execute the build-status lane and
  surface its failures; query real build processing and encryption status
  (#948).

- **Responses cache affinity**: preserve the Session's provider cache identity
  across native turns (#933).
- **MCP compatibility**: normalize permission input metadata to an object and
  skip tool catalogs when a server does not advertise tools (#930, #932).
- **Snapshot capture**: use literal pathspecs, enforce scope containment and
  create snapshot stores atomically. Capture through temporary indexes and
  publish by atomic rename, recover corrupt indexes, and sweep stale temporary
  files (#945, #956).

- **Live native output**: share one process-wide client-event fan-out and deliver
  native bridge events to attached clients. Native Session totals now read the
  engine usage ledger and resolve pricing through the product catalog; missing
  prices remain unknown (#910, #911, #915, #918).
- **Reconnect recovery**: rehydrate visible and pinned Session history, execution
  state, and pending permission/question requests after SSE reconnect. Invalidate
  hidden snapshots and reject stale reads that would overwrite newer state
  (#916).
- **Windows working directories**: guarded processes now honor the validated
  working directory, including nested directories. Simplify canonical Windows
  paths at the process boundary so `cmd.exe` does not misinterpret them as UNC
  paths and fall back to the Windows directory (#919).
- **Automatic compaction**: wait for a completed answer rather than cutting a
  tool continuation; summarize before promoting newer prompts; allow multiple
  checkpoints in one run. ACP output and loaded history retain original answers
  independently of the provider's compacted input (#937, #940).
- **Concurrent Session creation**: treat an existing projected creator binding
  as the routing authority instead of returning a spurious conflict (#925).
- **Evaluation shutdown**: explicitly cancel upstream SSE readers and release
  the persistent request-budget lock after disposal (#924, #928).

### Validation

- Independent ACP SDK checks cover permissions, cancellation, resume, long
  Sessions, host-configured MCP/LSP, delegation, and parent cancellation
  (#912, #921, #923, #927).
- Real TCP checks cover slow SSE subscriber isolation and durable cursor
  recovery (#922). Artifact drills cover journal retention, upgrade/rollback,
  process confinement, and closed-answer compaction (#920, #940).
- The request-capped live pilot is diagnostic evidence, not full G5 acceptance:
  read-only and multi-read passed; low-threshold compaction exposed the bugs
  fixed here. All 24 authorized upstream attempts were consumed. No new live
  model result for this release is claimed.

### Upgrade

Use the normal miao auto-update channel or repository installer, then restart
existing processes. Update a separately installed `miao-engine` through its
engine installer as well. These fixes do not change the default engine choice.
Published-asset acceptance is recorded separately from source-test evidence.
