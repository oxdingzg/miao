# miao v0.3.18

v0.3.18 让终端在回合运行期间保持稳定，让原生引擎可以正常使用 opencode-go，并落地共享权限权威的前几片。照常升级并启动 `miao`，无需改动配置。

## TUI

- **回合运行中也能立即提交（#1842）。** `ctrl+enter` 立即提交，不再等待当前回合结束；排队中的提示条数同时显示在输入框和状态栏（#1836）。
- **终端保持其尺寸与标题（#1840、#1839）。** Windows 控制台尺寸变化后不再留下过期画面；回合运行时标题带有活动标记，并仍然遵守 `MIAO_DISABLE_TERMINAL_TITLE`。
- **Shell 作业控制后终端归还 TUI（#1823）。** 挂起并恢复作业不再把终端留在子进程状态。

## 引擎与权限

- **opencode-go 回合携带会话头（#1838）。** Effect LLM 路径现在每回合发送 `x-opencode-session`（Session id 的摘要，与原生传输从 `$session` 解析出的路由键一致），网关不再以 `MissingSessionID` 拒绝请求。
- **共享权限权威的前几片（#1761、#1762、#1763、#1765、#1766）。** 源事务、持久化的 Root 断言、按活动源归属结算、目录交接（handoff）以及交接完成后的运行围栏。
- **后台取消绑定其所属运行（#1819）。** 一次运行的取消不再破坏另一次运行的工作。

## 配置与 ACP

- **迁移后未设置的键继续保持缺失（#1835）。** V1 文档从未设置的键，迁移后不再以默认值出现。
- **ACP 移除未加限定的 stdout 重写（#1829）**，并在回放超时时输出 fixture 的 stderr（#1831）。
