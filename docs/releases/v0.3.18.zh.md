# miao v0.3.18

v0.3.18 让 Rust TUI 的界面回到与 TypeScript 版相同的主题语言上，修好了一个会静默重置已配置模型的配置迁移，并让两类 provider 流失败说明真实原因，而不是用一帧晦涩的报文错误终止一轮。

## TUI

- **会话屏不再像另一个应用（#1857）。** Rust TUI 早已移植了主题 token，但应用得太薄：面板边框用了几乎不可见的 `border` 档，选中行也没有底纹。现在会话面板与对话框列表改用 `border_active`、坐在 `surface` 层次上、选中标签画在 `element` 底纹上并用 `primary` 着色，与 TypeScript 版列表选择一致。

## 配置

- **V1 形状的项目配置不再重置已配置模型（#1835）。** `migrate()` 把每个缺失字段物化成显式 `undefined` 键，而合并把“键存在”当作叶子，于是一个没有 `model` 的项目 `.miao/miao.jsonc` 把全局默认覆盖成空，会话回落到目录里最新（且限流）的条目。现在缺席保持缺席。

## 引擎

- **8 MiB 失控响应现在自解释（#1837）。** 响应流守卫原文案是 “message exceeds 8 MiB”，显示为 `invalid request: invalid provider stream: message exceeds 8 MiB`，看起来像请求格式错误。现在明确说明：响应被丢弃、请求本身没有问题。
- **网关把 tool-call 的 index 嵌进 function 也能识别（#1846）。** opencode-go 网关把调用 `index` 嵌在 `function` 内；解析器把这类帧判为 `invalid Chat Completions frame` 并终止整轮。现在两种形状都接受。
- **共享权限链落地（#1761–#1795）。** 权限引擎的共享 changefeed、结算、交接绑定、运行围栏、来源元数据、孤儿清理、事件投影、运行时激活、启动选择、托管授权、TUI 选择、Windows shim、监督与来源事务围栏恢复一并到来。
