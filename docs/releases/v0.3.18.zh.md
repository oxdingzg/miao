# miao v0.3.18

v0.3.18 修好了一个会静默重置已配置模型的配置迁移，接受了一类曾让整轮失败的网关变体，并让共享权限链（#1761–#1795）落地。

## 配置

- **V1 形状的项目配置不再重置已配置模型（#1835）。** `migrate()` 把每个缺失字段物化成显式 `undefined` 键，而合并把“键存在”当作叶子，于是一个没有 `model` 的项目 `.miao/miao.jsonc` 把全局默认覆盖成空，会话回落到目录里最新（且限流）的条目。现在缺席保持缺席。

## 引擎

- **网关把 tool-call 的 index 嵌进 function 也能识别（#1846）。** opencode-go 网关把调用 `index` 嵌在 `function` 内；解析器把这类帧判为 `invalid Chat Completions frame` 并终止整轮。现在两种形状都接受。
- **共享权限链落地（#1761–#1795）。** 权限引擎的共享 changefeed、结算、交接绑定、运行围栏、来源元数据、孤儿清理、事件投影、运行时激活、启动选择、托管授权、TUI 选择、Windows shim、监督与来源事务围栏恢复一并到来。

**完整更新日志**：与 [v0.3.17](https://github.com/oxdingzg/miao/compare/v0.3.17...v0.3.18) 对比。
