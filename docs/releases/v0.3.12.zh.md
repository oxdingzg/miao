# miao v0.3.12

v0.3.12 修掉日常使用中最影响体感的两个问题：首页输入内容回车后不再卡几秒才出现会话画面，转录里的代码高亮也重新有颜色。同时合入 ratatui TUI 的另外六个 Phase 3 切片。

## 性能

- **回车创建会话从约 3 秒降到约 50 毫秒（#1542）。** 窗口里的第一条 prompt 会在该窗口所在目录创建会话，旧路径把这个目录的 native 准备放到了用户等待期间：拉起引擎子进程、等插件启动完成、构建模型路由与工具。真实运行实测 `session.create` 为 2689–3725 毫秒，其中 2309–2535 毫秒就是这份准备（仅 `ProductRoutes.prepare` 等 `plugins.booted` 就占 1719–1883 毫秒），外加一次重复的 Location 启动 416–760 毫秒。这些工作与 prompt 内容无关，因此监听器一旦可达就开始预热该目录的 native owner，此时用户还在看首页。同一探针复测为 51 毫秒，会话正常打开并执行。预热是尽力而为：无法预热的目录会在首次使用时按原路径重新准备。

## TUI

- **转录里的代码高亮恢复颜色（#1541）。** 原生 markdown 渲染器按成本向 12,000 单位的 handle 池租借资源，但 prose 是按渲染行计费的，几段长回答就能把预算耗光，之后的代码块只能退回无颜色的纯文本。现在 prose 按段落计费，预算按最新优先分配（屏幕上正在看的消息保住颜色，而不是最旧的那些），紧凑回退路径会把 fenced code 渲染成带 filetype 的真正代码块，因此仍有高亮。assistant 的代码块和工具输出都恢复着色。
- **Phase 3 的 T3 至 T8 合入（#1527、#1528、#1529、#1540、#1531、#1532）。** ratatui TUI 现在能从引擎读取会话、编写并提交 prompt、中断执行并回答审批、打开模型/主题/会话对话框、显示状态栏、切换账号与暂存 prompt，并支持命令面板、斜杠命令与模板。它仍是备选前端：`miao` 启动的依然是 TypeScript TUI。
