# miao v0.3.28

v0.3.28 fixes the defect that made long answers arrive as a fragment: the
in-process engine starved its own progress channel, overflowed the ring that
carries streamed deltas, and the client discarded the signal that would have
repaired it. A turn now paints as it streams, on both engine paths.

## Streamed answers no longer lose their head

- **The in-process transport no longer starves its progress receiver
  (#2439).** `start_embedded` drained `runtime.progress()` from the same
  `select!` that runs `host.dispatch(...).await`, and a dispatch holds that
  loop for a whole provider turn. The channel is a 256-slot ring and the
  engine emits one notice per streamed delta — measured at 597 for a single
  answer — so the receiver fell behind, got `Lagged`, and every missed delta
  was gone. The receiver now runs on its own task whose only job is to drain,
  so the ring cannot overflow however long a command blocks.
- **The client acts on the overflow notice (#2439).** `TransportEvent::Resync`
  was an empty arm, so even the engine's own report did nothing. It now marks
  the projection dirty, which re-reads the snapshot and replays the durable
  journal instead of painting a transcript with a hole in it.

Measured on a real PTY, same prompt, three runs each:

| | first paint | growth |
|---|---|---|
| before | 2.4 s / 5.3 s / 8.3 s | deltas frequently lost |
| after | 2.6 s / 2.7 s / 2.8 s | smooth every run |

## Transcript layout

- **A wrapped code block keeps its box edge (#2437).** A fenced block is drawn
  as `  ╭ … │ … ╰`, and every markdown row was wrapped with a two-cell hang
  whose remainder is blanked on continuations. That is right for prose and
  wrong for a code block: a long line came out with the `│` gone and the text
  shifted three columns left, which an operator reads as "the output piled
  into one column".
- **The landing prompt matches the TypeScript home (#2435).** `prompt.max_width`
  from `tui.json` is read (a positive integer cap, `"auto"`, or the default
  75), and the wordmark/prompt group is centred rather than riding two-fifths
  down.

## TUI test suite

- **The pty suites no longer hide behind one failure (#2431).** `cargo test`
  stops at the first failing binary and the suites run in name order, so an
  `input_latency` failure meant `interaction_*` and `smoke` — every Session
  test — never ran. Both legs now pass `--no-fail-fast`.
- **The suites follow the prompt-form launcher (#2431).** `d5ca52247a` replaced
  the landing history list with a prompt and updated no pty test. They now
  enter through `--session`, which opens a specific Session directly instead of
  racing the catalog.
- **Question panels cannot outlive their question (#2431).** Past the deadline
  the engine resolves a question as expired and refuses both answer and
  reject, so a blocking panel had two outcomes and both failed with "question
  is already resolved". Expired questions are dropped from the projection and
  Escape clears a stale panel locally.

## Configuration that was validated but never applied

- **`sandbox.writable_roots` now reaches the sandbox (#2441).** The setting was
  parsed and checked, and then never passed on: a project could declare the
  directories its work needs and the sandbox still refused them, with no
  diagnosis. It now reaches the seatbelt profile, the Landlock rules and the
  pty runner.

## Commands

- **A bare `miao` starts the TUI (#2445).** Running `miao` with no arguments
  printed the usage listing; it now opens the interface, which is what the
  command with no arguments means for a terminal product.
- **`miao import` reports what landed (#2454).** Reading the Session back and
  comparing it against the bundle surfaces what the import actually produced
  instead of leaving an operator to open the Session and guess.

## Output and recovery

- **Tool output is cut on a character boundary (#2442).** The elision point
  could fall inside a multi-byte character, so Chinese text and emoji came back
  as `�` at the 32 KiB boundary.
- **Restoring a backup keeps every row (#2451).** The restore merged usage and
  permission rows instead of overwriting them, and now fails loudly when the
  restored row count falls short.

## Resource bounds

- **The TUI event bus is bounded (#2444).** It was unbounded, so a renderer
  that fell behind accumulated events without limit. The queue now holds 1024
  and applies a per-kind policy when it is full, rather than growing the heap.

## Release identity

- **The release ships the product CLI (#2416).** Both packaging paths built
  `crates/miao-tui` and renamed it `miao`, so a released `miao` refused
  `models`, `auth`, `serve` and the rest of the documented surface. Both paths
  now build `crates/miao-cli`, and a `cli` job compiles that crate in CI.
