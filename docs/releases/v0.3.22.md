# miao v0.3.22

v0.3.22 makes the TUI's model/provider picker usable and keeps a window alive across engine restarts: a dead engine wakes on the next prompt, plain lists filter as you type, and the window's own binding is marked.

## TUI

- **A dead engine wakes on the next prompt (#1897).** The request loop used to hold one engine client forever; when the engine died (idle reclaim, a crash, or a binary swap under an update) every later request answered `engine_closed` and the window sat dead until restarted. The loop now keeps the connection (cursors and event stream survive respawns) and reconnects lazily, so sending a message wakes the engine and replays gaplessly; a refused restart surfaces as a notice.
- **`/exit` works (#1897).** `exit` is an alias of `quit`; Ctrl+C, Ctrl+D and ctrl+x q still exit.
- **Model, account and theme lists filter as you type (#1898), and the model list marks the open Session's binding with `●`.** Long catalogs became navigable; the selected binding is visible at a glance.

## Engine

- **Compaction windows follow the operator's provider config (#1886).** A custom provider the catalog does not know takes its window from `providers.<id>.models.<model>.limit.context`, so automatic compaction arms on those routes instead of letting the Session grow until the provider refuses the turn. It complements the emergency truncation that shipped in v0.3.20.
