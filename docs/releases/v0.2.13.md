# [0.2.13] - 2026-10-16

miao 0.2.13 routes native sessions honestly and fixes auto-compaction: the TUI
no longer applies TypeScript agent/model preferences to a Session the operator's
engine configuration already placed, and the summarizer pass behind automatic
compaction no longer stalls forever on real models.

### Added

- **Native operator routing**: Session information now carries
  `execution: { engine, selection }`, and the server reports `rust`/`operator`
  for engine-placed Sessions. For that policy the TUI admits the plain prompt
  directly: it skips the pre-admission agent and model switches it previously
  sent as unsupported calls, submits without a catalog model, keeps the pickers
  locked behind an operator notice, and shows the route as `Native` in the
  footer. TypeScript Sessions keep their existing selection behavior (#904).

### Fixed

- **Auto-compaction stall**: the summarizer consumed only the final reply, so
  nobody read the progress channel it handed to the provider. The stream reader
  awaits send capacity per frame, so any real summary beyond the channel's
  sixteen frames blocked the reader forever — the first arriving event had
  already disarmed the first-event deadline, and the idle timeout only watches
  network bytes, which had all arrived. Every auto-compaction pass against a
  real model degraded to `compaction.failed: summary timeout` while the
  provider had answered in seconds. The summarizer now drains the feed for the
  duration of the call; a regression test pins a reply beyond the channel
  capacity and fails at its five-second bound when only the drain is reverted
  (#905).
- **TestFlight signing**: default TestFlight signing to a cloud-managed
  certificate (#900), upload builds from a macOS 26 runner (#902).
- **Release publishing**: write releases with a dedicated token (#901).

### Validation and upgrade

- Upgrade through the usual miao auto-update channel, or use the repository
  installer. The engine fix is covered by an end-to-end regression test and was
  verified by reverting only the fix on a build host: the reproduction test
  stalls to its bound without the drain and passes with it. The published
  artifact is smoke-tested by launching the terminal interface, not only by
  asking it for its version.
