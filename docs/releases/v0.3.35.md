# miao v0.3.35

v0.3.35 folds the running turn the way it folds the finished one.

## The running turn folds too

- **One spinner line for the work in flight (#2527).** While a turn ran, its
  draft painted every thinking part and every tool call — a long turn tiled
  the screen with bash rows before it answered. The draft now folds the same
  way the committed turn does: one spinner line counts the calls and the
  thinking (`⠇ 2 tool calls · 1 thinking`), and the newest call — the one
  running right now — keeps its full row with its live output. When the turn
  settles, the committed summary takes over.
