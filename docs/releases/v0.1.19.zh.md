## [0.1.19] - 2026-10-07

### 新增

- **cli**：`miao db status` 报告 V1 → V2 会话存储迁移状态——这是退役 legacy 读路径（core/v1、v1-read、回填机制与 schema V1 wire）的迁移指标（#329）

### 修复

- **core**：worktree 被绕过 miao 删除后遗留的孤儿会话自动迁回主检出——`miao -s` 恢复会话不再报 "Failed to load session"；删除 worktree 时会先把仍驻留的会话迁回主检出，而不是拒绝删除；数据库里已有的 11 个孤儿会话在下次访问时自愈（#327）
- **tui**：会话执行期间 mtty 标签页的状态圆圈显示错误（显示为已完成/空闲的绿点）——mtty 状态上报从 V1 事件名改为 V2 事件（`session.next.status` 等），执行中、重试中、等待确认各状态均正确（#328）
