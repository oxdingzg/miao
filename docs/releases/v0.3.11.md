# miao v0.3.11

v0.3.11 is a maintenance release with one performance fix worth the upgrade on its own: a long Session's snapshot no longer scans its journal once per message. It also lands the first two Phase 3 slices of the ratatui TUI, and closes several ways a live turn could end or stall on the engine side.

## Performance

- **A Session snapshot reads its identity journal once (#1524).** Projecting a 1,124-message Session over 7,227 events took 1.7–1.9 s because every message looked up its assistant identity with a separate event scan; the identities are now preloaded in one pass. The same projection now takes 170–175 ms, and every TUI re-hydration stops paying the quadratic cost.

## Engine

- **A slow stdio reader is backpressure, not a failure (#1523).** Writing a large replay frame to a paused client blocked the writer and was treated as a dead transport, ending every Session the engine owned. The writer now waits for the pipe to drain; only a closed pipe or an explicit shutdown ends the stream.
- **A garbled tool call no longer ends the run (#1519), and a rejected call says what it still needs (#1521).** Invalid tool arguments get the model a correction turn instead of tearing down the Session, and the rejection names the missing arguments.
- **Delegated children stay reachable, bounded, and non-recursive (#1514, #1515, #1517).** A child Session can be opened and inspected, cannot delegate again, and inherits a bound the host previously left unlimited.
- **Large attachments travel over stdio (#1512).** Attachments beyond a single frame's comfortable size now reach the engine intact.

## TUI

- **Phase 3 T1 and T2 land (#1503, #1520).** The ratatui shell and the engine's stdio transport are in the tree under `crates/miao-tui`; the transcript slices follow.
- **Sending a prompt no longer re-reads the transcript (#1525).** Admission refreshes the status and the pending inbox in parallel and leaves the transcript alone, so a send ends on two small reads instead of a full re-hydration; the model or agent switch is sent only when the selection actually changed.
- **A Session is titled from its first answer (#1518), and the status line names the tool the turn is waiting on (#1516).** The composer hint moves onto that same line (#1513).

## Platform

- No installer or packaging changes in this release.
