# CTX-05：可审阅、可编辑、可关闭的记忆

状态：设计待审阅；无代码改动。本文不重述记忆**存储**机制（见 `tool/knowledge.md`），而是界定
用户可见的记忆**生命周期面**：模型回合之外如何审阅、编辑、关闭已记住的内容，以及一个禁用开关。
源码基线为 main `7cac644215`，2026-10-28。

## 1. 问题

产品已有记忆系统：Core `knowledge` 工具 + 引擎共用 `.miao/knowledge.json`（`tool/knowledge.ts:18`），
带 `list/get/put/index_file/delete`、乐观并发、TTL、源 sha256 新鲜度，机制相当完整
（`tool/knowledge.md`）。但它**常开且只面向模型**：注册在内置工具表（`tool/builtins.ts:46`），
只在模型回合里被调用。用户要在模型回合之外看见/改掉/关掉"助手记住了什么"，没有产品路径。
CTX-05 补的正是这个生命周期面：审阅、编辑、关闭。

## 2. 现状盘点（as-is）

- **存储机制**（已完备，不属本文）：有界文档（128KiB/64 条，偏好与约束默认 7 天过期），每条
  note 带 kind/title/body/derivation/sources/location/origin_session/expiry；写入走
  `FileMutation` 条件写边界；坏文档与陈旧写请求"保留待审而非静默覆盖"（`tool/knowledge.md`）。
- **审阅原则已声明**：note "显式创建与审阅，不自动抽取、不注入每个请求"（`tool/knowledge.md`）——
  但"审阅"的执行面目前只有模型侧的 `list/get`。
- **常开**：`KnowledgeTool.node` 无条件注册（`tool/builtins.ts:46`），无配置开关可关。
- **无模型外审阅面**：TUI/CLI 没有列出/编辑/清除记忆的命令或对话框。

即：**记忆"能存、能被模型读写"，但用户"看不见、改不掉（回合外）、关不了"。**

## 3. 生命周期面（目标属主）

记忆的用户侧生命周期三件事，各自一个清晰入口，且都不打断当前模型回合：

1. **审阅（review）**：一条命令/对话框列出当前记住的 note——标题、kind、来源文件、新鲜度、
   过期时间、所属 location/session。只读，不触发模型。
2. **编辑（edit）**：在审阅面上直接改 body / 删除单条 / 批量清除。走与 `put/delete` 相同的
   乐观并发（`expected_revision` + `expected_store_sha256`），冲突时提示人工复核，绝不静默覆盖
   ——与存储既有原则一致。
3. **关闭（disable）**：一个配置开关，彻底停用记忆工具（模型侧不再注册、用户侧隐藏审阅写入），
   并对已存内容给出"保留只读"或"一并清除"的选择。关闭是用户对"不要替我记"的明确否决。

## 4. 现状缺口

- **G1｜无禁用开关**：记忆工具常开（`builtins.ts:46`），用户无法表达"不要用记忆"。
- **G2｜无模型外审阅/编辑面**：审阅只能靠模型调 `list/get`；用户想直接看/改没有入口。
- **G3｜生命周期与回合耦合**：审阅/编辑都发生在模型回合内的工具调用里，用户无法在会话空闲时
   独立管理记忆。

## 5. 目标契约（提案，不在本文实施）

- **C1｜禁用开关**：配置项（如 `memory.enabled`，默认开）门控 `KnowledgeTool.node` 的注册；
  关闭时对已存文档提供"转只读"或"清除"的选择，且清除走人工确认。
- **C2｜审阅命令**：一个 CLI 命令（如 `miao memory list/get`）+ TUI 只读对话框，直接读
  `.miao/knowledge.json`（只读不需模型），展示 note 的 kind/来源/新鲜/过期。
- **C3｜编辑走条件写**：编辑/删除复用 `FileMutation` 条件写与乐观并发，冲突提示复核，坏文档
  保留待审——不另起第二套写路径。
- **C4｜生命周期独立于回合**：审阅/编辑/关闭在会话空闲时可用，不占用模型回合、不需要模型介入。

## 6. 与相邻工作的边界

- **`tool/knowledge.md`**：属主存储机制与模型侧契约；本文属主用户侧生命周期面，二者互补不重叠。
- **CFG 配置属主**：C1 的 `memory.enabled` 归 CFG 配置读写；本文只声明需要这样一个开关。
- **SEC-06 密钥/日志边界**：记忆不得存密钥；审阅面展示 body 时须沿用既有的受限 source 隐藏规则
  （`tool/knowledge.md`）。
- **TUI-05 侧栏迁移**：TUI 审阅对话框的实现归 TUI 域；本文只定义需要一个审阅面与其字段。

## 7. 验收方向（后续）

设计对齐，不带验收。落地时以最小改动验证：关闭开关后模型不再有记忆工具且已存内容按选择处理
（C1）、`miao memory list` 只读列出且不触发模型（C2）、编辑冲突时提示复核而非覆盖（C3）。真实
隔离覆盖随 SEC-04。
