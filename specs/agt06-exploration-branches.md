# AGT-06：临时旁问与独立探索分支

状态：设计待审阅；无代码改动。本文界定一种**轻量探索分支**：工作途中提一个临时旁问、或试一条
独立思路，既不打断主线，又能廉价回报、可合并可丢弃。它比完整委派（AGT-03）轻，比用户驱动的
会话 fork（HIS-02）自动。源码基线为 main `e76435ad96`，2026-10-28。

## 1. 问题

主线推进时，常需要"先探一下这条路走不走得通""顺手问一句但别停下主活"。今天只有两个重手段：
派一个完整子代理（AGT-03，有派生/报告/预算全套成本），或 fork 一个会话（HIS-02，用户驱动的
全量分叉）。缺一个**便宜的中间档**：一个 subordinate 的探索分支，跑一条思路/答一个旁问，回报
一句结论，然后合并回主线或直接丢弃，全程不占用主线的上下文与注意力。AGT-06 要定义这个档位。

## 2. 现状盘点（as-is，锚定实现）

- **数据级 fork 原语**：`SessionFork.remapEventData`（`session/fork.ts:12`）能把一个会话的
  历史在新 aggregate 下重放（重映射消息级 id）。这是 fork 的**数据层**原语，被 fork/merge 操作
  使用，不是"探索分支"的产品概念。
- **旁问**：`question` 工具（`tool/question.ts:12`）向**用户**提问并等待答案——是阻塞式的人机
  交互，不是"向自己提一个旁问去探索"。
- **完整委派**：AGT-03 的 `task` 子代理——派生、隔离上下文、结构化报告、预算，成本高，不适合
  一句旁问或一次思路试错。
- **无轻量探索分支**：没有一个"起一条思路、跑、回报、合并/丢弃"的低成本档位。

即：**有数据级 fork、有用户旁问、有重型委派，独缺中间的轻量探索分支。**

## 3. 轻量探索分支的契约

一个探索分支是**主线下的临时、可丢弃、可合并的从属执行**，四条性质：

1. **从属（subordinate）**：分支属于主线会话（复用 `parent_id`），不另起用户可见的持久会话；
   主线的 Todo/Goal 不被分支的探索内容污染。
2. **廉价回报（cheap return）**：分支跑完只回一句**结论**（成/不成 + 一句依据），不回全量转写；
   与 AGT-03 的净收益回执同源，但默认更轻。
3. **可合并（mergeable）**：分支若探出可行动的产物（一段方案、一个发现），可按 AGT-04 的
   Plan→Todo 转写并入主线；数据层复用 `remapEventData` 的历史重放能力。
4. **可丢弃（discardable）**：分支默认临时；丢弃不产生副作用、不污染主线历史（沿用 RUN-04/05
   的"不重放副作用"铁律）。

## 4. 现状缺口

- **G1｜无低成本档位**：旁问只能二选一——问用户（`question`，阻塞）或派完整子代理（`task`，重）。
- **G2｜探索产物无轻量并入路径**：fork 是数据级、用户驱动；没有"分支探完自动转写回主线"的桥。
- **G3｜探索与主线注意力无隔离**：现有手段要么阻塞主线（问用户）、要么全量隔离（派子代理后
  主线仍要读报告），没有"探完只留一句结论"的中间态。

## 5. 目标契约（提案，不在本文实施）

- **C1｜探索分支原语**：一个轻量 spawn，起主线下的从属执行（复用 `parent_id`），带一个"只回
  结论"的收敛目标；不建用户可见持久会话。
- **C2｜结论回报**：分支收敛为一句 结论+依据，按 AGT-03 净收益回执口径回主线，主线不必读全量。
- **C3｜合并/丢弃二态**：探出可行动产物则按 AGT-04 Plan→Todo 转写并入（数据层复用
  `remapEventData`）；否则丢弃，无副作用、不污染历史。
- **C4｜预算与设界**：探索分支有独立小预算与 hop 上界（沿用 AGT-05 环路设界），防旁问变重活。

## 6. 与相邻工作的边界

- **AGT-03 委派**：属主重型委派（派生/结构化报告/预算继承）；本文属主**轻量**探索档位，是其
  "便宜探路"补充，不取代。
- **AGT-04 Plan→Todo**：本文 C3 的并入复用其转写契约，不另起。
- **AGT-01 子状态/导航**：探索分支若可见，其状态行/导航复用 AGT-01，本文只定义档位语义。
- **HIS-02 fork**：用户驱动的全量会话 fork 归 HIS-02；本文是自动的、从属的、临时的探索分支。
- **RUN-04/05**：丢弃不重放副作用遵循其铁律。

## 7. 验收方向（后续）

设计对齐，不带验收。落地时以最小改动验证：主线可起一条探索分支并只收一句结论（C1/C2）、探出
产物可并入主线 Todo 而丢弃无副作用（C3）、旁问不会膨胀成重活（C4）。真实隔离覆盖随 SEC-04。
